  7. 121 : 12 :: 25 : ?

    1. 6
    2. 5
    3. 7
    4. 8
    Show answer

    Answer: (A) 6

    Explanation: Take the square root, then add 1: √121+1=12 and √25+1=6.

  8. 6 : 222 :: 7 : ?

    1. 343
    2. 350
    3. 336
    4. 354
    Show answer

    Answer: (B) 350

    Explanation: The rule is x³+x: 6³+6=222, so 7³+7=350.

  9. 26 : 5 :: 65 : ?

    1. 7
    2. 6
    3. 8
    4. 9
    Show answer

    Answer: (C) 8

    Explanation: The first number is one more than a square: 26=5²+1 and 65=8²+1.

  10. 25 : 125 :: 36 : ?

    1. 180
    2. 206
    3. 256
    4. 216
    Show answer

    Answer: (D) 216

    Explanation: The pair is n²:n³; 25=5², so 125=5³. For 36=6², the match is 6³=216.

  11. 68 : 130 :: 222 : ?

    1. 350
    2. 342
    3. 343
    4. 360
    Show answer

    Answer: (A) 350

    Explanation: These are n³+n for consecutive n: 4³+4=68, 5³+5=130, 6³+6=222, so the next is 7³+7=350.

  12. 42 : 56 :: 72 : ?

    Answer: (B) 90

    Explanation: The products are 6×7, 7×8, 8×9; next is 9×10=90.

  20. 16 : 56 :: 32 : ?

  21. 0.16 : 0.0016 :: 1.02 : ?

  22. 7 : 56 :: 9 : ?

    1. 63
    2. 81
    3. 99
    4. 90
    Show answer

    Answer: (D) 90

    Explanation: Multiply a number by its successor: 7×8=56 and 9×10=90.

  23. 48 : 122 :: 168 : ?

    1. 290
    2. 225
    3. 292
    4. 280
    Show answer

    Answer: (A) 290

    Explanation: Write 48=7²−1 and 122=11²+1. Since 168=13²−1, apply the same offset of 4 to get 17²+1=290.

  24. 11529 : 72135 :: 152943 : ?

    1. 163044
    2. 213549
    3. 203448
    4. 6203
    Show answer

    Answer: (B) 213549

    Explanation: The digits in each number pair have equal sums: both 11529 and 72135 sum to 18; 152943 sums to 24, as does 213549.

  25. Given set (14, 23, 32): choose a matching set.

    1. (12, 20, 30)
    2. (14, 22, 32)
    3. (12, 21, 30)
    4. (13, 21, 31)
    Show answer

    Answer: (C) (12, 21, 30)

    Explanation: Each term increases by 9: 14, 23, 32. The matching set also increases by 9.
