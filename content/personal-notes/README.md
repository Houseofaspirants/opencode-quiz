# content/personal-notes/

Documents in this folder are rendered to static pages by
`scripts/build_content.py`.

What belongs here: a method that was really used, written after the fact —
the revision loop that survived a working week, the timetable that did not,
the mistake that cost marks. Not general advice, and never a claim that cannot
be checked against the attempt.

Page prefix `pnote-`, hub `personal-notes.html`, required beyond the shared
fields: `subject`.

Schemas, fields and rules: see [`content/README.md`](../README.md).
