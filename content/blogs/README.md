# content/blogs/

Preparation blog posts — study habits, book notes, mock test debriefs and
honest attempts. Documents in this folder are rendered to static pages by
`scripts/build_content.py` and published at `blogs.html` + `blog-<slug>.html`
(Punjabi edition under `/pa/`).

Schemas, fields and rules: see [`content/README.md`](../README.md).
