# content/success-stories/

Documents in this folder are rendered to static pages by
`scripts/build_content.py`.

What belongs here: one attempt, described honestly — the preparation, what
failed first, the change that made the difference and the part of the method
worth copying. The selection and the exam must both be real; nothing here is
written to motivate without evidence.

Page prefix `story-`, hub `success-stories.html`, required beyond the shared
fields: `exam`.

Schemas, fields and rules: see [`content/README.md`](../README.md).
