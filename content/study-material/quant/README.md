# Quantitative Aptitude — Study Material

Drop PDFs, Markdown or JSON files in this folder and run `npm run publish`.
Nothing else is needed: the folder is the registration.

Everything published from here appears under **Study → Quantitative Aptitude → Study Material**.

- What can be uploaded and what gets derived: `content/study-material/README.md`
- Optional per-file overrides: `metadata.json` beside the files
- Supported: `.pdf`, `.md`, `.json` — `README.md` is ignored

Arithmetic, algebra, geometry and the short methods that save minutes in the paper.
