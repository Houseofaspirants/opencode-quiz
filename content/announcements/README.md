# content/announcements/

Announcements from House of Aspirants — new sections, schedule changes,
editorial updates and platform news. Documents in this folder are rendered to
static pages by `scripts/build_content.py` and published at
`announcements.html` + `announce-<slug>.html` (Punjabi edition under `/pa/`).

Schemas, fields and rules: see [`content/README.md`](../README.md).
