# content/news/

Exam news — application dates, pattern changes and policy announcements, each
restated only from the recruiting body's own notification (`official_url` is
subject to the same official-source rule as `recruitment/`). Rendered by
`scripts/build_content.py` and published at `news.html` + `news-<slug>.html`
(Punjabi edition under `/pa/`).

Schemas, fields and rules: see [`content/README.md`](../README.md).
