# content/daily-practice/

Documents in this folder are rendered to static pages by
`scripts/build_content.py`.

What belongs here: a dated practice set and the write-up after attempting it —
what was asked, why each answer is what it is, and what to revise from the
ones that went wrong. `quiz:` points at the set to attempt.

Page prefix `practice-`, hub `daily-practice.html`, required beyond the shared
fields: `subject`.

Schemas, fields and rules: see [`content/README.md`](../README.md).
