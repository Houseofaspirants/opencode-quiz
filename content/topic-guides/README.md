# content/topic-guides/

Documents in this folder are rendered to static pages by
`scripts/build_content.py`.

What belongs here: one topic inside a subject — Fundamental Rights, the Sikh
period, blood relations — with the scope, the exceptions the paper loves, the
common mistakes and the set to attempt straight after reading.

Page prefix `tguide-`, hub `topic-guides.html`, required beyond the shared
fields: `subject` (`topic` names the topic in words).

Schemas, fields and rules: see [`content/README.md`](../README.md).
