# content/subject-guides/

Documents in this folder are rendered to static pages by
`scripts/build_content.py`.

What belongs here: one subject end to end — what the syllabus actually asks,
the order to study it in, the dates the paper keeps repeating and where to
practise afterwards. One guide per subject, kept current rather than long.

Page prefix `sguide-`, hub `subject-guides.html`, required beyond the shared
fields: `subject`.

Schemas, fields and rules: see [`content/README.md`](../README.md).
