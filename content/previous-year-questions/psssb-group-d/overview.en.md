## What is on this page

Every PSSSB Group D paper we have, as released by the Punjab Subordinate Services Selection Board (PSSSB). Each row is one year: the question paper, and the official answer key beside it where one was released. Where no key was released, the cell says so.

## Papers in this folder

- 2026: Question paper (5 Apr); official answer keys (Final / Provisional, Set A / Provisional, Set B / Provisional, Set C / Provisional, Set D)

## How to use these papers

1. Solve the first paper without a clock, to see which topics are really asked.
2. Attempt the next one strictly timed, and check it only against the official key.
3. Note every mistake as a concept gap or a speed gap, and revise those topics with our free topic-wise quizzes.
