Question bank

Input Devices - Part 1 - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. A hardware device that allows a user to enter data, instructions or control signals into a computer is called:

    1. Output Device
    2. Storage Device
    3. Input Device
    4. Processor
    Show answer

    Answer: (C) Input Device

    Explanation: An Input Device allows a user to enter data, instructions or control signals into a computer.

  2. Which is the most commonly used input device to enter text, numbers, symbols and commands?

    1. Mouse
    2. Scanner
    3. Joystick
    4. Keyboard
    Show answer

    Answer: (D) Keyboard

    Explanation: A Keyboard is the most commonly used input device to enter text, numbers, symbols and commands.

  3. A wireless keyboard, as mentioned in the chapter, connects through:

    1. Bluetooth
    2. USB cable
    3. Magnetic ink
    4. Paper tape
    Show answer

    Answer: (A) Bluetooth

    Explanation: Keyboard connectivity: USB Keyboard (Wired) and Bluetooth Keyboard (Wireless).

  4. Which is the most commonly used keyboard layout in the world?

    1. AZERTY
    2. DVORAK
    3. QWERTY
    4. QWERTZ
    Show answer

    Answer: (C) QWERTY

    Explanation: Exam Point: Most commonly used keyboard = QWERTY.

  5. A standard QWERTY keyboard usually contains how many keys?

    1. 104
    2. 84
    3. 101
    4. 110
    Show answer

    Answer: (A) 104

    Explanation: The QWERTY keyboard usually contains 104 keys.

  6. Keys that are used to switch a function ON or OFF are called:

    1. Modifier Keys
    2. Toggle Keys
    3. Function Keys
    4. Arrow Keys
    Show answer

    Answer: (B) Toggle Keys

    Explanation: Toggle Keys are used to switch a function ON or OFF.

  7. Which of the following is a Toggle Key?

    1. Caps Lock
    2. Shift
    3. Ctrl
    4. Alt
    Show answer

    Answer: (A) Caps Lock

    Explanation: Caps Lock, Num Lock and Scroll Lock are toggle keys.

  8. Which of the following is a Modifier (Combination) Key, used along with another key?

    1. Num Lock
    2. Scroll Lock
    3. Caps Lock
    4. Alt
    Show answer

    Answer: (D) Alt

    Explanation: Shift, Ctrl and Alt are modifier (combination) keys.

  9. The AZERTY keyboard is mainly used in:

    1. India and China
    2. USA and Canada
    3. France and Belgium
    4. Japan and Korea
    Show answer

    Answer: (C) France and Belgium

    Explanation: AZERTY is mainly used in France, Belgium and some European countries (French keyboard).

  10. Which keyboard was developed to improve typing speed?

    1. QWERTY
    2. DVORAK
    3. AZERTY
    4. Numeric keypad
    Show answer

    Answer: (B) DVORAK

    Explanation: Exam Point: DVORAK = Fast Typing Keyboard.

  11. Who invented the computer mouse?

    1. Douglas C. Engelbart
    2. C. B. Mirick
    3. Jack Kilby
    4. Frank Beck
    Show answer

    Answer: (A) Douglas C. Engelbart

    Explanation: The mouse was invented by Douglas C. Engelbart.

  12. In which year did Douglas C. Engelbart invent the mouse?

    1. 1955
    2. 1971
    3. 1999
    4. 1963
    Show answer

    Answer: (D) 1963

    Explanation: Douglas C. Engelbart invented the mouse in 1963.

  13. A laptop uses which device instead of a traditional mouse?

    1. Joystick
    2. Light Pen
    3. Digitizer
    4. Touchpad
    Show answer

    Answer: (D) Touchpad

    Explanation: A laptop uses a Touchpad instead of a traditional mouse.

  14. Which type of mouse contains a ball fixed inside the device that the user rotates with fingers?

    1. Optical Mouse
    2. Trackball Mouse
    3. Wireless Mouse
    4. Mechanical Mouse
    Show answer

    Answer: (B) Trackball Mouse

    Explanation: A Trackball Mouse contains a fixed ball which the user rotates using fingers.

  15. Which mouse uses a ball and rollers, collects dust and requires regular cleaning?

    1. Optical Mouse
    2. Mechanical Mouse
    3. Wireless Mouse
    4. Touchpad
    Show answer

    Answer: (B) Mechanical Mouse

    Explanation: A Mechanical Mouse uses a ball and rollers; its drawback is that it collects dust.

  16. An Optical Mouse works using:

    1. Ball and rollers
    2. Magnetic ink
    3. LED and optical sensor
    4. Photomultiplier tube
    Show answer

    Answer: (C) LED and optical sensor

    Explanation: An Optical Mouse uses LED, optical sensor and digital signal processing; it has no ball mechanism.

  17. Microsoft introduced optical mouse technology commercially in:

    1. 1999
    2. 1963
    3. 1984
    4. 1977
    Show answer

    Answer: (A) 1999

    Explanation: Microsoft introduced optical mouse technology commercially in 1999.

  18. Moving the mouse pointer over an object without clicking it is called:

    1. Dragging
    2. Scrolling
    3. Double-clicking
    4. Hovering
    Show answer

    Answer: (D) Hovering

    Explanation: Hovering means moving the mouse pointer over an object without clicking it.

  19. A Scanner converts printed documents, photographs or images into:

    1. Sound
    2. Magnetic ink
    3. Printed copies
    4. Digital form
    Show answer

    Answer: (D) Digital form

    Explanation: A Scanner converts printed documents, photographs or images into digital form.

  20. Which is the most commonly used type of scanner?

    1. Flatbed Scanner
    2. Drum Scanner
    3. Sheetfed Scanner
    4. Photo Scanner
    Show answer

    Answer: (A) Flatbed Scanner

    Explanation: The Flatbed Scanner is the most commonly used scanner; the document is placed on a glass surface.

  21. A Barcode Scanner is an example of which type of scanner?

    1. Handheld Scanner
    2. Flatbed Scanner
    3. Drum Scanner
    4. Sheetfed Scanner
    Show answer

    Answer: (A) Handheld Scanner

    Explanation: Barcode Scanner is a handheld scanner, held in hand and moved over the item.

  22. In which scanner does the paper move through the scanner while the scanner remains stationary, best for single-page documents?

    1. Flatbed Scanner
    2. Sheetfed Scanner
    3. Handheld Scanner
    4. Drum Scanner
    Show answer

    Answer: (B) Sheetfed Scanner

    Explanation: In a Sheetfed Scanner the paper moves through a stationary scanner; best for single-page documents.

  23. Which scanner uses a PMT (Photomultiplier Tube) and gives extremely high resolution?

    1. Flatbed Scanner
    2. Handheld Scanner
    3. Drum Scanner
    4. Sheetfed Scanner
    Show answer

    Answer: (C) Drum Scanner

    Explanation: A Drum Scanner uses PMT (Photomultiplier Tube) and offers extremely high resolution.

  24. Who is credited as the inventor of the Joystick in the chapter?

    1. Douglas C. Engelbart
    2. C. B. Mirick
    3. Bent Stumpe
    4. Jack Kilby
    Show answer

    Answer: (B) C. B. Mirick

    Explanation: Joystick inventor: C. B. Mirick.

  25. A Joystick is mainly used for:

    1. Reading bank cheques
    2. Scanning documents
    3. Video games and flight simulators
    4. Recording voice
    Show answer

    Answer: (C) Video games and flight simulators

    Explanation: Joystick uses: video games, flight simulators and military applications.
