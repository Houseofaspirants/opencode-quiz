Question bank

Analogy MCQ – Part 3: all 25 questions

Read the question, pick an option, then open the answer.

  1. Amanpreet lists two occupations and tools: Surveyor : Theodolite; Barber : Razor. Which statement identifies the common relation precisely?

    1. The second item is the usual workplace of the first.
    2. The first item measures the quantity named by the second.
    3. The first item is a raw material transformed into the second.
    4. The second item is equipment used by the first in professional work.
    Show answer

    Answer: (D) The second item is equipment used by the first in professional work.

    Explanation: A surveyor uses a theodolite and a barber uses a razor. Both are worker → professional equipment links.

  2. Cubing is the only operation in the analogy 12 : 1728 :: 16 : 4096 :: 18 : X. Calculate X.

    1. 6859
    2. 324
    3. 4913
    4. 5832
    Show answer

    Answer: (D) 5832

    Explanation: Cube 18: 18²=324 and 324×18=5832.

  3. A code reverses letter order and then replaces each letter by its alphabet opposite, as in BGL → OTY. Which conversion fails this two-step rule?

    1. FKU → FPU
    2. HNR → IMT
    3. DMS → HNW
    4. CQT → GJX
    Show answer

    Answer: (B) HNR → IMT

    Explanation: HNR reverses to RNH; its opposite letters are I, M and S, giving IMS rather than IMT. The other three conversions obey both steps.

  4. Replace the bracketed word without altering its meaning: Peril : Danger :: (Adept) : X. Which X makes a synonym analogy?

    1. Clumsy
    2. Unwilling
    3. Skilled
    4. Inexperienced
    Show answer

    Answer: (C) Skilled

    Explanation: Peril means danger. Adept means highly skilled, not clumsy, inexperienced or unwilling.

  5. A shared rule generates (9, 41), (13, 85) and (7, 25). Select the pair generated by the same rule; do not split digits.

    1. (19, 180)
    2. (17, 145)
    3. (11, 60)
    4. (15, 114)
    Show answer

    Answer: (B) (17, 145)

    Explanation: The rule is (n²+1)/2. For 17 it gives (289+1)/2=145; the other pairs do not satisfy it.

  6. Read each pair as home → animal, like Kennel → Dog. Which offered pair keeps that direction?

    1. Ant → Anthill
    2. Hen → Coop
    3. Drey → Squirrel
    4. Horse → Stable
    Show answer

    Answer: (C) Drey → Squirrel

    Explanation: A drey is a squirrel’s nest, so this pair runs home → animal. The other offered pairs run animal → home.

  7. Rupinder compares instrument → measured quantity pairs. Which replacement for Hydrometer : Relative density preserves that exact kind of relation?

    1. Balance : Kilogram
    2. Voltmeter : Ampere
    3. Altimeter : Altitude
    4. Stopwatch : Athlete
    Show answer

    Answer: (C) Altimeter : Altitude

    Explanation: A hydrometer measures relative density and an altimeter measures altitude. A quantity must be named second, not a unit or user.

  8. The code changes ACE8 → EAC12 and DGI5 → IDG10 rotate letters and alter the number. What is the corresponding form of KOR11?

    1. RKO15
    2. RKO18
    3. ORK18
    4. RKO22
    Show answer

    Answer: (B) RKO18

    Explanation: Move the last letter to the front and add the original last-to-first position gap: E−A=4 and I−D=5. KOR gives RKO and 11+(18−11)=18, hence RKO18.

  9. For a worker-to-workplace analogy, complete Jeweller : Jewellery workshop :: Librarian : X. Choose the place, rather than an object handled there.

    1. Book
    2. Reading
    3. Library
    4. Catalogue
    Show answer

    Answer: (C) Library

    Explanation: A librarian’s workplace is a library. A book or catalogue is an object there, and reading is an activity.

  10. Digit operations are allowed in 647 : 168 and 352 : 30. Infer the common rule and determine the partner of 826.

    1. 96
    2. 16
    3. 160
    4. 48
    Show answer

    Answer: (A) 96

    Explanation: Multiply all three digits: 8×2×6=96. Adding the digits or multiplying only two does not follow the rule.

  11. BDFH : CCEI and KMPR : LLOS apply one rule to the outside letters and another to the inside letters. Find the image of SUWY.

    1. RTVX
    2. TTVZ
    3. TTVX
    4. TVXZ
    Show answer

    Answer: (B) TTVZ

    Explanation: Advance the outside letters by 1 and move the inside letters back by 1. SUWY gives S→T, U→T, W→V and Y→Z, hence TTVZ.

  12. The arrow in Voluntary → Compulsory changes a word to its opposite. Under the same arrow, what should follow Lenient?

    1. Tolerant
    2. Merciful
    3. Strict
    4. Indulgent
    Show answer

    Answer: (C) Strict

    Explanation: Voluntary and compulsory are opposites. Lenient means not strict, so its opposite is strict.

  13. One pair expresses number → positive square root: (324, 18). Which further pair can be added to that category?

    1. (729, 9)
    2. (484, 24)
    3. (841, 29)
    4. (576, 26)
    Show answer

    Answer: (C) (841, 29)

    Explanation: The second entry must square to the first. Since 29²=841, (841, 29) fits.

  14. A travel analogy converts country : capital : currency into capital : currency : country, as in Canada : Ottawa : Canadian dollar → Ottawa : Canadian dollar : Canada. Which row is both factually correct and in the resulting order?

    1. Wellington : New Zealand dollar : New Zealand
    2. Australia : Canberra : Australian dollar
    3. Auckland : New Zealand dollar : New Zealand
    4. Wellington : Australian dollar : New Zealand
    Show answer

    Answer: (A) Wellington : New Zealand dollar : New Zealand

    Explanation: Wellington is New Zealand’s capital, and its currency is the New Zealand dollar. Only that row also follows capital → currency → country.

  15. A zoo card has the columns Young one : Adult : Sound. Which completed card is fully analogous to Kitten : Cat : Mew?

    1. Gosling : Goose : Honk
    2. Joey : Kangaroo : Roar
    3. Lamb : Sheep : Bray
    4. Duckling : Duck : Crow
    Show answer

    Answer: (A) Gosling : Goose : Honk

    Explanation: A gosling is a young goose, and a goose honks. The other rows give an incorrect sound for the named adult.

  16. Each two-number input produces the difference of its squares: (14, 9) → 115 and (16, 11) → 135. Evaluate (23, 17) using the fastest equivalent method.

    1. 60
    2. 36
    3. 1600
    4. 240
    Show answer

    Answer: (D) 240

    Explanation: Use a²−b²=(a−b)(a+b). Thus (23−17)(23+17)=6×40=240.

  17. Which chain completes the same three roles as Potter : Pottery workshop : Clay, with the order worker → workplace → main raw material?

    1. Weaver : Weaving shed : Yarn
    2. Baker : Flour : Bakery
    3. Carpenter : Workshop : Saw
    4. Cobbler : Shoe : Leather
    Show answer

    Answer: (A) Weaver : Weaving shed : Yarn

    Explanation: A weaver works in a weaving shed and uses yarn as raw material. The other chains misplace a role or supply a tool or product instead.

  18. The last letter moves to the front in GATE : EGAT, while the other letters keep their order. Apply that arrangement to POND.

    1. DNOP
    2. ONDP
    3. DPON
    4. PDON
    Show answer

    Answer: (C) DPON

    Explanation: Move D to the front and retain PON in order. POND becomes DPON.

  19. Keep two different relations separate: Glow : Blaze :: Tremor : X; Calm : Agitated :: Lucid : Y. Which combined choice completes both analogies?

    1. Violent earthquake; Clear
    2. Violent earthquake; Obscure
    3. Aftershock; Obscure
    4. Landslide; Transparent
    Show answer

    Answer: (B) Violent earthquake; Obscure

    Explanation: Glow → blaze increases the same phenomenon’s intensity, so tremor → violent earthquake fits. Calm → agitated is an antonym link, so lucid → obscure completes the second analogy.

  20. The map pairs a two-digit number with the positive difference between it and its reversal: 72 : 45 and 94 : 45. Find the image of 83.

    1. 5
    2. 45
    3. 24
    4. 121
    Show answer

    Answer: (B) 45

    Explanation: Reverse 83 to obtain 38, then subtract the smaller number: 83−38=45.

  21. In the analogy Millimetre : Length :: Millilitre : X, the prefixes do not alter what is being measured. Which quantity is X?

    1. Mass
    2. Density
    3. Area
    4. Volume
    Show answer

    Answer: (D) Volume

    Explanation: A millimetre measures length; a millilitre measures volume. The prefix milli changes scale, not the quantity.

  22. Harleen groups (6, 13) and (10, 21) because the second number is the next odd integer after twice the first. Which pair must stay outside the group?

    1. (15, 29)
    2. (12, 25)
    3. (8, 17)
    4. (19, 39)
    Show answer

    Answer: (A) (15, 29)

    Explanation: The common rule is 2n+1. For 15 it requires 31, not 29; every other offered pair fits.

  23. Under A=1 to Z=26, BCD : 24 and CEF : 90 use a product of positions. A second operation then shifts each letter back by 1. What complete output belongs to DGH?

    1. CFG224
    2. CFG126
    3. CFG19
    4. EFI224
    Show answer

    Answer: (A) CFG224

    Explanation: The original position product is 4×7×8=224. Moving D, G and H back by 1 gives CFG, hence CFG224.

  24. Use letter-position multiplication, with A=1 to Z=26. CF corresponds to 18; what corresponds to HK?

    1. 19
    2. 811
    3. 3
    4. 88
    Show answer

    Answer: (D) 88

    Explanation: C×F=3×6=18. Therefore H×K=8×11=88.

  25. Square numbers are paired with the next larger square: 64 : 81 :: 121 : 144 :: 289 : X. Determine X.

    1. 361
    2. 290
    3. 306
    4. 324
    Show answer

    Answer: (D) 324

    Explanation: 289=17², so move to 18²=324. Do not reuse the earlier numerical gaps; the square roots increase by 1.
