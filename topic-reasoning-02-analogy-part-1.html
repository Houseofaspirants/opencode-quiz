Question bank

Analogy MCQ – Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. At a Ludhiana workshop, Harjit matches Engraver : Burin. Which pair preserves the same worker-to-specialised-tool relation?

    1. Weaver : Fabric
    2. Mason : Trowel
    3. Welder : Workshop
    4. Cobbler : Leather
    Show answer

    Answer: (B) Mason : Trowel

    Explanation: An engraver works with a burin; a mason works with a trowel. Both pairs link a worker to a tool, in that order.

  2. A machine pairs 14 with 196 and 19 with 361 by taking the square. What should it pair with 27?

    1. 729
    2. 54
    3. 784
    4. 676
    Show answer

    Answer: (A) 729

    Explanation: Square the input: 27 × 27 = 729.

  3. A letter conversion gives BFK : DJQ and HMR : JQX. Decode QVA under the same position-wise shifts; continue after Z from A.

    1. SZG
    2. SYG
    3. UZG
    4. SZE
    Show answer

    Answer: (A) SZG

    Explanation: The three shifts are +2, +4 and +6. Thus Q→S, V→Z and A→G, giving SZG.

  4. For a vocabulary analogy, Mehak needs a pair with the same meaning relation as Frugal : Economical. Which entry fits?

    1. Tepid : Scalding
    2. Candid : Frank
    3. Timid : Bold
    4. Scarce : Plentiful
    Show answer

    Answer: (B) Candid : Frank

    Explanation: Frugal and economical are synonyms. Candid and frank also mean open and direct in expression.

  5. Find the number pair governed by the relation in (8, 60) and (11, 117). Treat each number as a whole.

    1. (15, 223)
    2. (12, 148)
    3. (9, 85)
    4. (14, 192)
    Show answer

    Answer: (D) (14, 192)

    Explanation: The second number is the square of the first minus 4: 8²−4=60 and 11²−4=117. Therefore 14²−4=192.

  6. A wildlife register uses adult → young one. Which entry must be removed because it reverses that direction?

    1. Goat : Kid
    2. Pig : Piglet
    3. Cat : Kitten
    4. Fawn : Deer
    Show answer

    Answer: (D) Fawn : Deer

    Explanation: A fawn is a young deer, so Fawn : Deer runs young → adult. The other entries run adult → young.

  7. Complete both links, keeping capital and currency separate: Kenya : Nairobi :: Vietnam : X; Kenya : Kenyan shilling :: Vietnam : Y. What are X and Y?

    1. Hanoi; Dong
    2. Hanoi; Baht
    3. Ho Chi Minh City; Dong
    4. Vientiane; Kip
    Show answer

    Answer: (A) Hanoi; Dong

    Explanation: The first link is country → capital; the second is country → currency. Vietnam has capital Hanoi and currency dong.

  8. Simran obtains CF7 → DG49 and HK9 → IL81. Which output belongs to TW12 if the letters and number follow the same separate rules?

    1. UV144
    2. UX143
    3. UX144
    4. UX24
    Show answer

    Answer: (C) UX144

    Explanation: Advance each letter by 1 and square the number. T→U, W→X and 12²=144, so the result is UX144.

  9. Neeraj labels a workplace relation Pharmacist → Pharmacy. Which label follows the same direction?

    1. Baker → Oven
    2. Astronomer → Observatory
    3. Sculptor → Statue
    4. Museum → Curator
    Show answer

    Answer: (B) Astronomer → Observatory

    Explanation: A pharmacy is a pharmacist’s workplace; an observatory is an astronomer’s workplace.

  10. An input-output table reads 7 → 28 and 13 → 46. Its rule is multiplication by one fixed integer followed by addition of another. Find the output for 24.

    1. 86
    2. 79
    3. 75
    4. 72
    Show answer

    Answer: (B) 79

    Explanation: The input increase of 6 gives an output increase of 18, so multiply by 3; 28−3×7=7. Hence 3×24+7=79.

  11. In a code, MANGO becomes PHOBN and LEMON becomes OPNFM. What is the corresponding form of TULIP?

    1. QJMVU
    2. PILUT
    3. RKNWV
    4. UVMJQ
    Show answer

    Answer: (A) QJMVU

    Explanation: Reverse the letter order and then advance every letter by 1. TULIP→PILUT→QJMVU.

  12. A relation card says Transparent : Opaque. In the same order, which word must follow Flexible?

    1. Supple
    2. Pliable
    3. Elastic
    4. Rigid
    Show answer

    Answer: (D) Rigid

    Explanation: Transparent and opaque are opposites. The opposite of flexible is rigid.

  13. A doubling relation links (23, 46). Which of these pairs has the identical relation?

    1. (34, 70)
    2. (37, 74)
    3. (41, 81)
    4. (29, 59)
    Show answer

    Answer: (B) (37, 74)

    Explanation: The second number must be twice the first. Only 37×2=74 fits.

  14. Aman writes Barometer : Atmospheric pressure : Pascal. Which complete chain preserves instrument → measured quantity → SI unit?

    1. Anemometer : Wind speed : Kilometre
    2. Ammeter : Potential difference : Ampere
    3. Dynamometer : Force : Newton
    4. Thermometer : Temperature : Joule
    Show answer

    Answer: (C) Dynamometer : Force : Newton

    Explanation: A dynamometer measures force, whose SI unit is the newton. Each other chain has a mismatch in the quantity or unit.

  15. Two blanks must represent an animal’s sound and then its home: Horse : Neigh : Stable :: Pig : X : Y. Select X and Y together.

    1. Bleat; Sty
    2. Squeak; Eyrie
    3. Grunt; Sty
    4. Grunt; Kennel
    Show answer

    Answer: (C) Grunt; Sty

    Explanation: A pig grunts and is kept in a sty. Both blanks must match the sound → home order after the animal.

  16. Digit operations are permitted. The pairs 47 → 37 and 63 → 27 follow one rule combining digit product and digit difference. Determine the partner of 85.

    1. 43
    2. 53
    3. 37
    4. 49
    Show answer

    Answer: (D) 49

    Explanation: Add the digit product to the squared difference: 4×7+(7−4)²=37 and 6×3+(6−3)²=27. For 85, 8×5+(8−5)²=49.

  17. A Patiala unit records Jute sack : Jute and Leather belt : Leather. Which proposed entry breaks this product-to-raw-material relation?

    1. Glass bottle : Glassblower
    2. Cotton towel : Cotton
    3. Rubber tyre : Rubber
    4. Woollen shawl : Wool
    Show answer

    Answer: (A) Glass bottle : Glassblower

    Explanation: Glassblower names the worker, not the raw material of a glass bottle. The other entries name the material used.

  18. The alphabet rule is one place backward for every letter. If FKP becomes EJO, what does MQT become?

    1. LPS
    2. MPS
    3. LQS
    4. NRU
    Show answer

    Answer: (A) LPS

    Explanation: Move M→L, Q→P and T→S. The required group is LPS.

  19. Both links must express a rise in intensity without changing the underlying feeling: Annoyance : Rage :: X : Y. Which pair satisfies both conditions?

    1. Delight : Contentment
    2. Fury : Irritation
    3. Grief : Happiness
    4. Unease : Terror
    Show answer

    Answer: (D) Unease : Terror

    Explanation: Rage is much stronger anger than annoyance. Terror similarly intensifies the fear present in unease; the other pairs weaken or change the feeling.

  20. Jasleen’s cards show 12 : 9 and 16 : 13. The rule first squares the input and then uses its digits. What should be paired with 14?

    1. 54
    2. 5
    3. 16
    4. 196
    Show answer

    Answer: (C) 16

    Explanation: Add the digits of the square: 12²=144 gives 1+4+4=9, and 16²=256 gives 2+5+6=13. Thus 14²=196 gives 1+9+6=16.

  21. Choose the relation that matches Keyboard key : Keyboard while keeping the first item a physical component of the second.

    1. Driver : Vehicle
    2. Battery charger : Battery
    3. Blueprint : Building
    4. Turbine blade : Turbine
    Show answer

    Answer: (D) Turbine blade : Turbine

    Explanation: A key is a component of a keyboard, just as a blade is a component of a turbine. User, plan and accessory relations do not fit.

  22. The number pairs (5, 35), (9, 99) and (6, 48) follow a common product rule. Which further pair fits without splitting digits?

    1. (11, 132)
    2. (10, 100)
    3. (12, 168)
    4. (8, 72)
    Show answer

    Answer: (C) (12, 168)

    Explanation: Use n(n+2): 5×7=35 and 9×11=99. The matching pair is 12×14=168.

  23. A ledger uses the code changes D16 → W4 and J100 → Q10. Identify the matching output for N196; letter and number operations are independent.

    1. L14
    2. M14
    3. N14
    4. M98
    Show answer

    Answer: (B) M14

    Explanation: Replace the letter with its opposite and take the positive square root of the number. N is opposite M, and √196=14, giving M14.

  24. Only the order is reversed in CFJM : MJFC. Apply that relation to RUVX.

    1. XUVR
    2. URXV
    3. XVUR
    4. RVUX
    Show answer

    Answer: (C) XVUR

    Explanation: Read RUVX from right to left: X, V, U, R.

  25. Three entries use the same cube-to-cube-root relation: 216 : 6; 1000 : 10; 2744 : X. Find X.

    1. 14
    2. 12
    3. 16
    4. 13
    Show answer

    Answer: (A) 14

    Explanation: The output is the cube root: 14×14×14=2744. Thus X=14.
