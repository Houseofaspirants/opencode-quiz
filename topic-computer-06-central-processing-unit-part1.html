Question bank

Central Processing Unit - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. Which component is often called the 'Brain of the Computer'?

    1. CPU
    2. Monitor
    3. Hard Disk
    4. Keyboard
    Show answer

    Answer: (A) CPU

    Explanation: The CPU is called the Brain of the Computer because it controls and performs almost all processing operations.

  2. CPU stands for:

    1. Central Program Unit
    2. Control Processing Unit
    3. Central Processing Unit
    4. Computer Processing Unit
    Show answer

    Answer: (C) Central Processing Unit

    Explanation: CPU stands for Central Processing Unit.

  3. Which of the following is NOT another name for the CPU?

    1. Motherboard
    2. Processor
    3. Central Processor
    4. Microprocessor
    Show answer

    Answer: (A) Motherboard

    Explanation: The CPU is also known as Processor, Central Processor or Microprocessor; the motherboard holds the CPU socket.

  4. Converting raw data into meaningful information is which function of the CPU?

    1. Executing instructions
    2. Managing input and output devices
    3. Running software
    4. Processing data
    Show answer

    Answer: (D) Processing data

    Explanation: Under 'Processes Data', the CPU converts raw data into meaningful information.

  5. The CPU is installed in a special socket called the CPU Socket, which is located on the:

    1. Hard Disk
    2. RAM module
    3. Motherboard
    4. Monitor
    Show answer

    Answer: (C) Motherboard

    Explanation: The CPU Socket that holds the CPU is located on the Motherboard.

  6. Which was the world's first microprocessor?

    1. Intel 4004
    2. Intel 8086
    3. Intel Core i3
    4. AMD Ryzen 3
    Show answer

    Answer: (A) Intel 4004

    Explanation: The world's first microprocessor was the Intel 4004, developed by Intel Corporation.

  7. In which year was the Intel 4004 microprocessor introduced?

    1. 1969
    2. 1971
    3. 1975
    4. 1981
    Show answer

    Answer: (B) 1971

    Explanation: Intel 4004 was developed by Intel Corporation in 1971.

  8. The CPU mainly consists of:

    1. Control Unit, ALU and Hard Disk
    2. ALU, Monitor and Registers
    3. Control Unit, Keyboard and ALU
    4. Control Unit, ALU and Registers
    Show answer

    Answer: (D) Control Unit, ALU and Registers

    Explanation: The main components of the CPU are the Control Unit (CU), Arithmetic Logic Unit (ALU) and Registers (Memory Unit).

  9. Which part of the CPU controls and coordinates all operations of the computer?

    1. Arithmetic Logic Unit (ALU)
    2. Registers
    3. Control Unit (CU)
    4. CPU Socket
    Show answer

    Answer: (C) Control Unit (CU)

    Explanation: The Control Unit controls and coordinates all operations of the computer (CU = Controls Everything).

  10. The Control Unit is compared to which of the following, directing the flow of information inside the computer?

    1. A Traffic Police Officer
    2. A Calculator
    3. A Librarian
    4. A Postman
    Show answer

    Answer: (A) A Traffic Police Officer

    Explanation: The Control Unit acts like a Traffic Police Officer directing the flow of information inside the computer.

  11. Which function of the Control Unit ensures that instructions are executed in the correct order?

    1. Decodes Instructions
    2. Maintains Instruction Sequence
    3. Generates Control Signals
    4. Controls Data Flow
    Show answer

    Answer: (B) Maintains Instruction Sequence

    Explanation: 'Maintains Instruction Sequence' ensures instructions are executed in the correct order.

  12. Converting instructions into understandable signals is which function of the Control Unit?

    1. Coordinating operations
    2. Maintaining instruction sequence
    3. Storing results
    4. Decoding instructions
    Show answer

    Answer: (D) Decoding instructions

    Explanation: Under 'Decodes Instructions', the CU converts instructions into understandable signals.

  13. The Program Counter (PC) stores:

    1. The result of the last calculation
    2. The address of the next instruction
    3. The opcode of the current instruction
    4. The clock speed of the CPU
    Show answer

    Answer: (B) The address of the next instruction

    Explanation: The Program Counter stores the address of the next instruction.

  14. During decoding, what does the Opcode tell the CPU?

    1. On which data the operation should be performed
    2. What operation must be performed
    3. Where the result must be stored
    4. The address of the next instruction
    Show answer

    Answer: (B) What operation must be performed

    Explanation: Opcode tells the CPU what operation must be performed; Operand tells on which data it is performed.

  15. Which part of the CPU performs arithmetic and logical operations?

    1. Control Unit
    2. Program Counter
    3. ALU
    4. CPU Socket
    Show answer

    Answer: (C) ALU

    Explanation: The Arithmetic Logic Unit (ALU) performs arithmetic and logical operations; it is the calculator and decision-maker of the CPU.

  16. When the ALU checks whether '50 > 30' is true or false, it is performing a:

    1. Arithmetic operation
    2. Fetch operation
    3. Storage operation
    4. Logical operation
    Show answer

    Answer: (D) Logical operation

    Explanation: Comparisons such as Greater Than (>) are logical operations performed by the ALU.

  17. According to the CU vs ALU comparison, which statement is correct?

    1. CU processes data, while ALU does not
    2. Both CU and ALU process data
    3. CU does not process data, while ALU does
    4. Neither CU nor ALU processes data
    Show answer

    Answer: (C) CU does not process data, while ALU does

    Explanation: Data processing: Control Unit – No, ALU – Yes; CU is the supervisor and ALU the calculator.

  18. Which is the fastest memory in a computer?

    1. Hard Disk
    2. Registers
    3. RAM
    4. Pen Drive
    Show answer

    Answer: (B) Registers

    Explanation: Exam Point: Registers are the fastest memory in a computer; they are very small, very fast memory locations inside the CPU.

  19. The register abbreviated as MAR stands for:

    1. Main Access Register
    2. Memory Arithmetic Register
    3. Machine Address Register
    4. Memory Address Register
    Show answer

    Answer: (D) Memory Address Register

    Explanation: Examples of registers include PC, IR, MAR (Memory Address Register) and MDR (Memory Data Register).

  20. The clock speed of modern CPUs is measured in:

    1. Gigahertz (GHz)
    2. Megabytes (MB)
    3. Dots Per Inch (DPI)
    4. Pages Per Minute (PPM)
    Show answer

    Answer: (A) Gigahertz (GHz)

    Explanation: The unit of clock speed is Hertz (Hz); modern CPUs are measured in Gigahertz (GHz).

  21. A processor running at 4.0 GHz can perform approximately how many clock cycles per second?

    1. 4 million
    2. 4 thousand
    3. 40 billion
    4. 4 billion
    Show answer

    Answer: (D) 4 billion

    Explanation: A 4.0 GHz processor performs approximately 4 billion clock cycles per second.

  22. A CPU with 6 cores is called:

    1. Hexa-Core
    2. Quad-Core
    3. Octa-Core
    4. Dual-Core
    Show answer

    Answer: (A) Hexa-Core

    Explanation: Single-Core 1, Dual-Core 2, Quad-Core 4, Hexa-Core 6, Octa-Core 8 cores.

  23. The Instruction Cycle is also called the:

    1. Fetch-Decode-Execute Cycle
    2. Input-Output Cycle
    3. Clock-Core Cycle
    4. Read-Write Cycle
    Show answer

    Answer: (A) Fetch-Decode-Execute Cycle

    Explanation: The Instruction Cycle, the sequence of operations to execute an instruction, is also called the Fetch-Decode-Execute Cycle.

  24. In the fetch step of the Instruction Cycle, the fetched instruction is stored in the:

    1. MDR (Memory Data Register)
    2. CIR (Current Instruction Register)
    3. ALU
    4. CPU Socket
    Show answer

    Answer: (B) CIR (Current Instruction Register)

    Explanation: In the fetch step, the instruction is fetched from main memory and stored in the CIR (Current Instruction Register).

  25. Ryzen 3, Ryzen 5, Ryzen 7 and Ryzen 9 processors are made by:

    1. Intel
    2. IBM
    3. AMD
    4. Apple
    Show answer

    Answer: (C) AMD

    Explanation: Intel (Core i3, i5, i7, i9) and AMD (Ryzen 3, 5, 7, 9) are the two most popular CPU manufacturers.
