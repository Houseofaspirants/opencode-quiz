Question bank

Decimal Fractions MCQ – Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. What is the place value of 8 in 14.3086?

    1. 0.0008
    2. 8
    3. 0.008
    4. 0.08
    Show answer

    Answer: (C) 0.008

    Explanation: The digit 8 is in the thousandths place, so its value is 8/1000 = 0.008.

  2. Find x: 18.75 − 4.625 + x = 20.5.

    1. 6.375
    2. 10.375
    3. 1.75
    4. 5.375
    Show answer

    Answer: (A) 6.375

    Explanation: x = 20.5 − 18.75 + 4.625 = 6.375.

  3. If x = 0.2(45), where 45 repeats, find 330x.

    1. 80
    2. 75
    3. 245
    4. 81
    Show answer

    Answer: (D) 81

    Explanation: x = (245 − 2)/990 = 27/110, so 330x = 81.

  4. Which is the second largest of 0.72, 5/7, 0.725 and 29/41?

    1. 0.725
    2. 0.72
    3. 29/41
    4. 5/7
    Show answer

    Answer: (B) 0.72

    Explanation: 29/41 < 5/7 < 0.72 < 0.725, so the second largest is 0.72.

  5. What is 0.0476 × 1000?

    1. 47.6
    2. 0.476
    3. 4.76
    4. 476
    Show answer

    Answer: (A) 47.6

    Explanation: Multiplying by 1000 shifts the decimal point 3 places right: 0.0476 × 1000 = 47.6.

  6. Evaluate 7.2 ÷ 0.09 − 2.5 × 12.

    1. 770
    2. 77.5
    3. 50
    4. 20
    Show answer

    Answer: (C) 50

    Explanation: 7.2 ÷ 0.09 = 80 and 2.5 × 12 = 30, so the result is 50.

  7. Evaluate (3.84² − 1.16²) ÷ 0.268.

    1. 5
    2. 50
    3. 25
    4. 10
    Show answer

    Answer: (B) 50

    Explanation: Use the difference of squares: (3.84 + 1.16)(3.84 − 1.16) ÷ 0.268 = 5 × 2.68 ÷ 0.268 = 50.

  8. A shop in Ludhiana has 18.9 kg of rice. It packs all of it into packets of 0.45 kg each. How many packets are made?

    1. 84
    2. 4.2
    3. 45
    4. 42
    Show answer

    Answer: (D) 42

    Explanation: Number of packets = 18.9 ÷ 0.45 = 1890 ÷ 45 = 42.

  9. Express 0.0625 as a percentage.

    1. 0.625
    2. 62.5
    3. 0.0625
    4. 6.25
    Show answer

    Answer: (D) 6.25

    Explanation: Percentage = 0.0625 × 100 = 6.25%.

  10. When 0.0875 is reduced to its lowest fractional form, what is the sum of its numerator and denominator?

    1. 47
    2. 87
    3. 79
    4. 807
    Show answer

    Answer: (B) 87

    Explanation: 0.0875 = 875/10000 = 7/80, so the required sum is 7 + 80 = 87.

  11. Which fraction is closest to 0.65?

    1. 11/17
    2. 13/21
    3. 15/23
    4. 17/25
    Show answer

    Answer: (C) 15/23

    Explanation: The gap between 15/23 and 0.65 is 1/460; the gaps for 13/21, 17/25 and 11/17 are 13/420, 3/100 and 1/340. The smallest gap is 1/460.

  12. Evaluate 0.48 × 2.5 + 0.84 ÷ 0.7.

    1. 2.4
    2. 1.32
    3. 0.24
    4. 3.3
    Show answer

    Answer: (A) 2.4

    Explanation: 0.48 × 2.5 = 1.2 and 0.84 ÷ 0.7 = 1.2, so their sum is 2.4.

  13. Write 0.(63), where 63 repeats, as a fraction in lowest terms.

    1. 21/11
    2. 7/11
    3. 7/9
    4. 63/100
    Show answer

    Answer: (B) 7/11

    Explanation: 0.(63) = 63/99 = 7/11.

  14. Which power of 10 must multiply 0.000384 to give 38.4?

    1. 10^3
    2. 10^4
    3. 10^6
    4. 10^5
    Show answer

    Answer: (D) 10^5

    Explanation: The decimal point moves 5 places right, so the multiplier is 10^5.

  15. For a = 0.72 and b = 0.28, evaluate (a³ + b³) ÷ (a² − ab + b²) + ab.

    1. 1.2016
    2. 0.7984
    3. 1.4032
    4. 0.6416
    Show answer

    Answer: (A) 1.2016

    Explanation: The quotient is a + b = 1, so the result is 1 + 0.72 × 0.28 = 1.2016.

  16. Which number lies strictly between 0.58 and 7/12?

    1. 0.58
    2. 0.59
    3. 0.582
    4. 0.584
    Show answer

    Answer: (C) 0.582

    Explanation: 7/12 = 0.58333 recurring, so 0.58 < 0.582 < 7/12.

  17. Which fraction is equal to 0.0032?

    1. 1/3125
    2. 2/125
    3. 2/625
    4. 4/125
    Show answer

    Answer: (C) 2/625

    Explanation: 0.0032 = 32/10000 = 2/625.

  18. Find x: 0.036 ÷ x = 1.2 ÷ 0.5.

    1. 0.015
    2. 0.15
    3. 0.0864
    4. 0.0015
    Show answer

    Answer: (A) 0.015

    Explanation: The right side is 2.4, so x = 0.036 ÷ 2.4 = 0.015.

  19. Harpreet buys 2.4 kg of almonds at ₹375.50 per kg and 1.6 kg of raisins at ₹124.50 per kg. How much change does he receive from ₹1200?

    1. 101.6
    2. 199.6
    3. 100.4
    4. 99.6
    Show answer

    Answer: (D) 99.6

    Explanation: Cost = 2.4 × 375.50 + 1.6 × 124.50 = 1100.4, so change = 1200 − 1100.4 = ₹99.6.

  20. If x = 0.1(6) and y = 0.(18), where the bracketed digits repeat, find x ÷ y.

    1. 11/6
    2. 11/12
    3. 12/11
    4. 1/12
    Show answer

    Answer: (B) 11/12

    Explanation: x = 1/6 and y = 18/99 = 2/11, so x ÷ y = 1/6 × 11/2 = 11/12.

  21. Which is the greatest of the following numbers?

    1. 0.807
    2. 4/5
    3. 0.8007
    4. 0.0787
    Show answer

    Answer: (A) 0.807

    Explanation: 4/5 = 0.8; comparing decimal places gives 0.807 as the greatest.

  22. Evaluate 6.4 − [2.8 − {0.72 ÷ (1.1 − 0.5)}].

    1. 3.6
    2. 6
    3. 4.8
    4. 2.4
    Show answer

    Answer: (C) 4.8

    Explanation: Work inward: 1.1 − 0.5 = 0.6 and 0.72 ÷ 0.6 = 1.2; hence 6.4 − (2.8 − 1.2) = 4.8.

  23. To the nearest whole number, estimate 119.8 × 0.503 ÷ 0.199.

    1. 3
    2. 303
    3. 30
    4. 3000
    Show answer

    Answer: (B) 303

    Explanation: Use 120 × 0.5 ÷ 0.2 = 300 as a starting estimate; the actual quotient is about 302.811, which rounds to 303.

  24. A positive number is multiplied by 0.8 and then by 1.25. What is the overall multiplier?

    1. 1.05
    2. 2.05
    3. 0.1
    4. 1
    Show answer

    Answer: (D) 1

    Explanation: Overall multiplier = 0.8 × 1.25 = 4/5 × 5/4 = 1.

  25. If a + b = 1.5 and ab = 0.44, find a³ + b³.

    1. 1.395
    2. 2.715
    3. 5.355
    4. 3.375
    Show answer

    Answer: (A) 1.395

    Explanation: a³ + b³ = (a + b)³ − 3ab(a + b) = 1.5³ − 3 × 0.44 × 1.5 = 1.395.
