All about Punjab GK

Where this lane sits inside General Knowledge.

Punjab GK is the section that makes a state exam a state exam. Districts and rivers, fairs and festivals, personalities and awards, the state's history and its recent decisions - all of it is short-form, all of it is repeated, and all of it is forgettable if you only read it once.

The working method is a daily set plus a one-line correction file. Attempt, read the explanation, write down only what you missed, and revise that file weekly. Within a month the file becomes shorter than the questions you already know.

This lane sits inside General Knowledge (6 lanes in total), so it stays narrow on purpose: 0 topic sets and 0 questions currently publish under Punjab GK. Every question is timed at 30 seconds, carries four options and explains why the right answer is right.

Run a set untimed first to find the gaps, then repeat it against the clock. The questions you miss twice are your revision list - keep them to one line each and revise the file the night before the paper.
