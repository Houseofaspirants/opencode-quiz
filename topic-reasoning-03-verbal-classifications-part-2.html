Question bank

Verbal Classifications MCQ – Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. Read the alphabet gaps from left to right. Three groups have gaps 1, 2 and 3. Which does not?

    1. KLNR
    2. FGIL
    3. ABDG
    4. PQSV
    Show answer

    Answer: (A) KLNR

    Explanation: KLNR has gaps 1, 2 and 4. The other three groups have gaps 1, 2 and 3.

  2. A grocer makes a group consisting only of pulses. Which item needs a different label?

    1. Pigeon pea
    2. Chickpea
    3. Lentil
    4. Sorghum
    Show answer

    Answer: (D) Sorghum

    Explanation: Sorghum is a cereal. Lentil, chickpea and pigeon pea are pulses.

  3. Manpreet applies one common multiply-then-add rule to the first number of each pair. Which pair cannot belong to the other three?

    1. 19 : 59
    2. 12 : 38
    3. 16 : 52
    4. 7 : 23
    Show answer

    Answer: (C) 16 : 52

    Explanation: The common rule is y = 3x + 2. For 16 it gives 3 × 16 + 2 = 50, not 52; the other pairs fit.

  4. Navjot needs a material that allows electric current to pass readily. Three fit; which should she reject?

    1. Copper
    2. Aluminium
    3. Graphite
    4. Porcelain
    Show answer

    Answer: (D) Porcelain

    Explanation: Porcelain is an electrical insulator. Graphite, aluminium and copper conduct electricity.

  5. Of these four parcel codes, identify the one that is not a perfect cube of a whole number.

    1. 5832
    2. 1728
    3. 4098
    4. 2744
    Show answer

    Answer: (C) 4098

    Explanation: 1728 = 12³, 2744 = 14³ and 5832 = 18³. Since 16³ = 4096, 4098 is not a perfect cube.

  6. Within each group, pair the first letter with the second and the third with the fourth. Which group contains a pair that is not alphabetically opposite?

    1. EVLO
    2. GTMN
    3. CXJP
    4. IRFU
    Show answer

    Answer: (C) CXJP

    Explanation: Opposite positions add to 27. In CXJP, J + P = 10 + 16 = 26; every pair in the other groups totals 27.

  7. Three pairs link an institution with the people it primarily serves. Which pair links an institution with its workers instead?

    1. Prison : Inmates
    2. Hospital : Nurses
    3. Orphanage : Orphans
    4. School : Pupils
    Show answer

    Answer: (B) Hospital : Nurses

    Explanation: Nurses work in a hospital; its primary recipients of care are patients. The other pairs name the institutions' residents or learners.

  8. Among these animals, which lies outside the reptile class?

    1. Salamander
    2. Gecko
    3. Crocodile
    4. Tortoise
    Show answer

    Answer: (A) Salamander

    Explanation: A salamander is an amphibian. A gecko, crocodile and tortoise are reptiles.

  9. Apply the alternating-digit-sum test for divisibility by 11. Which number fails?

    1. 8602
    2. 6315
    3. 4213
    4. 5720
    Show answer

    Answer: (B) 6315

    Explanation: For 6315, (6 + 1) − (3 + 5) = −1, which is not a multiple of 11. The other alternating-sum differences are 0, 0 and 0.

  10. Compare each three-digit number with the number after the colon. Which pair does not show complete digit reversal?

    1. 846 : 648
    2. 472 : 724
    3. 591 : 195
    4. 368 : 863
    Show answer

    Answer: (B) 472 : 724

    Explanation: Reversing 472 gives 274, not 724. The other second numbers are exact reversals.

  11. An alphabetical check requires every letter to lie before the previous one. Which group fails this descending-order check?

    1. YVPL
    2. ZTRK
    3. XUOH
    4. WQSM
    Show answer

    Answer: (D) WQSM

    Explanation: In WQSM, Q to S moves forward rather than backward. Every step in the other groups moves towards A.

  12. A gardener groups plants by reproduction through spores rather than seeds. Which plant is misplaced?

    1. Moss
    2. Fern
    3. Pine
    4. Horsetail
    Show answer

    Answer: (C) Pine

    Explanation: Pine produces seeds in cones. Ferns, mosses and horsetails reproduce through spores.

  13. Compare the ratios within these number pairs. Which pair does not share the common simplified ratio?

    1. 52 : 93
    2. 44 : 77
    3. 28 : 49
    4. 68 : 119
    Show answer

    Answer: (A) 52 : 93

    Explanation: 52 × 7 = 364, while 93 × 4 = 372. Each other pair satisfies 7 × first = 4 × second.

  14. Four unit names are listed. Which is a derived SI unit rather than an SI base unit?

    1. Mole
    2. Candela
    3. Kelvin
    4. Pascal
    Show answer

    Answer: (D) Pascal

    Explanation: Pascal is a derived unit of pressure, equal to newton per square metre. Kelvin, mole and candela are base units.

  15. Only one number has its middle digit different from the product of its outer digits. Find it.

    1. 284
    2. 263
    3. 354
    4. 393
    Show answer

    Answer: (C) 354

    Explanation: For 354, 3 × 4 = 12, not 5. The other products are 2 × 3 = 6, 2 × 4 = 8 and 3 × 3 = 9, matching their middle digits.

  16. The format is XYXY, obtained by repeating a two-letter block. Which code was written in another format?

    1. DHDH
    2. LLPP
    3. MVMV
    4. RWRW
    Show answer

    Answer: (B) LLPP

    Explanation: LLPP repeats each letter beside itself, an XXYY pattern. The other codes repeat a two-letter block.

  17. Select the pair that differs when the relationship is whole followed by one of its constituent parts.

    1. Wheel : Spoke
    2. Flower : Petal
    3. Book : Chapter
    4. Library : Librarian
    Show answer

    Answer: (D) Library : Librarian

    Explanation: A librarian is a person working in a library, not a constituent part of the object. Chapters, spokes and petals are parts of the named wholes.

  18. Simran separates objects by whether they normally form a real image on a screen. Which optical device cannot do this for a real object?

    1. Convex lens
    2. Plane mirror
    3. Pinhole camera
    4. Concave mirror
    Show answer

    Answer: (B) Plane mirror

    Explanation: A plane mirror forms a virtual image of a real object. The other devices can form a real image on a screen under suitable conditions.

  19. Take A = 1 to Z = 26. In three groups the last position is the sum of the first two. Which group fails?

    1. ILU
    2. GJS
    3. FHN
    4. CDG
    Show answer

    Answer: (B) GJS

    Explanation: G + J = 7 + 10 = 17, which is Q rather than S. The other sums are 3 + 4 = 7, 6 + 8 = 14 and 9 + 12 = 21.

  20. A number qualifies if it is divisible by the sum of its digits. Which number does not qualify?

    1. 248
    2. 192
    3. 240
    4. 156
    Show answer

    Answer: (A) 248

    Explanation: 248 has digit sum 14, but 248 = 14 × 17 + 10. The other numbers divide exactly by their digit sums: 156/12 = 13, 192/12 = 16 and 240/6 = 40.

  21. Which shape is outside the group of polygons, even though it is a closed plane figure?

    1. Rhombus
    2. Pentagon
    3. Trapezium
    4. Ellipse
    Show answer

    Answer: (D) Ellipse

    Explanation: An ellipse has a curved boundary. A polygon is bounded entirely by straight line segments.

  22. A pair links a perfect square with the cube of the same positive integer. Which pair breaks this link?

    1. 144 : 1728
    2. 256 : 4106
    3. 81 : 729
    4. 196 : 2744
    Show answer

    Answer: (B) 256 : 4106

    Explanation: 256 = 16², so its partner must be 16³ = 4096, not 4106. The other pairs use bases 9, 12 and 14.

  23. A nutrition chart groups food components that can supply usable energy to the human body. Which component is outside that group?

    1. Water
    2. Protein
    3. Carbohydrate
    4. Fat
    Show answer

    Answer: (A) Water

    Explanation: Water provides no calories. Carbohydrates, fats and proteins can supply energy.

  24. Keep only groups that alternate consonant, vowel, consonant, vowel. Which group must be deleted?

    1. NIPI
    2. KOTA
    3. FARK
    4. BEMU
    Show answer

    Answer: (C) FARK

    Explanation: FARK ends in a consonant, K, instead of a vowel. The other groups follow consonant–vowel–consonant–vowel.

  25. A qualifying value has the form n(n + 1)/2 for a positive integer n. Which value cannot qualify?

    1. 97
    2. 91
    3. 66
    4. 120
    Show answer

    Answer: (A) 97

    Explanation: 66 = 11 × 12/2, 91 = 13 × 14/2 and 120 = 15 × 16/2. Since 91 < 97 < 105, 97 lies between consecutive such values.
