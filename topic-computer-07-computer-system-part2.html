Question bank

Computer System - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. SMPS, the Power Supply Unit of a computer, stands for:

    1. Switched Mode Power Supply
    2. System Main Power Supply
    3. Single Mode Power Source
    4. Switched Memory Power System
    Show answer

    Answer: (A) Switched Mode Power Supply

    Explanation: SMPS = Switched Mode Power Supply, the Power Supply Unit of the computer.

  2. A microphone is an input device that converts:

    1. Electrical signals into sound
    2. AC power into DC power
    3. Sound waves into electrical signals
    4. Images into digital data
    Show answer

    Answer: (C) Sound waves into electrical signals

    Explanation: A Microphone is an input device that converts sound waves into electrical signals.

  3. Who is credited as the inventor of the microphone in the chapter?

    1. David S. Lee
    2. Alexander Graham Bell
    3. Thomas Edison
    4. Emile Berliner
    Show answer

    Answer: (D) Emile Berliner

    Explanation: The microphone's inventor is given as Emile Berliner (1877).

  4. In which year did Emile Berliner invent the microphone?

    1. 1871
    2. 1877
    3. 1887
    4. 1897
    Show answer

    Answer: (B) 1877

    Explanation: Microphone – Inventor: Emile Berliner in 1877.

  5. A Pen Drive (USB Flash Drive) uses which memory technology?

    1. Flash memory
    2. Magnetic tape
    3. Optical disc
    4. CMOS memory
    Show answer

    Answer: (A) Flash memory

    Explanation: Exam Point: Pen Drive uses Flash Memory Technology.

  6. Which of the following is NOT a feature of a USB Flash Drive?

    1. Portable
    2. Rewritable
    3. USB interface
    4. Read-only (cannot be rewritten)
    Show answer

    Answer: (D) Read-only (cannot be rewritten)

    Explanation: Features of a USB Flash Drive are: Portable, Rewritable and USB Interface.

  7. Which of the following is a type of memory card?

    1. SATA Card
    2. MicroSD Card
    3. AGP Card
    4. PCI Card
    Show answer

    Answer: (B) MicroSD Card

    Explanation: Types of memory cards: SD Card, MicroSD Card and MiniSD Card.

  8. Connection points on a computer where external devices are connected, acting like 'gates' for data, are called:

    1. Ports
    2. Registers
    3. Chipsets
    4. Heat sinks
    Show answer

    Answer: (A) Ports

    Explanation: Ports are connection points where external devices are connected; they act like gates through which data enters or leaves.

  9. USB stands for:

    1. Universal System Bus
    2. Unique Serial Bus
    3. United Serial Board
    4. Universal Serial Bus
    Show answer

    Answer: (D) Universal Serial Bus

    Explanation: USB = Universal Serial Bus; it is the most common port, used for keyboard, mouse, printer, pen drive and scanner.

  10. PATA, an older hard disk port using parallel data transfer, stands for:

    1. Parallel Advanced Technology Attachment
    2. Primary Advanced Technology Adapter
    3. Parallel Access Transfer Architecture
    4. Peripheral Advanced Technology Attachment
    Show answer

    Answer: (A) Parallel Advanced Technology Attachment

    Explanation: PATA = Parallel Advanced Technology Attachment; older technology with parallel data transfer.

  11. In modern computers, SATA has replaced:

    1. USB
    2. PATA
    3. HDMI
    4. VGA
    Show answer

    Answer: (B) PATA

    Explanation: Exam Point: SATA replaced PATA in modern computers; SATA is faster than PATA.

  12. SATA, used for hard disks, stands for:

    1. System Advanced Technology Adapter
    2. Serial Access Transfer Architecture
    3. Standard Advanced Technology Attachment
    4. Serial Advanced Technology Attachment
    Show answer

    Answer: (D) Serial Advanced Technology Attachment

    Explanation: SATA = Serial Advanced Technology Attachment; it is used for hard disks.

  13. Which hard disk port/interface is used in servers and high-performance storage systems?

    1. PS/2
    2. SCSI (Small Computer System Interface)
    3. VGA
    4. Serial Port
    Show answer

    Answer: (B) SCSI (Small Computer System Interface)

    Explanation: SCSI (Small Computer System Interface) is used in servers and high-performance storage systems.

  14. Which port transfers multiple bits simultaneously and is used for printers and scanners?

    1. Serial Port
    2. Ethernet Port
    3. HDMI Port
    4. Parallel Port
    Show answer

    Answer: (D) Parallel Port

    Explanation: A Parallel Port transfers multiple bits simultaneously and is used for printers and scanners.

  15. A serial port transfers data:

    1. Multiple bits at once
    2. Eight bytes at a time
    3. One bit at a time
    4. Only audio and video together
    Show answer

    Answer: (C) One bit at a time

    Explanation: A Serial Port transfers data one bit at a time and is used for modems, projectors and older communication devices.

  16. The PS/2 port is used to connect:

    1. Monitor and Projector
    2. Hard Disk
    3. Internet (LAN)
    4. Keyboard and Mouse
    Show answer

    Answer: (D) Keyboard and Mouse

    Explanation: Exam Point: PS/2 Port = Mouse and Keyboard Connection.

  17. The PS/2 port was developed by:

    1. Apple
    2. IBM
    3. Intel
    4. AMD
    Show answer

    Answer: (B) IBM

    Explanation: The PS/2 (Personal System/2) port was developed by IBM.

  18. VGA, the port used for monitors, stands for:

    1. Video Graphics Array
    2. Visual Graphics Adapter
    3. Video Gaming Array
    4. Virtual Graphics Access
    Show answer

    Answer: (A) Video Graphics Array

    Explanation: VGA = Video Graphics Array; it connects monitors and projectors.

  19. Which type of signal does a VGA port carry?

    1. Digital audio and video signal
    2. Network data signal
    3. Analog video signal
    4. Power signal
    Show answer

    Answer: (C) Analog video signal

    Explanation: VGA port carries an Analog Video Signal.

  20. Which port transfers both audio and video through a single cable?

    1. VGA
    2. HDMI
    3. PS/2
    4. Ethernet
    Show answer

    Answer: (B) HDMI

    Explanation: Exam Point: HDMI carries both Audio and Video through a single cable.

  21. HDMI stands for:

    1. High Digital Media Input
    2. Hybrid Definition Multimedia Interface
    3. High Definition Multimedia Interface
    4. High Density Media Interconnect
    Show answer

    Answer: (C) High Definition Multimedia Interface

    Explanation: HDMI = High Definition Multimedia Interface.

  22. The FireWire port, used for high-speed data transfer, was developed by:

    1. Apple
    2. IBM
    3. Intel
    4. Microsoft
    Show answer

    Answer: (A) Apple

    Explanation: FireWire port was developed by Apple and is used for high-speed data transfer, digital cameras and external storage.

  23. FireWire is also known as:

    1. IEEE 1394
    2. IEEE 802.3
    3. IEEE 1284
    4. IEEE 802.11
    Show answer

    Answer: (A) IEEE 1394

    Explanation: FireWire's other name is IEEE 1394.

  24. The Ethernet port, used for connecting computers to a network, is also called:

    1. VGA Port
    2. PS/2 Port
    3. LAN Port
    4. AGP Port
    Show answer

    Answer: (C) LAN Port

    Explanation: Exam Point: Ethernet Port = LAN Port; used for internet connection and Local Area Network.

  25. Which component controls communication between the CPU, RAM, storage devices and expansion cards?

    1. Heat Sink
    2. CMOS Battery
    3. Chipset
    4. Power Connector
    Show answer

    Answer: (C) Chipset

    Explanation: A chipset controls communication between the CPU, RAM, storage devices and expansion cards.
