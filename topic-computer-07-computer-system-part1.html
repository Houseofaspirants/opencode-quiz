Question bank

Computer System - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. A computer system consists of which two main components?

    1. Hardware and Software
    2. Input and Output
    3. CPU and Monitor
    4. RAM and ROM
    Show answer

    Answer: (A) Hardware and Software

    Explanation: A computer system consists of two main components: Hardware and Software, which work together to perform tasks.

  2. The physical and tangible components of a computer that can be seen and touched are called:

    1. Software
    2. Firmware
    3. Data
    4. Hardware
    Show answer

    Answer: (D) Hardware

    Explanation: Hardware refers to all physical and tangible components of a computer system that can be seen and touched.

  3. Which of the following is an example of hardware?

    1. MS Word
    2. Web Browser
    3. Operating System
    4. Hard Disk
    Show answer

    Answer: (D) Hard Disk

    Explanation: Monitor, Keyboard, Mouse, CPU, Motherboard, RAM, ROM, Hard Disk, Printer and Speakers are examples of hardware.

  4. According to the Hardware vs Software comparison, which feature belongs to software?

    1. Cannot be physically damaged
    2. Subject to physical damage
    3. Can be touched
    4. Consists of physical components
    Show answer

    Answer: (A) Cannot be physically damaged

    Explanation: Software consists of programs and instructions, cannot be touched and cannot be physically damaged.

  5. In the Hardware vs Software table, which of these is given as an example of software?

    1. Keyboard
    2. Monitor
    3. MS Word
    4. Printer
    Show answer

    Answer: (C) MS Word

    Explanation: The table gives Keyboard as an example of hardware and MS Word as an example of software.

  6. The main circuit board of a computer that connects and holds together almost all internal hardware components is the:

    1. Expansion Card
    2. Heat Sink
    3. SMPS
    4. Motherboard
    Show answer

    Answer: (D) Motherboard

    Explanation: The Motherboard is the main circuit board that connects and holds almost all internal hardware components.

  7. Which of the following is another name for the motherboard?

    1. Expansion Board
    2. Sound Board
    3. System Board
    4. Network Board
    Show answer

    Answer: (C) System Board

    Explanation: Other names of the motherboard are Mainboard, System Board and Printed Circuit Board (PCB).

  8. The motherboard is also known as PCB. PCB stands for:

    1. Primary Circuit Board
    2. Power Control Board
    3. Printed Circuit Board
    4. Processor Connection Board
    Show answer

    Answer: (C) Printed Circuit Board

    Explanation: Motherboard is also known as PCB – Printed Circuit Board.

  9. Which component is called the 'Heart' or 'Backbone' of the computer system?

    1. Motherboard
    2. CPU
    3. Monitor
    4. Hard Disk
    Show answer

    Answer: (A) Motherboard

    Explanation: Important Exam Point: Motherboard = Heart/Backbone of Computer System.

  10. The motherboard acts as the ________ of the computer.

    1. Power generator
    2. Permanent storage
    3. Display unit
    4. Communication center
    Show answer

    Answer: (D) Communication center

    Explanation: The motherboard acts as the communication center of the computer.

  11. Which of the following is listed as a function of the motherboard?

    1. Converts AC power into DC power
    2. Houses the CPU by providing a socket for the processor
    3. Converts sound waves into electrical signals
    4. Stores data permanently using flash memory
    Show answer

    Answer: (B) Houses the CPU by providing a socket for the processor

    Explanation: Functions of the motherboard: connects all hardware, supplies power, enables communication and houses the CPU.

  12. Memory slots on the motherboard are mainly used for installing:

    1. Graphics cards
    2. RAM modules
    3. The SMPS
    4. The CMOS battery
    Show answer

    Answer: (B) RAM modules

    Explanation: Memory slots are used for installing memory modules such as RAM (and ROM modules in some systems).

  13. Expansion slots on a motherboard are used to:

    1. Store BIOS settings
    2. Convert AC power into DC power
    3. Add new hardware capabilities by installing additional cards
    4. Cool the processor
    Show answer

    Answer: (C) Add new hardware capabilities by installing additional cards

    Explanation: Exam Point: Expansion Slot = used to add new hardware capabilities (additional hardware cards).

  14. Which of the following is an example of a card installed in an expansion slot?

    1. CMOS Battery
    2. Heat Sink
    3. Power Connector
    4. TV Tuner Card
    Show answer

    Answer: (D) TV Tuner Card

    Explanation: Graphics Card, Sound Card, Network Card and TV Tuner Card are examples of expansion cards.

  15. Northbridge is a chipset responsible for high-speed communication between:

    1. Keyboard, Mouse and Printer
    2. CPU, RAM and Graphics Controller
    3. SMPS and Power Connector
    4. Pen Drive and Scanner
    Show answer

    Answer: (B) CPU, RAM and Graphics Controller

    Explanation: Northbridge handles high-speed communication between the CPU, RAM and Graphics Controller.

  16. Modern processors often integrate the functions of which motherboard component into the CPU itself?

    1. Northbridge
    2. CMOS Battery
    3. SMPS
    4. PS/2 Port
    Show answer

    Answer: (A) Northbridge

    Explanation: Note: Modern processors often integrate Northbridge functions into the CPU itself.

  17. PCI slot stands for:

    1. Peripheral Component Interconnect
    2. Personal Computer Interface
    3. Primary Control Interconnect
    4. Parallel Component Interface
    Show answer

    Answer: (A) Peripheral Component Interconnect

    Explanation: PCI = Peripheral Component Interconnect; it connects sound cards, modems, network cards and video cards.

  18. AGP stands for:

    1. Advanced Graphics Processor
    2. Analog Graphics Port
    3. Accelerated Graphics Port
    4. Auxiliary Graphics Panel
    Show answer

    Answer: (C) Accelerated Graphics Port

    Explanation: AGP stands for Accelerated Graphics Port.

  19. The AGP slot is specially designed for:

    1. Sound Cards
    2. Graphics Cards
    3. RAM modules
    4. Hard Disks
    Show answer

    Answer: (B) Graphics Cards

    Explanation: Exam Point: AGP = Graphics Card Slot.

  20. A metallic component that absorbs and dissipates heat generated by the processor is called:

    1. CMOS Battery
    2. Northbridge
    3. Heat Sink
    4. Power Connector
    Show answer

    Answer: (C) Heat Sink

    Explanation: A Heat Sink absorbs and dissipates heat generated by the processor and prevents CPU overheating.

  21. A heat sink is often used together with:

    1. CMOS battery and BIOS
    2. SMPS and power connector
    3. Memory slots and RAM
    4. Cooling fan and thermal paste
    Show answer

    Answer: (D) Cooling fan and thermal paste

    Explanation: A heat sink is often used with a Cooling Fan and Thermal Paste.

  22. The power connector on the motherboard supplies electrical power from the:

    1. SMPS
    2. CMOS Battery
    3. USB Port
    4. Heat Sink
    Show answer

    Answer: (A) SMPS

    Explanation: The Power Connector supplies electrical power from the SMPS to the motherboard.

  23. Which component maintains the BIOS settings, date and time even when the computer is switched off?

    1. CMOS Battery
    2. SMPS
    3. Heat Sink
    4. Northbridge
    Show answer

    Answer: (A) CMOS Battery

    Explanation: Exam Point: CMOS Battery maintains BIOS settings; it also stores date, time and hardware configuration.

  24. CMOS stands for:

    1. Central Memory Operating System
    2. Complementary Metal Oxide Semiconductor
    3. Complementary Memory Oxide Storage
    4. Computer Metal Oxide Semiconductor
    Show answer

    Answer: (B) Complementary Metal Oxide Semiconductor

    Explanation: CMOS stands for Complementary Metal Oxide Semiconductor.

  25. SMPS converts:

    1. DC power into AC power
    2. AC power from the wall socket into DC power
    3. Sound waves into electrical signals
    4. Analog signals into digital signals
    Show answer

    Answer: (B) AC power from the wall socket into DC power

    Explanation: SMPS converts AC power from the wall socket into DC power required by computer components.
