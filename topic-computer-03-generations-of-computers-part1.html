Question bank

Generations of Computers - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. A "Generation of Computers" refers to:

    1. A brand of computer manufacturer
    2. A stage in the development of computer technology
    3. The storage capacity of a computer
    4. A type of programming language
    Show answer

    Answer: (B) A stage in the development of computer technology

    Explanation: A Generation of Computers refers to a stage in the development of computer technology.

  2. What was the period of First Generation computers?

    1. 1959–1965
    2. 1965–1971
    3. 1946–1959
    4. 1971–1980
    Show answer

    Answer: (C) 1946–1959

    Explanation: First Generation computers: 1946–1959.

  3. Which was the main electronic component of First Generation computers?

    1. Vacuum Tubes
    2. Transistors
    3. Integrated Circuits
    4. Microprocessors
    Show answer

    Answer: (A) Vacuum Tubes

    Explanation: Vacuum tubes were used as the main electronic components in First Generation computers.

  4. Which were the input devices of First Generation computers?

    1. Keyboard and Mouse
    2. Scanner and Light Pen
    3. Punch Cards and Paper Tape
    4. Touch Screen and Joystick
    Show answer

    Answer: (C) Punch Cards and Paper Tape

    Explanation: First Generation input devices were Punch Cards and Paper Tape.

  5. Which internal storage was used in First Generation computers?

    1. Magnetic Core Memory
    2. Magnetic Drum
    3. Magnetic Disk
    4. Semiconductor Memory
    Show answer

    Answer: (B) Magnetic Drum

    Explanation: Internal storage of First Generation computers was the Magnetic Drum.

  6. Which programming language was used in First Generation computers?

    1. Assembly Language
    2. COBOL
    3. C
    4. Machine Language
    Show answer

    Answer: (D) Machine Language

    Explanation: First Generation computers used Machine Language.

  7. Machine Language is a binary language consisting of only:

    1. 0 to 9
    2. A to Z
    3. 0 to 7
    4. 0 and 1
    Show answer

    Answer: (D) 0 and 1

    Explanation: Machine Language is a binary language consisting of only 0 and 1.

  8. First Generation computers used a Batch Processing System. In such a system:

    1. Jobs were processed one after another without user interaction
    2. Many users shared the CPU interactively at the same time
    3. Jobs were processed instantly as data arrived
    4. Jobs were spread across many connected computers
    Show answer

    Answer: (A) Jobs were processed one after another without user interaction

    Explanation: In batch processing, jobs were processed one after another without user interaction.

  9. Which of the following is a First Generation computer?

    1. IBM 7094
    2. IBM 360
    3. DEC 10
    4. IBM-701
    Show answer

    Answer: (D) IBM-701

    Explanation: ENIAC, EDVAC, UNIVAC-I, IBM-701 and IBM-650 were First Generation computers.

  10. ENIAC belongs to which generation of computers?

    1. Second
    2. Third
    3. First
    4. Fourth
    Show answer

    Answer: (C) First

    Explanation: Exam Point: ENIAC belongs to the First Generation.

  11. What was the period of Second Generation computers?

    1. 1946–1959
    2. 1959–1965
    3. 1965–1971
    4. 1971–1980
    Show answer

    Answer: (B) 1959–1965

    Explanation: Second Generation computers: 1959–1965.

  12. Second Generation computers used which main technology?

    1. Vacuum Tubes
    2. Integrated Circuits
    3. Transistors
    4. VLSI
    Show answer

    Answer: (C) Transistors

    Explanation: Transistors replaced vacuum tubes in the Second Generation.

  13. The transistor was invented at:

    1. IBM
    2. Bell Laboratories
    3. C-DAC
    4. University of Cambridge
    Show answer

    Answer: (B) Bell Laboratories

    Explanation: The transistor was invented at Bell Laboratories.

  14. Which primary memory was used in Second Generation computers?

    1. Magnetic Drum
    2. Paper Tape
    3. Cache Memory
    4. Magnetic Core Memory
    Show answer

    Answer: (D) Magnetic Core Memory

    Explanation: Second Generation primary memory was Magnetic Core Memory.

  15. COBOL and FORTRAN were introduced in which generation?

    1. First
    2. Fourth
    3. Second
    4. Fifth
    Show answer

    Answer: (C) Second

    Explanation: Exam Point: COBOL and FORTRAN were introduced in the Second Generation.

  16. Which operating systems were used in Second Generation computers?

    1. Real-Time OS and Distributed OS
    2. Time Sharing and Remote Processing
    3. Real-Time OS and Time Sharing OS
    4. Batch Processing and Multiprogramming
    Show answer

    Answer: (D) Batch Processing and Multiprogramming

    Explanation: Second Generation operating systems: Batch Processing and Multiprogramming.

  17. Which of the following is a Second Generation computer?

    1. IBM-650
    2. IBM 370/168
    3. PDP 11
    4. IBM 7094
    Show answer

    Answer: (D) IBM 7094

    Explanation: IBM 1620, IBM 7094, CDC 1604, CDC 3600 and UNIVAC 1108 were Second Generation computers.

  18. What was the period of Third Generation computers?

    1. 1965–1971
    2. 1959–1965
    3. 1971–1980
    4. 1946–1959
    Show answer

    Answer: (A) 1965–1971

    Explanation: Third Generation computers: 1965–1971.

  19. Third Generation computers were based on:

    1. Integrated Circuits (ICs)
    2. Vacuum Tubes
    3. Transistors
    4. ULSI
    Show answer

    Answer: (A) Integrated Circuits (ICs)

    Explanation: In the Third Generation, ICs replaced transistors.

  20. Who invented the Integrated Circuit (IC)?

    1. Charles Babbage
    2. Douglas Engelbart
    3. Jack Kilby
    4. John W. Mauchly
    Show answer

    Answer: (C) Jack Kilby

    Explanation: The Integrated Circuit was invented by Jack Kilby.

  21. Keyboard and Monitor were introduced in which generation of computers?

    1. Third
    2. First
    3. Second
    4. Fifth
    Show answer

    Answer: (A) Third

    Explanation: Exam Point: Keyboard and Monitor were introduced in the Third Generation.

  22. Mini Computers were introduced in which generation?

    1. Third
    2. Second
    3. Fourth
    4. Fifth
    Show answer

    Answer: (A) Third

    Explanation: Exam Point: Mini Computers were introduced in the Third Generation.

  23. Remote Processing, along with Multiprogramming and Time Sharing, was an operating system feature of which generation?

    1. First
    2. Third
    3. Second
    4. Fifth
    Show answer

    Answer: (B) Third

    Explanation: Third Generation operating systems: Multiprogramming, Time Sharing and Remote Processing.

  24. The IBM 360 Series belongs to which generation of computers?

    1. First
    2. Third
    3. Second
    4. Fourth
    Show answer

    Answer: (B) Third

    Explanation: IBM 360 Series, IBM 370/168, Honeywell 6000, PDP and TDC-316 were Third Generation computers.

  25. What is the full form of PDP, a Third Generation computer?

    1. Programmed Data Processor
    2. Personal Data Processor
    3. Programmed Digital Processor
    4. Parallel Data Processor
    Show answer

    Answer: (A) Programmed Data Processor

    Explanation: PDP stands for Programmed Data Processor.
