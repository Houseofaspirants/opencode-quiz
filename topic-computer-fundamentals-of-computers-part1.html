Question bank

Fundamentals of Computers - Part 1: all 20 questions

Read the question, pick an option, then open the answer.

  1. Which of the following best defines a computer?

    1. A device that only stores data
    2. A purely mechanical calculating device
    3. An electronic device that accepts data, processes it, stores it and gives output
    4. A device used only for printing documents
    Show answer

    Answer: (C) An electronic device that accepts data, processes it, stores it and gives output

    Explanation: A computer is an electronic device that accepts data, processes it, stores it and provides useful information as output.

  2. Raw, unorganized facts entered into a computer are called:

    1. Data
    2. Information
    3. Output
    4. Instructions
    Show answer

    Answer: (A) Data

    Explanation: Data is raw, unorganized information such as 45, 78, 92, entered through input devices.

  3. Data + Processing = ?

    1. Instructions
    2. Memory
    3. Storage
    4. Information
    Show answer

    Answer: (D) Information

    Explanation: Information is processed and organized data, so Data + Processing = Information.

  4. What is the correct order of the basic working cycle of a computer?

    1. Processing → Input → Output
    2. Input → Processing → Output
    3. Output → Processing → Input
    4. Input → Output → Processing
    Show answer

    Answer: (B) Input → Processing → Output

    Explanation: Data is first entered (input), then processed by the CPU, and finally shown as output.

  5. Commands given to a computer to perform a specific task are called:

    1. Data
    2. Instructions
    3. Information
    4. Output
    Show answer

    Answer: (B) Instructions

    Explanation: Instructions are commands such as save a file, open a folder or print a document.

  6. Which part is called the 'Brain' of the computer?

    1. Motherboard
    2. RAM
    3. Monitor
    4. CPU
    Show answer

    Answer: (D) CPU

    Explanation: The CPU performs calculations, controls operations and processes data, so it is called the brain of the computer.

  7. Which of the following is an input device?

    1. Keyboard
    2. Monitor
    3. Printer
    4. Speaker
    Show answer

    Answer: (A) Keyboard

    Explanation: A keyboard is used to enter text into a computer; monitor, printer and speaker are output devices.

  8. Which of the following is an output device?

    1. Mouse
    2. Scanner
    3. Monitor
    4. Webcam
    Show answer

    Answer: (C) Monitor

    Explanation: A monitor displays processed information. Mouse, scanner and webcam are input devices.

  9. Computer speed refers to:

    1. The screen size of the monitor
    2. The storage capacity of the hard disk
    3. The number of users using the computer
    4. The number of instructions processed in one second
    Show answer

    Answer: (D) The number of instructions processed in one second

    Explanation: Speed is the number of instructions a computer processes in one second.

  10. Which of the following is the smallest unit of time used for computer speed?

    1. Nanosecond (ns)
    2. Picosecond (ps)
    3. Microsecond (μs)
    4. Millisecond (ms)
    Show answer

    Answer: (B) Picosecond (ps)

    Explanation: Picosecond (10⁻¹² s) is smaller than nanosecond (10⁻⁹ s), microsecond (10⁻⁶ s) and millisecond (10⁻³ s).

  11. Intel Core i7 and AMD Ryzen are examples of:

    1. Storage devices
    2. Output devices
    3. Processors (CPU)
    4. Operating systems
    Show answer

    Answer: (C) Processors (CPU)

    Explanation: They are processors (CPUs) that execute instructions and process data.

  12. Which of the following is a permanent storage device?

    1. SSD
    2. RAM
    3. Cache Memory
    4. Motherboard
    Show answer

    Answer: (A) SSD

    Explanation: HDD, SSD, pen drive and CD/DVD store data permanently, whereas RAM and cache are temporary memory.

  13. The main circuit board that connects all components of a computer is the:

    1. Motherboard
    2. Hard Disk Drive
    3. Cache Memory
    4. Scanner
    Show answer

    Answer: (A) Motherboard

    Explanation: The motherboard connects the CPU, RAM, storage, input and output devices; it is the backbone of the computer.

  14. Which statement about Memory and Storage is correct?

    1. Memory is permanent, Storage is temporary
    2. Both Memory and Storage are permanent
    3. Memory is temporary, Storage is permanent
    4. Both Memory and Storage are temporary
    Show answer

    Answer: (C) Memory is temporary, Storage is permanent

    Explanation: Memory holds data temporarily while processing, while storage keeps data permanently.

  15. Which of the following is NOT a storage device?

    1. Pen Drive
    2. Scanner
    3. SSD
    4. CD/DVD
    Show answer

    Answer: (B) Scanner

    Explanation: A scanner is an input device used to scan documents; the others store data.

  16. Which device is used to input sound into a computer?

    1. Speaker
    2. Projector
    3. Printer
    4. Microphone
    Show answer

    Answer: (D) Microphone

    Explanation: A microphone is an input device for sound, while a speaker produces sound as output.

  17. Which unit of the CPU controls and coordinates all activities of the computer?

    1. Arithmetic Logic Unit (ALU)
    2. Control Unit (CU)
    3. Memory Unit
    4. Cache Memory
    Show answer

    Answer: (B) Control Unit (CU)

    Explanation: The Control Unit (CU) controls all activities, while the ALU performs arithmetic and logical operations.

  18. The CPU consists of:

    1. CU + ALU + Memory Unit
    2. ALU + RAM + Hard Disk
    3. CU + Monitor + Keyboard
    4. Motherboard + ALU + Printer
    Show answer

    Answer: (A) CU + ALU + Memory Unit

    Explanation: As per the notes, CPU = CU + ALU + Memory Unit.

  19. Which of the following lists contains ONLY input devices?

    1. Keyboard, Printer, Mouse
    2. Monitor, Speaker, Scanner
    3. Projector, Webcam, Microphone
    4. Keyboard, Scanner, Webcam
    Show answer

    Answer: (D) Keyboard, Scanner, Webcam

    Explanation: Keyboard, scanner and webcam are all input devices; each other list contains an output device such as printer, monitor, speaker or projector.

  20. Which of the following are examples of memory (temporary storage)?

    1. HDD and SSD
    2. Pen Drive and CD/DVD
    3. RAM and Cache Memory
    4. CPU and Motherboard
    Show answer

    Answer: (C) RAM and Cache Memory

    Explanation: RAM and Cache Memory hold data temporarily during processing and allow fast communication with the CPU.
