Question bank

Input Devices - Part 2 - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. A pen-shaped pointing device containing a light-sensitive sensor that detects objects on the screen is:

    1. Light Pen
    2. Stylus
    3. Joystick
    4. Digitizer
    Show answer

    Answer: (A) Light Pen

    Explanation: A Light Pen is a pen-shaped pointing device with a light-sensitive sensor.

  2. The Light Pen was developed around 1955 under which project?

    1. ENIAC Project
    2. PARAM Project (C-DAC)
    3. EDSAC Project (Cambridge)
    4. Whirlwind Project (MIT)
    Show answer

    Answer: (D) Whirlwind Project (MIT)

    Explanation: The Light Pen was invented around 1955 under the Whirlwind Project at MIT.

  3. According to the exam facts in the chapter, a Light Pen is NOT used with:

    1. Drawing applications
    2. Selecting objects
    3. LCD screens
    4. Pointing on the screen
    Show answer

    Answer: (C) LCD screens

    Explanation: Exam fact: Light Pen is not used with LCD screens.

  4. A Digitizer is also known as:

    1. Touchpad
    2. Graphics Tablet
    3. Light Pen
    4. Trackball
    Show answer

    Answer: (B) Graphics Tablet

    Explanation: Digitizer (Graphics Tablet) is a flat input device used with a stylus.

  5. A Digitizer is a flat input device that is used with a:

    1. Stylus
    2. Joystick
    3. Trackball
    4. Barcode reader
    Show answer

    Answer: (A) Stylus

    Explanation: A Digitizer is used with a stylus to convert hand-drawn images into digital form.

  6. Which input device is especially used in CAD and AutoCAD?

    1. Microphone
    2. Digitizer
    3. MICR
    4. Webcam
    Show answer

    Answer: (B) Digitizer

    Explanation: Exam fact: Digitizer is used in CAD and AutoCAD.

  7. Which input device is used to record voice for video conferencing and online meetings?

    1. Scanner
    2. Light Pen
    3. Joystick
    4. Microphone
    Show answer

    Answer: (D) Microphone

    Explanation: A Microphone enters sound; used for voice recording, voice calls and video conferencing.

  8. What is the full form of MICR?

    1. Magnetic Ink Code Reader
    2. Magnetic Ink Character Recognition
    3. Micro Ink Character Recognition
    4. Magnetic Image Character Reader
    Show answer

    Answer: (B) Magnetic Ink Character Recognition

    Explanation: MICR stands for Magnetic Ink Character Recognition.

  9. MICR is mainly used for:

    1. Bank cheque processing
    2. Video games
    3. Digital drawing
    4. Face unlock
    Show answer

    Answer: (A) Bank cheque processing

    Explanation: Exam Point: MICR is used on bank cheques.

  10. What is the full form of OCR?

    1. Optical Code Reader
    2. Online Character Recognition
    3. Optical Character Recognition
    4. Optical Character Reader
    Show answer

    Answer: (C) Optical Character Recognition

    Explanation: OCR stands for Optical Character Recognition.

  11. OCR converts printed or handwritten text into:

    1. Magnetic ink characters
    2. Audio signals
    3. Barcodes
    4. Editable digital text
    Show answer

    Answer: (D) Editable digital text

    Explanation: OCR converts printed or handwritten text into editable digital text.

  12. According to the OCR vs MICR comparison in the chapter, which statement is correct?

    1. MICR has very high accuracy, OCR has high accuracy
    2. OCR has very high accuracy, MICR has high accuracy
    3. OCR uses magnetic technology
    4. MICR is mainly used for documents
    Show answer

    Answer: (A) MICR has very high accuracy, OCR has high accuracy

    Explanation: OCR: optical, used for documents, high accuracy; MICR: magnetic, used for cheques, very high accuracy.

  13. Which device acts as both an input device and an output device?

    1. Keyboard
    2. Scanner
    3. Microphone
    4. Touch Screen
    Show answer

    Answer: (D) Touch Screen

    Explanation: A Touch Screen is both an input and an output device.

  14. The Touch Screen was developed in the early 1970s by:

    1. Mauchly and Eckert
    2. Douglas Engelbart and C. B. Mirick
    3. Jack Kilby and Bell Laboratories
    4. Frank Beck and Bent Stumpe
    Show answer

    Answer: (D) Frank Beck and Bent Stumpe

    Explanation: Touch Screen inventors: Frank Beck and Bent Stumpe, developed in the early 1970s.

  15. Which of the following is a use of Touch Screens mentioned in the chapter?

    1. Bank cheque reading
    2. Flight simulators
    3. ATM machines and kiosks
    4. Drum scanning
    Show answer

    Answer: (C) ATM machines and kiosks

    Explanation: Touch Screens are used in smartphones, tablets, ATM machines and kiosks.

  16. Which technology creates a computer-generated environment that appears real to the user?

    1. Virtual Reality (VR)
    2. OCR
    3. MICR
    4. Digitizer
    Show answer

    Answer: (A) Virtual Reality (VR)

    Explanation: Virtual Reality (VR) creates a computer-generated environment that appears real to the user.

  17. Which of the following devices is used in Virtual Reality?

    1. MICR reader
    2. Drum Scanner
    3. VR Headset
    4. Barcode Scanner
    Show answer

    Answer: (C) VR Headset

    Explanation: Devices used in VR: VR Headset, Gloves and Headphones.

  18. A camera connected to a computer, used for video calls and online classes, is called:

    1. Webcam
    2. Scanner
    3. Digitizer
    4. Light Pen
    Show answer

    Answer: (A) Webcam

    Explanation: A Webcam is a camera connected to a computer, used for video calls, online classes and recording videos.

  19. Biometric devices identify a person using:

    1. Magnetic ink characters
    2. Printed barcodes
    3. Unique biological characteristics
    4. Typed passwords
    Show answer

    Answer: (C) Unique biological characteristics

    Explanation: Biometric Devices identify a person using unique biological characteristics.

  20. Which is the most commonly used biometric device?

    1. Retina Scanner
    2. Fingerprint Scanner
    3. Voice Scanner
    4. Hand Scanner
    Show answer

    Answer: (B) Fingerprint Scanner

    Explanation: The Fingerprint Scanner is the most common biometric device.

  21. A Hand Scanner identifies a person using:

    1. Palm vein patterns
    2. Facial measurements
    3. Voice characteristics
    4. The retina
    Show answer

    Answer: (A) Palm vein patterns

    Explanation: A Hand Scanner uses palm vein patterns.

  22. According to the chapter, which biological feature is even more unique than fingerprints?

    1. Voice
    2. Palm veins
    3. Face
    4. Handwriting
    Show answer

    Answer: (B) Palm veins

    Explanation: Palm veins are even more unique than fingerprints.

  23. Which biometric device uses the eye for identification and provides high security?

    1. Face Scanner
    2. Voice Scanner
    3. Retina/Iris Scanner
    4. Hand Scanner
    Show answer

    Answer: (C) Retina/Iris Scanner

    Explanation: Retina/Iris Scanner uses the eye for identification; Retina Scanner provides high security.

  24. "Face Unlock" in smartphones is an example of which biometric device?

    1. Hand Scanner
    2. Face Scanner
    3. Voice Scanner
    4. Retina Scanner
    Show answer

    Answer: (B) Face Scanner

    Explanation: A Face Scanner identifies a person using facial measurements, e.g. Face Unlock in smartphones.

  25. Which biometric device uses voice characteristics for identification?

    1. Face Scanner
    2. Fingerprint Scanner
    3. Hand Scanner
    4. Voice Scanner
    Show answer

    Answer: (D) Voice Scanner

    Explanation: A Voice Scanner uses voice characteristics for identification.
