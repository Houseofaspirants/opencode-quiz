Fundamentals of Computers - Part 2 - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. Which input device is used to input video?

    1. Webcam
    2. Microphone
    3. Scanner
    4. Keyboard
    Show answer

    Answer: (A) Webcam

    Explanation: In the chapter's table, Webcam is the input device used to input video.

  2. The function of a microphone as an input device is to:

    1. Input video
    2. Scan documents
    3. Point and click
    4. Input sound
    Show answer

    Answer: (D) Input sound

    Explanation: Microphone is an input device used to input sound.

  3. Which input device is used to "point and click"?

    1. Mouse
    2. Keyboard
    3. Webcam
    4. Microphone
    Show answer

    Answer: (A) Mouse

    Explanation: Mouse is used to point and click.

  4. Which of the following is an output device?

    1. Keyboard
    2. Scanner
    3. Webcam
    4. Monitor
    Show answer

    Answer: (D) Monitor

    Explanation: Monitor is an output device; keyboard, scanner and webcam are input devices.

  5. Which output device is used to display information on a large screen?

    1. Monitor
    2. Printer
    3. Projector
    4. Speaker
    Show answer

    Answer: (C) Projector

    Explanation: Projector displays information on a large screen.

  6. In the chapter, computers are classified into Micro, Mini, Mainframe, Super and Workstation on the basis of:

    1. Colour and shape
    2. Size and processing power
    3. Brand and price
    4. Operating system and language
    Show answer

    Answer: (B) Size and processing power

    Explanation: Based on size and processing power, computers are divided into five types.

  7. A Micro Computer is a single-user computer that uses a ______ as its CPU.

    1. Microprocessor
    2. Vacuum tube
    3. Magnetic drum
    4. Punch card
    Show answer

    Answer: (A) Microprocessor

    Explanation: A Micro Computer uses a microprocessor as its CPU.

  8. Which is the most common type of computer?

    1. Mini Computer
    2. Mainframe Computer
    3. Micro Computer
    4. Super Computer
    Show answer

    Answer: (C) Micro Computer

    Explanation: Exam Point: Most common type of computer = Micro Computer.

  9. Laptop, Tablet, Smartphone and PDA are examples of which type of computer?

    1. Mini Computer
    2. Mainframe Computer
    3. Workstation
    4. Micro Computer
    Show answer

    Answer: (D) Micro Computer

    Explanation: Desktop, Laptop, Tablet, Smartphone and PDA are examples of Micro Computers.

  10. What is the full form of PDA?

    1. Personal Data Assistant
    2. Portable Digital Assistant
    3. Personal Digital Application
    4. Personal Digital Assistant
    Show answer

    Answer: (D) Personal Digital Assistant

    Explanation: PDA stands for Personal Digital Assistant, an example of a micro computer.

  11. Mini Computer is also called:

    1. Midrange Computer
    2. Personal Computer
    3. Workstation
    4. Handheld Computer
    Show answer

    Answer: (A) Midrange Computer

    Explanation: A Mini Computer is also called a Midrange Computer.

  12. University admission systems, departmental databases and small business operations mainly use which type of computer?

    1. Super Computer
    2. Mini Computer
    3. Micro Computer
    4. Workstation
    Show answer

    Answer: (B) Mini Computer

    Explanation: Mini Computers are multi-user computers used by small organizations for such tasks.

  13. In the chapter's comparison table, "Department Server" is given as an example of which computer type?

    1. Mini
    2. Micro
    3. Mainframe
    4. Workstation
    Show answer

    Answer: (A) Mini

    Explanation: The comparison table lists Department Server as the example of a Mini computer.

  14. Which computer can support hundreds to thousands of users simultaneously and process huge amounts of data?

    1. Micro Computer
    2. Mainframe Computer
    3. Workstation
    4. Mini Computer
    Show answer

    Answer: (B) Mainframe Computer

    Explanation: A Mainframe is a large, powerful multi-user computer supporting hundreds to thousands of users.

  15. Banks commonly use which type of computer?

    1. Super Computer
    2. Mainframe Computer
    3. Micro Computer
    4. Workstation
    Show answer

    Answer: (B) Mainframe Computer

    Explanation: Exam Point: Banks commonly use Mainframe Computers.

  16. Which is the fastest and most powerful type of computer?

    1. Mainframe Computer
    2. Mini Computer
    3. Super Computer
    4. Workstation
    Show answer

    Answer: (C) Super Computer

    Explanation: A Super Computer is the fastest and most powerful type of computer.

  17. Weather forecasting, space research and nuclear research mainly use:

    1. Mini Computers
    2. Micro Computers
    3. Super Computers
    4. Workstations
    Show answer

    Answer: (C) Super Computers

    Explanation: Uses of Super Computers include weather forecasting, space research and nuclear research.

  18. Which was the first supercomputer of the world?

    1. CRAY-1
    2. CDC 6600
    3. PARAM 8000
    4. IBM PC
    Show answer

    Answer: (B) CDC 6600

    Explanation: The first supercomputer of the world was CDC 6600.

  19. In which year was CDC 6600, the world's first supercomputer, introduced?

    1. 1976
    2. 1991
    3. 1981
    4. 1964
    Show answer

    Answer: (D) 1964

    Explanation: First Supercomputer: CDC 6600 (1964).

  20. CRAY-1 was developed by Cray Research in the year:

    1. 1964
    2. 1991
    3. 1946
    4. 1976
    Show answer

    Answer: (D) 1976

    Explanation: CRAY-1 was developed by Cray Research in 1976.

  21. Which was India's first supercomputer?

    1. PARAM 8000
    2. CDC 6600
    3. CRAY-1
    4. UNIVAC-I
    Show answer

    Answer: (A) PARAM 8000

    Explanation: PARAM 8000 was India's first supercomputer.

  22. PARAM 8000 was developed by:

    1. C-DAC
    2. Cray Research
    3. IBM
    4. CDC
    Show answer

    Answer: (A) C-DAC

    Explanation: PARAM 8000 was developed by C-DAC.

  23. In which year did C-DAC develop PARAM 8000?

    1. 1964
    2. 1976
    3. 1991
    4. 1984
    Show answer

    Answer: (C) 1991

    Explanation: First Indian Supercomputer: PARAM 8000 (1991), developed by C-DAC.

  24. A powerful single-user computer designed for professional and technical work is called:

    1. Mini Computer
    2. Mainframe Computer
    3. Workstation
    4. Super Computer
    Show answer

    Answer: (C) Workstation

    Explanation: A Workstation is a powerful single-user computer for professional and technical work.

  25. CAD/CAM, engineering design and desktop publishing are typical uses of:

    1. Mainframe Computer
    2. Workstation
    3. Mini Computer
    4. Super Computer
    Show answer

    Answer: (B) Workstation

    Explanation: Workstations are used for software development, engineering design, CAD/CAM and desktop publishing.
