Question bank

Mobile Phone Part1 25 Mcqs: all 25 questions

Read the question, pick an option, then open the answer.

  1. Who is known as the 'Father of the Mobile Phone'?

    1. Donald Hings
    2. Martin Cooper
    3. Steve Jobs
    4. Tim Berners-Lee
    Show answer

    Answer: (B) Martin Cooper

    Explanation: Martin Cooper invented the first mobile phone.

  2. The first mobile phone was invented in which year?

    1. 1969
    2. 1973
    3. 1979
    4. 1983
    Show answer

    Answer: (B) 1973

    Explanation: The first mobile phone was invented in 1973.

  3. Which was the first commercial mobile phone?

    1. IBM Simon
    2. Nokia 1011
    3. Motorola DynaTAC 8000X
    4. Motorola Razr
    Show answer

    Answer: (C) Motorola DynaTAC 8000X

    Explanation: Motorola DynaTAC 8000X was the first commercial mobile phone.

  4. The first smartphone was:

    1. Nokia 1100
    2. IBM Simon Personal Communicator
    3. BlackBerry
    4. iPhone
    Show answer

    Answer: (B) IBM Simon Personal Communicator

    Explanation: IBM Simon Personal Communicator was the first smartphone.

  5. The first cellular network was launched by:

    1. Motorola
    2. Apple
    3. NTT Japan
    4. Google
    Show answer

    Answer: (C) NTT Japan

    Explanation: NTT Japan launched the first cellular network.

  6. Mobile phones communicate using:

    1. Infrared Rays
    2. Radio Waves
    3. Microwaves Only
    4. Laser
    Show answer

    Answer: (B) Radio Waves

    Explanation: Mobile phones use radio waves.

  7. The ideal shape of a cellular cell is:

    1. Circle
    2. Triangle
    3. Square
    4. Hexagon
    Show answer

    Answer: (D) Hexagon

    Explanation: Hexagon is used for network planning.

  8. A cell is served by:

    1. Satellite
    2. Base Station
    3. Router
    4. Switch
    Show answer

    Answer: (B) Base Station

    Explanation: Each cell has one base station.

  9. Mobile phones support which communication mode?

    1. Half Duplex
    2. Simplex
    3. Full Duplex
    4. Broadcast
    Show answer

    Answer: (C) Full Duplex

    Explanation: Users can speak and listen simultaneously.

  10. FDMA stands for:

    1. Frequency Division Multiple Access
    2. Fast Digital Mobile Access
    3. Frequency Dual Mobile Access
    4. Fixed Data Mobile Access
    Show answer

    Answer: (A) Frequency Division Multiple Access

    Explanation: FDMA allocates separate frequencies.

  11. TDMA divides communication by:

    1. Code
    2. Time
    3. Frequency
    4. Location
    Show answer

    Answer: (B) Time

    Explanation: TDMA uses time slots.

  12. CDMA allows users to share:

    1. Different Frequencies
    2. Different Towers
    3. Same Frequency with Unique Codes
    4. Different SIM Cards
    Show answer

    Answer: (C) Same Frequency with Unique Codes

    Explanation: CDMA uses unique codes.

  13. PDMA uses different:

    1. Passwords
    2. Polarization States
    3. Packets
    4. Ports
    Show answer

    Answer: (B) Polarization States

    Explanation: PDMA separates signals using polarization.

  14. ESN is:

    1. Temporary
    2. Permanent
    3. Deleted After Restart
    4. SIM Based
    Show answer

    Answer: (B) Permanent

    Explanation: ESN is permanently programmed.

  15. ESN is a:

    1. 16-bit Number
    2. 32-bit Number
    3. 64-bit Number
    4. 128-bit Number
    Show answer

    Answer: (B) 32-bit Number

    Explanation: ESN is a unique 32-bit number.

  16. MIN stands for:

    1. Mobile Identification Number
    2. Mobile Internet Number
    3. Main Identification Network
    4. Multiple Identity Number
    Show answer

    Answer: (A) Mobile Identification Number

    Explanation: MIN identifies the subscriber.

  17. SID identifies the:

    1. Phone
    2. Subscriber
    3. Carrier
    4. Tower
    Show answer

    Answer: (C) Carrier

    Explanation: SID identifies the network provider.

  18. IMEI contains:

    1. 10 Digits
    2. 12 Digits
    3. 15 Digits
    4. 16 Digits
    Show answer

    Answer: (C) 15 Digits

    Explanation: IMEI is a unique 15-digit number.

  19. Which code identifies a mobile handset?

    1. IMEI
    2. IMSI
    3. SID
    4. MIN
    Show answer

    Answer: (A) IMEI

    Explanation: IMEI identifies the device.

  20. To check IMEI, dial:

    1. *#06#
    2. *#07#
    3. #123#
    4. *111#
    Show answer

    Answer: (A) *#06#

    Explanation: IMEI can be checked using *#06#.

  21. SIM stands for:

    1. Subscriber Identity Module
    2. System Identity Module
    3. Subscriber Internet Module
    4. Secure Identity Memory
    Show answer

    Answer: (A) Subscriber Identity Module

    Explanation: SIM = Subscriber Identity Module.

  22. IMSI is stored in:

    1. Battery
    2. SIM Card
    3. Processor
    4. Display
    Show answer

    Answer: (B) SIM Card

    Explanation: IMSI is stored in the SIM.

  23. TMSI stands for:

    1. Temporary Mobile Subscriber Identity
    2. Telecom Mobile Subscriber Identity
    3. Transfer Mobile Subscriber Identity
    4. Terminal Mobile Subscriber Identity
    Show answer

    Answer: (A) Temporary Mobile Subscriber Identity

    Explanation: TMSI is a temporary identity.

  24. eSIM stands for:

    1. Electronic SIM
    2. Embedded Subscriber Identity Module
    3. Enhanced SIM
    4. External SIM
    Show answer

    Answer: (B) Embedded Subscriber Identity Module

    Explanation: eSIM is embedded in device hardware.

  25. eSIM can be activated:

    1. Only by replacing hardware
    2. Digitally
    3. Only with cable
    4. Only at factory
    Show answer

    Answer: (B) Digitally

    Explanation: eSIM is activated digitally.
