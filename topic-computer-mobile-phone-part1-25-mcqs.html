Topic introduction

What Mobile Phone Part1 25 Mcqs covers

The shape of the set before you start it.

Mobile phones sit inside the computer-awareness syllabus as a compact, high-frequency cluster. This set covers three parts of it: the early history of the handset, how a cellular network actually talks to a device, and the identification codes that let a network tell one handset from another.

Each of the twenty-five questions carries four options and a full explanation, so the set works twice - once as a test, and again as revision when you read why each distractor is wrong.
