Generations of Computers - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. What was the period of Fourth Generation computers?

    1. 1965–1971
    2. 1980–Present
    3. 1971–1980
    4. 1959–1965
    Show answer

    Answer: (C) 1971–1980

    Explanation: Fourth Generation computers: 1971–1980.

  2. What is the full form of VLSI?

    1. Very Large Scale Integration
    2. Very Long Scale Integration
    3. Variable Large Scale Integration
    4. Very Large System Integration
    Show answer

    Answer: (A) Very Large Scale Integration

    Explanation: VLSI stands for Very Large Scale Integration, the main technology of the Fourth Generation.

  3. The Microprocessor was introduced in which generation?

    1. Third
    2. Second
    3. Fifth
    4. Fourth
    Show answer

    Answer: (D) Fourth

    Explanation: Exam Point: Microprocessor was introduced in the Fourth Generation.

  4. With the introduction of the microprocessor in the Fourth Generation:

    1. Vacuum tubes were placed on a single chip
    2. A complete CPU was placed on a single chip
    3. Transistors replaced vacuum tubes
    4. Magnetic drum became the main memory
    Show answer

    Answer: (B) A complete CPU was placed on a single chip

    Explanation: In the Fourth Generation, a complete CPU was placed on a single chip (microprocessor).

  5. In VLSI technology of the Fourth Generation, how many transistors were placed on a single chip?

    1. Millions
    2. Only one
    3. Tens
    4. Hundreds
    Show answer

    Answer: (A) Millions

    Explanation: In VLSI, millions of transistors were placed on a single chip.

  6. Real-Time OS and Distributed OS were operating systems of which generation?

    1. First
    2. Second
    3. Third
    4. Fourth
    Show answer

    Answer: (D) Fourth

    Explanation: Fourth Generation operating systems: Real-Time OS, Time Sharing OS and Distributed OS.

  7. Which programming languages are associated with the Fourth Generation?

    1. COBOL and FORTRAN
    2. Machine Language only
    3. C and C++
    4. PL/1 and ALGOL-68
    Show answer

    Answer: (C) C and C++

    Explanation: Fourth Generation languages: C, C++ and Database Languages.

  8. GUI (Graphical User Interface) was introduced in which generation?

    1. Second
    2. Third
    3. First
    4. Fourth
    Show answer

    Answer: (D) Fourth

    Explanation: Exam Point: GUI was introduced in the Fourth Generation.

  9. In which generation did the Mouse become popular?

    1. Third
    2. Second
    3. First
    4. Fourth
    Show answer

    Answer: (D) Fourth

    Explanation: Exam Point: Mouse became popular in the Fourth Generation.

  10. Personal Computers (PCs) emerged in which generation?

    1. Third
    2. Fourth
    3. Second
    4. Fifth
    Show answer

    Answer: (B) Fourth

    Explanation: Personal Computers emerged in the Fourth Generation.

  11. In which year did IBM introduce the IBM PC?

    1. 1977
    2. 1984
    3. 1981
    4. 1971
    Show answer

    Answer: (C) 1981

    Explanation: In 1981, IBM introduced the IBM PC.

  12. In 1984, Apple introduced which computer with GUI?

    1. Apple II
    2. Commodore PET
    3. Macintosh
    4. IBM PC
    Show answer

    Answer: (C) Macintosh

    Explanation: 1984: Apple introduced the Macintosh with GUI; Apple Macintosh popularized GUI.

  13. CRAY-1 and CRAY X-MP are examples of which generation of computers?

    1. Second
    2. Fourth
    3. Third
    4. First
    Show answer

    Answer: (B) Fourth

    Explanation: DEC 10, PDP 11, STAR 1000, CRAY-1 and CRAY X-MP were Fourth Generation computers.

  14. What is the period of Fifth Generation computers?

    1. 1971–1980
    2. 1980–Present
    3. 1965–1971
    4. 1990–Present
    Show answer

    Answer: (B) 1980–Present

    Explanation: Fifth Generation computers: 1980–Present.

  15. What is the full form of ULSI?

    1. Ultra Large Scale Integration
    2. Ultra Long Scale Integration
    3. Universal Large Scale Integration
    4. Ultra Large System Integration
    Show answer

    Answer: (A) Ultra Large Scale Integration

    Explanation: ULSI stands for Ultra Large Scale Integration, used in the Fifth Generation.

  16. What is the main focus (hallmark) of Fifth Generation computers?

    1. Vacuum Tubes
    2. Artificial Intelligence (AI)
    3. Batch Processing
    4. Magnetic Core Memory
    Show answer

    Answer: (B) Artificial Intelligence (AI)

    Explanation: Exam Point: AI is the hallmark of the Fifth Generation.

  17. ULSI chips of the Fifth Generation contain:

    1. Only a few hundred transistors
    2. A single vacuum tube
    3. Millions to billions of electronic components
    4. Only magnetic cores
    Show answer

    Answer: (C) Millions to billions of electronic components

    Explanation: ULSI chips contain millions to billions of electronic components.

  18. Java, .NET and Python are programming languages associated with which generation?

    1. Fifth
    2. Second
    3. Third
    4. First
    Show answer

    Answer: (A) Fifth

    Explanation: Fifth Generation languages: C, C++, Java, .NET, Python and AI languages.

  19. Parallel Processing is a feature of which generation of computers?

    1. Fifth
    2. First
    3. Second
    4. Third
    Show answer

    Answer: (A) Fifth

    Explanation: Exam Point: Parallel Processing is used in the Fifth Generation.

  20. Ultrabooks, Chromebooks and AI-based systems are examples of which generation?

    1. Fourth
    2. Third
    3. Second
    4. Fifth
    Show answer

    Answer: (D) Fifth

    Explanation: Fifth Generation examples include desktops, laptops, notebooks, ultrabooks, Chromebooks and AI-based systems.

  21. Which was the first complete personal computer?

    1. Apple II
    2. Commodore PET
    3. IBM PC
    4. Macintosh
    Show answer

    Answer: (B) Commodore PET

    Explanation: The first complete personal computer was the Commodore PET.

  22. When was the Commodore PET introduced?

    1. January 1977
    2. January 1981
    3. January 1984
    4. January 1971
    Show answer

    Answer: (A) January 1977

    Explanation: The Commodore PET was introduced in January 1977.

  23. Soon after the Commodore PET, which highly popular computer was introduced by Apple?

    1. Macintosh
    2. IBM PC
    3. PDP 11
    4. Apple II
    Show answer

    Answer: (D) Apple II

    Explanation: Soon after Commodore PET, Apple introduced Apple II, which became highly popular.

  24. Which personal computer became the most successful and established the PC standard used today?

    1. IBM PC
    2. Commodore PET
    3. Apple II
    4. Macintosh
    Show answer

    Answer: (A) IBM PC

    Explanation: IBM PC became the most successful personal computer and established today's PC standard.

  25. In the memory trick "V-T-I-M-A" for generations, the letter "M" stands for:

    1. Magnetic Drum
    2. Machine Language
    3. Microprocessor
    4. Mainframe
    Show answer

    Answer: (C) Microprocessor

    Explanation: V-T-I-M-A: Vacuum Tubes, Transistors, Integrated Circuits, Microprocessor, Artificial Intelligence.
