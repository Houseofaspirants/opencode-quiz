Question bank

Coding and Decoding MCQ – Part 5: all 25 questions

Read the question, pick an option, then open the answer.

  1. Fixed codes ignore order: “books inspire minds” = “qa ve lu”; “stories inspire children” = “ve ro na”; “books delight children” = “qa mi na”. Which extra coded sentence is consistent with all three?

    1. stories delight minds = ro na lu
    2. stories delight minds = ro mi lu
    3. books inspire children = qa ve ro
    4. children delight books = mi lu qa
    Show answer

    Answer: (B) stories delight minds = ro mi lu

    Explanation: Elimination gives stories=ro, delight=mi and minds=lu. Thus ro mi lu is the consistent extra code.

  2. A label stores the complete reversal of BANUR. Which letter occupies the second position from the LEFT in the stored label?

    1. R
    2. N
    3. U
    4. A
    Show answer

    Answer: (C) U

    Explanation: BANUR reverses to RUNAB. Its second letter from the left is U.

  3. Each word has a fixed, distinct code and order is arbitrary. “mela starts early” = “ka ri so”; “mela starts tomorrow” = “ri ka tu”; “early trains arrive” = “so ne pa”. How many different tokens can individually represent “starts” from these statements?

    1. 3
    2. 2
    3. 4
    4. 1
    Show answer

    Answer: (B) 2

    Explanation: Mela and starts share the unresolved set ka,ri. Nothing separates those two words, so starts has two possible tokens.

  4. Use row then column. Columns 0,1,2; row 0=K,A,R; row 1=N,A,L; row 2=R,K,A. Decode 21-22-02-10-01-12, then exchange the first and last decoded letters. Which final string results?

    1. LARNKA
    2. KALNAR
    3. KARNAL
    4. LARNAK
    Show answer

    Answer: (D) LARNAK

    Explanation: The coordinates first give KARNAL. Exchanging only its endpoint letters gives LARNAK.

  5. A naming cycle is TRAIN→BUS, BUS→TAXI, TAXI→TRAIN. Each of two clerks applies the naming rule once to the label received. Starting from the real item TAXI, what label does the second clerk return?

    1. TRAIN
    2. CAR
    3. TAXI
    4. BUS
    Show answer

    Answer: (D) BUS

    Explanation: The two required steps are TAXI→TRAIN→BUS. The second clerk returns BUS.

  6. In an eight-letter word, positions 1 and 8 exchange, 2 and 7 exchange, while positions 3–6 stay fixed. Which code results from JALANDAR?

    1. JALANDRA
    2. RALANDAJ
    3. RAALNDAJ
    4. RADNALAJ
    Show answer

    Answer: (B) RALANDAJ

    Explanation: Only the outer two pairs change. R,A remain at the front, LAND stays in the middle, and A,J finish the code: RALANDAJ.

  7. Under a fixed +6 shift, the incomplete name H?RI becomes NGXO. Which letter is missing in the original?

    1. A
    2. Z
    3. G
    4. B
    Show answer

    Answer: (A) A

    Explanation: The second coded letter G has rank 7. Undo +6: 7-6=1=A.

  8. Successive letters move forward by the first five primes: 2,3,5,7,11. Which code belongs to DIWAS?

    1. ELBHB
    2. FLBHD
    3. FMCIC
    4. FLBHB
    Show answer

    Answer: (B) FLBHD

    Explanation: Apply +2,+3,+5,+7,+11, wrapping after Z. DIWAS becomes FLBHD.

  9. A five-letter rule maps input positions to output positions as follows: 1→3, 2→5, 3→1, 4→2, 5→4. Which complete output corresponds to MEHAR?

    1. HAMER
    2. HRMEA
    3. HAMRE
    4. EAMRH
    Show answer

    Answer: (C) HAMRE

    Explanation: These arrows specify destinations, not a reading order. Filling output places 1–5 gives H,A,M,R,E, or HAMRE.

  10. A mixed code uses P→5, 5→#, #→R, R→8. Replace each ORIGINAL character exactly once. What is the code of P5#R?

    1. 5#R8
    2. #R88
    3. 8#R8
    4. 5#88
    Show answer

    Answer: (A) 5#R8

    Explanation: Apply one substitution per original position, without recoding the results. P,5,#,R become 5,#,R,8.

  11. The rule +1,-2 alternates within EACH word and restarts after a space. What is the code for SAT PAL?

    1. TYU QYM
    2. TYU QBM
    3. TYU NBI
    4. TBU QBM
    Show answer

    Answer: (A) TYU QYM

    Explanation: SAT uses +1,-2,+1 to become TYU. Restart the same shifts for PAL to get QYM, giving TYU QYM.

  12. Codes are fixed, one-to-one and unordered. “safe roads save lives” = “an bo ce du”; “safe buses save time” = “an ef ce gi”; “roads need time” = “bo ha gi”; “lives need care” = “du ha jo”. Which code set represents “buses care roads”?

    1. gi jo bo
    2. ef ha bo
    3. ef jo du
    4. ef jo bo
    Show answer

    Answer: (D) ef jo bo

    Explanation: The first and third lines give roads=bo; the second and third give time=gi, so buses=ef. The last line gives care=jo, producing ef jo bo.

  13. A code is 3 times the number of vowels plus the alphabet-rank sum of consonants. Count repeated occurrences. What is the code for KAPURTHALA?

    1. 97
    2. 109
    3. 106
    4. 94
    Show answer

    Answer: (A) 97

    Explanation: There are four vowels, contributing 12. Consonants K,P,R,T,H,L sum to 85, so the code is 97.

  14. A number code moves the last digit to the front and leaves the others in order. What is the code of 50736?

    1. 35076
    2. 07365
    3. 65073
    4. 63705
    Show answer

    Answer: (C) 65073

    Explanation: Move only the final 6 before 5073. This gives 65073.

  15. A six-letter code adds triangular shifts 1,3,6,10,15,21 to successive letters. Decode the stored output KDYLXM.

    1. JASIBR
    2. JASBIR
    3. JASBER
    4. JASBIQ
    Show answer

    Answer: (B) JASBIR

    Explanation: Subtract 1,3,6,10,15,21 position by position. The recovered letters spell JASBIR.

  16. An encoder reverses a word and deletes its new first and last letters. For the seven-letter input TEACHER, which five-letter output remains?

    1. REHCA
    2. HCAET
    3. EHCAE
    4. EACHE
    Show answer

    Answer: (C) EHCAE

    Explanation: TEACHER reverses to REHCAET. Deleting R and T leaves EHCAE.

  17. A word’s code is its first two letters followed by the number of vowel occurrences. A,E,I,O,U are vowels. Select the code for ROPAR.

    1. RO1
    2. RO3
    3. RO2
    4. RA2
    Show answer

    Answer: (C) RO2

    Explanation: The first two letters are RO. O and A are two vowels, giving RO2.

  18. A six-letter word is first shifted by +3,-2,+3,-2,+3,-2; then each adjacent pair of coded letters is exchanged. What is the final output for MUKESH?

    1. XKHIKQ
    2. SPCNFV
    3. PSNCVF
    4. SPNCVF
    Show answer

    Answer: (B) SPCNFV

    Explanation: The alternating shifts first give PSNCVF. Exchange pairs PS,NC,VF to get SPCNFV.

  19. For original digits, add 2 to even digits and subtract 3 from odd digits, wrapping within 0–9 independently. Which string codes 907264?

    1. 624486
    2. 124486
    3. 624448
    4. 624489
    Show answer

    Answer: (A) 624486

    Explanation: 9,0,7,2,6,4 become 6,2,4,4,8,6. No carries are used, so the code is 624486.

  20. A numeric message gives cumulative rank sums: 13,14,27,39,40. Each later total includes all earlier letters. What five-letter word does it represent?

    1. MAMKA
    2. NANMB
    3. MALMA
    4. MAMLA
    Show answer

    Answer: (D) MAMLA

    Explanation: Successive differences are 13,1,13,12,1. These ranks spell MAMLA.

  21. Base: K→%,A→3,N→8,E→7,R→9. Test original KANER and apply all actions in order: (1) if both endpoints are consonants, rotate the base code one place right; (2) if there are exactly two original vowels, replace their codes by # at their CURRENT positions; (3) if the original middle letter is a consonant, move the first code to the end. What results?

    1. %#8#9
    2. %38#9
    3. 9%#8#
    4. %#8#7
    Show answer

    Answer: (A) %#8#9

    Explanation: Rotate %3879 to 9%387. The moved vowel codes become #, giving 9%#8#; moving its first code to the end yields %#8#9.

  22. The key is unknown, but every letter of a word must move by the SAME cyclic shift. Which candidate can be a code of SOLAN?

    1. AWTIA
    2. AWUJV
    3. AWTIO
    4. AWTIV
    Show answer

    Answer: (D) AWTIV

    Explanation: Compare position-wise differences. Only AWTIV gives +8 at every position; different shifts in one candidate disqualify it.

  23. Three alphabet-opposite pairs below are correct and one is wrong. Identify the wrong pair.

    1. L→O
    2. W→D
    3. G→S
    4. J→Q
    Show answer

    Answer: (C) G→S

    Explanation: Opposite ranks must add to 27. G=7 pairs with T=20, so G→S is wrong.

  24. For an even-length word, multiply each rank by its mirror partner’s rank and add, counting each mirror pair once. Which number codes AMRITSAR?

    1. 553
    2. 561
    3. 1106
    4. 99
    Show answer

    Answer: (A) 553

    Explanation: Mirror pairs are A–R,M–A,R–S,I–T. The sum is 1×18+13×1+18×19+9×20=553.

  25. Each stored value is the ordinary rank of a letter minus the rank of the preceding letter; the first value is the first letter’s ordinary rank. What sequence stores PATNA?

    1. 16, -15, 19, 6, -13
    2. 16, 15, 19, 6, 13
    3. 16, 1, 20, 14, 1
    4. 16, -15, 19, -6, -13
    Show answer

    Answer: (D) 16, -15, 19, -6, -13

    Explanation: Use signed differences: 16,1-16,20-1,14-20,1-14. The groups are 16, -15, 19, -6, -13.
