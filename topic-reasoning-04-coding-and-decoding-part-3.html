Question bank

Coding and Decoding MCQ – Part 3: all 25 questions

Read the question, pick an option, then open the answer.

  1. A filing code places all letters in descending alphabetical order, retaining duplicates. Which filing code belongs to AMBALA?

    1. AAABLM
    2. MLBAAA
    3. MLABAA
    4. MLBAA
    Show answer

    Answer: (B) MLBAAA

    Explanation: Arrange M,L,B,A,A,A from highest rank to lowest. The code is MLBAAA.

  2. A fixed mapping allows two letters to share a code: P→#, Q→#, R→@, S→7. How many different three-letter originals have code #@#?

    1. 2
    2. 4
    3. 8
    4. 3
    Show answer

    Answer: (B) 4

    Explanation: Each # can independently be P or Q; @ must be R. Thus 2×1×2=4 originals are possible.

  3. A three-letter code is (sum of ranks)² minus the sum of their squares. What number represents JET?

    1. 525
    2. 350
    3. 700
    4. 1225
    Show answer

    Answer: (C) 700

    Explanation: Use 2(ab+bc+ac): 2×(10×5+5×20+10×20)=700. This avoids squaring 35.

  4. A numeric code writes twice each ordinary alphabet rank, as separate groups. Which sequence represents BINA?

    1. 4-16-28-2
    2. 4-18-28-2
    3. 4-18-26-2
    4. 2-9-14-1
    Show answer

    Answer: (B) 4-18-28-2

    Explanation: Double 2,9,14,1 to obtain 4-18-28-2.

  5. For a three-digit number abc, its code is a×c+b². Which listed number has code 34?

    1. 526
    2. 624
    3. 352
    4. 425
    Show answer

    Answer: (A) 526

    Explanation: 526 gives 5×6+2²=34. The other codes are 31,24 and 28.

  6. Base: I→3, A→6, M→%, 2→K, 7→@. Test original input I2M7A. In order: if the first character is a vowel, replace its code by #; if the last character is a vowel, exchange the CURRENT endpoint codes; finally replace codes of original even digits by $. What is the result?

    1. #$%@6
    2. 6$%@3
    3. 6K%@#
    4. 6$%@#
    Show answer

    Answer: (D) 6$%@#

    Explanation: Start with 3K%@6; first get #K%@6, then 6K%@#, then replace 2’s code. The final result is 6$%@#.

  7. Fixed word codes ignore token order: “canals bring water” = “de hu pa”; “rivers carry water” = “jo pa si”; “canals carry crops” = “hu si ve”. A clerk records “rivers bring crops” as “jo hu ve”. Which token should replace the mistaken hu?

    1. de
    2. jo
    3. si
    4. pa
    Show answer

    Answer: (A) de

    Explanation: The overlaps give water=pa, canals=hu and carry=si. Bring is therefore de, so replace hu with de.

  8. The alphabet is numbered cyclically from L=1, M=2, through Z=15, A=16, and K=26. What are the numbers for LUCK?

    1. 1-9-18-26
    2. 1-10-17-26
    3. 1-10-18-26
    4. 12-21-3-11
    Show answer

    Answer: (C) 1-10-18-26

    Explanation: Use ((ordinary rank-12) mod 26)+1. L,U,C,K become 1,10,18,26.

  9. A six-letter input first swaps adjacent pairs, then rotates the resulting string one place left. The stored result is SKNRAA. What was the input?

    1. SAKNAR
    2. SANKAR
    3. KARSAN
    4. ASKNRA
    Show answer

    Answer: (B) SANKAR

    Explanation: Rotate SKNRAA one place right to recover ASKNRA. Swap each adjacent pair to obtain SANKAR.

  10. Letters at odd places move -2; those at even places move +4. A trainee writes BALDEV→ZEJHCR. At which single place is the trainee’s code wrong?

    1. 3
    2. 2
    3. 6
    4. 5
    Show answer

    Answer: (C) 6

    Explanation: The correct code is ZEJHCZ. Only place 6 should be Z instead of R.

  11. A station’s name is stored by full reversal as ARGOM. Recover the name.

    1. MAGRO
    2. ARGOM
    3. MORGA
    4. MOGRA
    Show answer

    Answer: (D) MOGRA

    Explanation: Reverse ARGOM once more to recover MOGRA.

  12. Encoding uses +1,-2,+3,-4,+5,-6 from left to right. For NAGPUR, an operator reports OYJLAL. Which position alone requires correction?

    1. 6
    2. 4
    3. 2
    4. 5
    Show answer

    Answer: (D) 5

    Explanation: The correct code is OYJLZL: U at place 5 moves +5 to Z. Only place 5 differs.

  13. Every letter of JIND moves the same positive number of places to give ONSI. What is that forward shift?

    1. 6
    2. 21
    3. 5
    4. 4
    Show answer

    Answer: (C) 5

    Explanation: J=10 becomes O=15, a forward shift of 5. The other three pairs confirm +5.

  14. For a five-letter word, leave the first and last letters untouched and reverse only the middle three. What will the encoder produce for SIKAR?

    1. RAKIS
    2. SKIAR
    3. SAKIR
    4. SIKAR
    Show answer

    Answer: (C) SAKIR

    Explanation: Keep S and R fixed; reverse IKA to AKI. Join S+AKI+R = SAKIR.

  15. A game’s dictionary is LEFT→RIGHT, RIGHT→BACK, BACK→FRONT, FRONT→LEFT. Which announcer’s one-step replacement violates this dictionary?

    1. LEFT→BACK
    2. FRONT→LEFT
    3. RIGHT→BACK
    4. BACK→FRONT
    Show answer

    Answer: (A) LEFT→BACK

    Explanation: LEFT is assigned RIGHT after one replacement. Reaching BACK would require a second replacement, so LEFT→BACK violates the one-step rule.

  16. Columns are 2,4,6 and rows are 1,3,5. Row 1: S,A,R; row 3: I,N,D; row 5: R,A,N. A pair always gives row then column. Decode 16-32-36-54.

    1. SINA
    2. RADI
    3. RINA
    4. RIDA
    Show answer

    Answer: (D) RIDA

    Explanation: Using the actual labels, 16=R,32=I,36=D and 54=A. The result is RIDA.

  17. A word is converted to reverse alphabet values, then each value is multiplied by its left-hand place number. No wraparound is used. Decode 9-52-57-72.

    1. RAHI
    2. RAHJ
    3. RAKI
    4. IZSR
    Show answer

    Answer: (A) RAHI

    Explanation: Divide 9,52,57,72 by 1,2,3,4 to get 9,26,19,18. Subtract each from 27 to recover R,A,H,I.

  18. Take alphabet opposites of FATE, reverse the four-letter result, then add +1,+2,+3,+4 from the left. Which final code is obtained?

    1. UEWQ
    2. WHAV
    3. VBJZ
    4. WICY
    Show answer

    Answer: (D) WICY

    Explanation: Opposites give UZGV; reversal gives VGZU. Adding 1,2,3,4 produces WICY.

  19. A word code has two fields: the number of letters that occur exactly once, then the repeated letter with the highest alphabet rank. A letter repeated three times still counts as repeated. Code TARNTARAN.

    1. 1T
    2. 4T
    3. 0T
    4. 0R
    Show answer

    Answer: (C) 0T

    Explanation: A occurs three times, and T,R,N each twice. No letter occurs once; the highest-ranked repeated letter is T, giving 0T.

  20. Successive letters move forward by 1,3,5,7 places. Which final letter completes the code of ROPA as S R U _ (spaces separate letters)?

    1. E
    2. G
    3. I
    4. H
    Show answer

    Answer: (D) H

    Explanation: The fourth letter A moves +7: 1+7=8=H. The earlier shifts give S,R,U.

  21. Codes are fixed, one-to-one and unordered: “young players train” = “xa bu li”; “players win medals” = “bu fo ne”; “young teams win” = “li ga fo”; “teams train daily” = “ga xa ru”. Remove the code for “medals” from the code set for “medals young daily”. Which pair remains?

    1. li ru
    2. ne ru
    3. li ga
    4. xa ru
    Show answer

    Answer: (A) li ru

    Explanation: Elimination gives young=li, teams=ga, train=xa and daily=ru. Removing medals leaves the pair li ru.

  22. Codes distinguish case: a→%, A→7, m→2, M→#. Which code represents aMA exactly as written?

    1. %27
    2. %#%
    3. %#7
    4. 7#7
    Show answer

    Answer: (C) %#7

    Explanation: Read case as well as letter identity: a→%, M→#, A→7. The code is %#7.

  23. An eight-letter code alternates two fixed shifts. MARIGOLD becomes PZUHJNOC. Using those shifts, encode CHANDPUR and report only places 2,4,6,8.

    1. GMSQ
    2. GMOQ
    3. GMOR
    4. KQSU
    Show answer

    Answer: (B) GMOQ

    Explanation: The example gives +3,-1 alternately. The requested even places come from H,N,P,R shifted -1, giving GMOQ.

  24. A uniform +9 encoder is applied three times to the same five-letter string. Starting with DANCE, what is the final string?

    1. VSFUW
    2. EBODF
    3. MJWLN
    4. DANCE
    Show answer

    Answer: (B) EBODF

    Explanation: Three applications give +27, equivalent to +1 after a full alphabet cycle. DANCE becomes EBODF.

  25. For a four-letter word, the code is the sum of ranks at odd places minus the sum at even places. Find the code of KOTA.

    1. 15
    2. 47
    3. -15
    4. 5
    Show answer

    Answer: (A) 15

    Explanation: Odd places give K+T=31; even places give O+A=16. The code is 31-16=15.
