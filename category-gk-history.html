All about History

Where this lane sits inside General Knowledge.

History is a memory subject with a shape. Punjab's own arc, the Sikh period and the freedom movement sit alongside the national sequence, and examiners tend to ask about turning points rather than minor details - which means the same handful of events repeat across papers.

Build a timeline rather than a list of facts, then test it here. When an answer costs you time, write the missing link as one line and add it back into your timeline the same day.

This lane sits inside General Knowledge (6 lanes in total), so it stays narrow on purpose: 0 topic sets and 0 questions currently publish under History. Every question is timed at 30 seconds, carries four options and explains why the right answer is right.

Run a set untimed first to find the gaps, then repeat it against the clock. The questions you miss twice are your revision list - keep them to one line each and revise the file the night before the paper.
