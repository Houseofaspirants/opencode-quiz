Question bank

Coding and Decoding MCQ – Part 4: all 25 questions

Read the question, pick an option, then open the answer.

  1. Use row then column. Columns: 0,1,2; row 0=A,B,A; row 1=C,A,D; row 2=B,D,C. How many coordinate sequences code ABACA if no cell may be reused and the FIRST A must come from row 0?

    1. 24
    2. 18
    3. 16
    4. 12
    Show answer

    Answer: (C) 16

    Explanation: The first A has 2 choices; the other A cells can be arranged in 2×1 ways. B and C each have 2 choices, so 2×2×1×2×2=16.

  2. The same one-to-one character code gives MELA→4@7# and AMAR→#4#8. Which extra mapping must be wrong?

    1. E→@
    2. R→7
    3. A→#
    4. L→7
    Show answer

    Answer: (B) R→7

    Explanation: The examples fix M=4,E=@,L=7,A=#,R=8. Therefore R→7 conflicts with R→8.

  3. Base: A→1,I→2,T→6,R→8,N→7,U→9. Apply only the first matching rule: (1) first letter vowel and last consonant: exchange endpoint codes, then reverse the interior codes; (2) both endpoints vowels: replace their codes by #; (3) otherwise retain the base. Encode ARITNUT.

    1. 6976281
    2. 1826796
    3. 6826791
    4. 1976286
    Show answer

    Answer: (A) 6976281

    Explanation: Base code is 1826796. Rule 1 swaps the endpoints to 6826791, then reverses the interior 82679 to 97628, giving 6976281.

  4. A fixed shift codes ZIRA as ENWF. Which additional word–code pair follows precisely the same shift?

    1. SUNAM → VXQDP
    2. BANGA → GFSLF
    3. MALER → QEPIV
    4. RAJPURA → VEPTYVE
    Show answer

    Answer: (B) BANGA → GFSLF

    Explanation: Z→E means +5 with wraparound. BANGA shifted +5 is GFSLF; the other entries do not use +5 throughout.

  5. Two dictionaries are used in order. First: RICE→WHEAT, WHEAT→MAIZE. Second: WHEAT→PULSE, MAIZE→RICE. Apply one replacement in each dictionary to the real item RICE. Which final label results?

    1. RICE
    2. PULSE
    3. MAIZE
    4. WHEAT
    Show answer

    Answer: (B) PULSE

    Explanation: The first dictionary sends RICE to WHEAT. The second sends that WHEAT to PULSE.

  6. One of these inputs remains unchanged when its entire letter order is reversed. Which is it?

    1. NARAM
    2. NAYAM
    3. NAVAN
    4. NAGAR
    Show answer

    Answer: (C) NAVAN

    Explanation: NAVAN reads N-A-V-A-N in both directions. The other strings have different endpoint or inner pairs.

  7. A four-place block (+a,0,-a,+b) repeats from the left, where a and b are positive integers below 6. SURINDER becomes UUPJPDCS. Infer a and b, then code CHANDIGARH using the same block. Which output is correct?

    1. EHYOFIEBTH
    2. DHZPEIFCSH
    3. EHYPFIECTH
    4. HTBEIFOYHE
    Show answer

    Answer: (A) EHYOFIEBTH

    Explanation: S→U gives a=2; I→J gives b=1, and the other pairs confirm the block. Repeat +2,0,-2,+1 to obtain EHYOFIEBTH.

  8. A fixed forward shift of 6 is used on FARIDKOT. How many vowels are in the code? Count A,E,I,O,U as vowels.

    1. 0
    2. 3
    3. 2
    4. 1
    Show answer

    Answer: (C) 2

    Explanation: The shifted word is LGXOJQUZ. It contains O and U, so there are 2 vowels.

  9. To encode a seven-letter word, reverse it, move every letter -2, then reverse only the first three coded letters. What is the final output for HARVEST?

    1. CQRTPYF
    2. RQCTPYF
    3. FYPTCQR
    4. VUGXTCJ
    Show answer

    Answer: (A) CQRTPYF

    Explanation: Reversal and -2 give RQCTPYF. Reverse its first three letters only to obtain CQRTPYF.

  10. Encoding stores the sum of the first two letter ranks, then each later rank separately. The first letter is fixed as B. Decode 10-15-16-1-12.

    1. BJOPAL
    2. BIPOLA
    3. BHOPAL
    4. BHOPLA
    Show answer

    Answer: (C) BHOPAL

    Explanation: B=2, so the second rank is 10-2=8=H. The later ranks give O,P,A,L, producing BHOPAL.

  11. For a six-letter word, the code is the absolute difference between the square of the odd-place rank sum and the square of the even-place rank sum. Find the code of NAGPUR.

    1. 2989
    2. 5929
    3. 49
    4. 539
    Show answer

    Answer: (D) 539

    Explanation: Odd places sum to 14+7+21=42; even places sum to 1+16+18=35. Use 42²-35²=(42-35)(42+35)=539.

  12. For each letter, use ordinary rank if the word place is odd and reverse rank if it is even. No reordering is allowed. Find the number sequence for SANGRUR.

    1. 19-26-14-20-18-6-9
    2. 8-1-13-7-9-21-9
    3. 19-1-14-7-18-21-18
    4. 19-26-14-20-18-6-18
    Show answer

    Answer: (D) 19-26-14-20-18-6-18

    Explanation: Odd places give 19,14,18,18; even places give 26,20,6. Interleave them as 19-26-14-20-18-6-18.

  13. A three-letter word is represented by the product of its alphabet ranks. Which number represents FAD?

    1. 11
    2. 24
    3. 10
    4. 36
    Show answer

    Answer: (B) 24

    Explanation: F=6,A=1,D=4. Multiply 6×1×4=24.

  14. A fixed one-to-one word code ignores order: “silver coins shine” = “ra pu te”; “gold coins shine” = “ki te pu”; “silver lamps glow” = “ra mo sa”. Which added observation would uniquely identify the individual code for “shine”?

    1. coins glow = pu sa
    2. gold silver = ki ra
    3. lamps glow = mo sa
    4. coins shine = pu te
    Show answer

    Answer: (A) coins glow = pu sa

    Explanation: Initially coins and shine are unresolved as pu,te. “coins glow = pu sa” fixes coins=pu, leaving shine=te; the other observations do not split that pair.

  15. Opposite-letter coding is applied twice to PONDA, then a uniform +2 shift is applied. Which result follows?

    1. NMLBY
    2. KLMWZ
    3. IJKUX
    4. RQPFC
    Show answer

    Answer: (D) RQPFC

    Explanation: Taking opposites twice restores every original letter. Only +2 remains, giving RQPFC.

  16. Move every letter of HISAR 2 places backward. What are the first and last letters of the resulting code, in that order?

    1. F T
    2. J T
    3. G Q
    4. F P
    Show answer

    Answer: (D) F P

    Explanation: H-2=F and R-2=P. The requested endpoint pair is F P.

  17. An access code is made by sorting the digits of 804272 in ascending order, retaining all digits, then moving the first digit to the end. What is the six-position code?

    1. 022478
    2. 224780
    3. 247820
    4. 224870
    Show answer

    Answer: (B) 224780

    Explanation: Ascending order is 022478. Moving its leading 0 to the end gives 224780.

  18. A letter is stored as its ordinary rank followed by its reverse rank, separated by /. Which stored pair represents V?

    1. 5/22
    2. 22/5
    3. 21/6
    4. 22/4
    Show answer

    Answer: (B) 22/5

    Explanation: V has ordinary rank 22 and reverse rank 27-22=5. Its pair is 22/5.

  19. Starting at the RIGHTMOST letter, apply +2,-3,+2,-3 repeatedly. Keep the word order when writing the code. What is the code of GARIMA?

    1. IXTFOX
    2. DXOFJX
    3. DCOKJC
    4. ICTKOC
    Show answer

    Answer: (C) DCOKJC

    Explanation: For six letters, the left-to-right shifts are -3,+2,-3,+2,-3,+2. The result is DCOKJC.

  20. A five-letter word uses shifts +5,+4,+3,+2,+1. All but one pair below follow that rule. Which pair is faulty?

    1. NEERA → SIHTB
    2. MOHAN → RSKCO
    3. KAMAL → PEPCM
    4. ROPAR → WSSCT
    Show answer

    Answer: (D) ROPAR → WSSCT

    Explanation: Applying +5,+4,+3,+2,+1 to ROPAR gives WSSCS, so the listed final T is wrong.

  21. A fixed printer code gives NAVAN→6#8#6. Which single character is the code for V?

    1. 8
    2. V
    3. #
    4. 6
    Show answer

    Answer: (A) 8

    Explanation: The middle letter V corresponds to the middle code character 8.

  22. A word code records length followed by # if the word contains any repeated letter, otherwise @. Which code belongs to BARNALA?

    1. 7#
    2. 7@
    3. 3#
    4. 6#
    Show answer

    Answer: (A) 7#

    Explanation: BARNALA contains seven letters and repeats A. Hence its code is 7#.

  23. Each word has a fixed code; order is arbitrary. “read every morning” = “ab cd ef”; “write every evening” = “gh cd ij”; “read and write” = “ab kl gh”. Which token cannot represent any word in “every and read”?

    1. cd
    2. kl
    3. gh
    4. ab
    Show answer

    Answer: (C) gh

    Explanation: The phrase uses every=cd, and=kl and read=ab. Token gh belongs to write, which is absent.

  24. A seven-letter encoder writes even-position letters in reverse order, followed by odd-position letters in their original order. Select the output for MALERKA.

    1. MLRAKEA
    2. AEKMLRA
    3. AKEMLRA
    4. KEAMLRA
    Show answer

    Answer: (D) KEAMLRA

    Explanation: Even places 2,4,6 hold A,E,K; reversing gives K,E,A. Odd places give M,L,R,A, so the code is KEAMLRA.

  25. Letters are processed in order from BOTH ends: first, last, second, second-last, and so on. They move +1,+2,+3,+4,+5,+6 in that processing order, but are written back in their original positions. Code LAVISH.

    1. MCYMXN
    2. RFZLUI
    3. MDAKWN
    4. MDAOWJ
    Show answer

    Answer: (D) MDAOWJ

    Explanation: The original positions receive shifts +1,+3,+5,+6,+4,+2. LAVISH becomes MDAOWJ.
