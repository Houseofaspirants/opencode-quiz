Question bank

Decimal Fractions MCQ – Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. Which decimal multiplier represents a decrease of 17.5%?

    1. 0.9825
    2. 0.175
    3. 1.175
    4. 0.825
    Show answer

    Answer: (D) 0.825

    Explanation: The remaining percentage is 100 − 17.5 = 82.5%, so the multiplier is 0.825.

  2. Which is the correct ascending order of −0.48, −1/2 and −0.485?

    1. −0.48 < −0.485 < −1/2
    2. −1/2 < −0.485 < −0.48
    3. −0.485 < −1/2 < −0.48
    4. −1/2 < −0.48 < −0.485
    Show answer

    Answer: (B) −1/2 < −0.485 < −0.48

    Explanation: Write −1/2 as −0.500; for negative numbers, the one with the larger absolute value is smaller. Thus −0.500 < −0.485 < −0.480.

  3. Evaluate (0.0048 × 0.075 × 1.6) ÷ (0.012 × 0.002).

    1. 24
    2. 240
    3. 0.24
    4. 2.4
    Show answer

    Answer: (A) 24

    Explanation: Cancel in pairs: 0.0048/0.012 = 0.4 and 0.075/0.002 = 37.5; then 0.4 × 37.5 × 1.6 = 24.

  4. Write 1.0(27), where 27 repeats, as a fraction in lowest terms.

    1. 34/33
    2. 127/110
    3. 113/110
    4. 1027/990
    Show answer

    Answer: (C) 113/110

    Explanation: The fractional part is 27/990 = 3/110, so the number is 1 + 3/110 = 113/110.

  5. What is the decimal form of 23/125?

    1. 0.0184
    2. 0.184
    3. 1.84
    4. 0.23
    Show answer

    Answer: (B) 0.184

    Explanation: Multiply both numerator and denominator by 8: 23/125 = 184/1000 = 0.184.

  6. A milk seller mixes 7.25 litres of milk with 2.75 litres of water and fills bottles of 0.4 litre each. How many full bottles are filled?

    1. 40
    2. 2.5
    3. 20
    4. 25
    Show answer

    Answer: (D) 25

    Explanation: Total mixture = 7.25 + 2.75 = 10 litres; bottles = 10 ÷ 0.4 = 25.

  7. How many of 0.43, 7/16, 0.44 and 4/9 lie strictly between 3/7 and 0.445?

    1. 1
    2. 2
    3. 4
    4. 3
    Show answer

    Answer: (C) 4

    Explanation: 3/7 is about 0.428571, while the four numbers are 0.43, 0.4375, 0.44 and about 0.444444. All four lie inside the interval.

  8. Find x: (x + 3.75) ÷ 0.25 = 26.4.

    1. 2.85
    2. 6.6
    3. 10.35
    4. 101.85
    Show answer

    Answer: (A) 2.85

    Explanation: x + 3.75 = 26.4 × 0.25 = 6.6, so x = 6.6 − 3.75 = 2.85.

  9. What is 68.4 ÷ 10000?

    1. 0.00684
    2. 0.000684
    3. 0.684
    4. 0.0684
    Show answer

    Answer: (A) 0.00684

    Explanation: Dividing by 10000 shifts the decimal point 4 places left: 68.4 ÷ 10000 = 0.00684.

  10. Evaluate 12.48 × 0.25 + 6.24 × 0.5.

    1. 0.624
    2. 3.12
    3. 6.24
    4. 9.36
    Show answer

    Answer: (C) 6.24

    Explanation: Multiplication by 0.25 means division by 4, so both terms equal 3.12; their sum is 6.24.

  11. If x = 0.(36), where 36 repeats, find (1 + x) ÷ (1 − x).

    1. 7/15
    2. 15/11
    3. 11/7
    4. 15/7
    Show answer

    Answer: (D) 15/7

    Explanation: x = 36/99 = 4/11; hence (1 + x)/(1 − x) = (15/11)/(7/11) = 15/7.

  12. Which fraction is greater than 0.62 but less than 0.625?

    1. 31/50
    2. 28/45
    3. 19/30
    4. 5/8
    Show answer

    Answer: (B) 28/45

    Explanation: 28/45 = 0.62222 recurring, which lies strictly between 0.62 and 0.625.

  13. Evaluate 0.125 × 48.

    1. 12
    2. 0.6
    3. 6
    4. 3
    Show answer

    Answer: (C) 6

    Explanation: 0.125 = 1/8, so 0.125 × 48 = 48 ÷ 8 = 6.

  14. A bus travels 16.8 km on 1.2 litres of diesel. At the same rate, how many km will it travel on 3.5 litres?

    1. 49
    2. 58.8
    3. 40
    4. 4.9
    Show answer

    Answer: (A) 49

    Explanation: Mileage = 16.8 ÷ 1.2 = 14 km per litre; distance = 14 × 3.5 = 49 km.

  15. Find the positive value of x if (x + 0.4)² − (x − 0.4)² = 3.84.

    1. 1.2
    2. 2.4
    3. 9.6
    4. 4.8
    Show answer

    Answer: (B) 2.4

    Explanation: Use (u + v)² − (u − v)² = 4uv: 1.6x = 3.84, so x = 2.4.

  16. If 736 × 28 = 20608, find 0.0736 × 2.8.

    1. 20.608
    2. 2.0608
    3. 0.020608
    4. 0.20608
    Show answer

    Answer: (D) 0.20608

    Explanation: The factors have a total of 5 decimal places, so 20608 becomes 0.20608.

  17. If x = 0.(9), where 9 repeats, find 1 − x.

    1. 0.1
    2. 0.01
    3. 1/9
    4. 0
    Show answer

    Answer: (D) 0

    Explanation: x = 9/9 = 1, so 1 − x = 0.

  18. If 6.04 = 6 + a/10 + b/100, where a and b are decimal digits, find a + b.

    1. 40
    2. 4
    3. 6
    4. 10
    Show answer

    Answer: (B) 4

    Explanation: The tenths digit is a = 0 and the hundredths digit is b = 4; hence a + b = 4.

  19. A 24.5 m ribbon is cut into 0.6 m pieces. Each cut wastes 0.01 m, and each usable piece needs one cut. What is the maximum number of full pieces?

    1. 40
    2. 42
    3. 41
    4. 39
    Show answer

    Answer: (A) 40

    Explanation: Each piece uses 0.6 + 0.01 = 0.61 m. Since 40 × 0.61 = 24.4 and 41 × 0.61 = 25.01, the maximum is 40.

  20. Evaluate (5.7 + 2.3) × 0.45 − 0.18 ÷ 0.06.

    1. 3.3
    2. 6.6
    3. 0.6
    4. 0.06
    Show answer

    Answer: (C) 0.6

    Explanation: The sum in brackets is 8, so the expression becomes 3.6 − 3 = 0.6.

  21. Which is the smallest of the following?

    1. 0.91
    2. 0.909
    3. 0.9099
    4. 10/11
    Show answer

    Answer: (B) 0.909

    Explanation: 10/11 = 0.90909 recurring, which is slightly greater than 0.909; both 0.9099 and 0.91 are also greater.

  22. A price of ₹640 is multiplied by 1.125. By how many rupees does it increase?

    1. 8
    2. 72
    3. 720
    4. 80
    Show answer

    Answer: (D) 80

    Explanation: Only the extra multiplier matters: increase = 640 × (1.125 − 1) = 640 × 0.125 = ₹80.

  23. A quotient is 0.072. If its dividend is multiplied by 100 and its divisor is divided by 10, what is the new quotient?

    1. 0.72
    2. 7.2
    3. 72
    4. 720
    Show answer

    Answer: (C) 72

    Explanation: The quotient is multiplied by 100 × 10 = 1000, so the new quotient is 0.072 × 1000 = 72.

  24. The sum of two positive numbers is 0.9 and their difference is 0.3. Find their product.

    1. 0.18
    2. 0.09
    3. 0.27
    4. 0.36
    Show answer

    Answer: (A) 0.18

    Explanation: Product = [(sum)² − (difference)²]/4 = (0.9² − 0.3²)/4 = 0.18.

  25. If p = 0.84, q = −0.31 and r = −0.53, find (p³ + q³ + r³) ÷ (pqr).

    1. −3
    2. 3
    3. 1
    4. 0
    Show answer

    Answer: (B) 3

    Explanation: Since p + q + r = 0, the identity p³ + q³ + r³ = 3pqr gives a quotient of 3.
