Computer System - ਭਾਗ 1 ਬਾਰੇ

ਸੈੱਟ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ।

ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

ਜਿਹੜਾ ਸਵਾਲ ਦੋ ਵਾਰ ਗਲਤ ਹੋਵੇ, ਉਹਨੂੰ ਆਪਣੀ ਕਾਪੀ ਵਿੱਚ ਲਿਖ ਲਓ - ਪ੍ਰੀਖਿਆ ਤੋਂ ਪਹਿਲਾਂ ਦੁਹਰਾਈ ਲਈ ਇਹੀ ਸਭ ਤੋਂ ਕੰਮ ਦੀ ਸੂਚੀ ਹੈ।

Computer System - ਭਾਗ 1: ਸਾਰੇ 25 ਸਵਾਲ

ਹਰ ਸਵਾਲ ਦਾ ਉੱਤਰ ਅਤੇ ਵਿਆਖਿਆ ਉਸਦੇ ਹੇਠਾਂ ਹੈ।

  1. ਕੰਪਿਊਟਰ ਸਿਸਟਮ ਕਿਹੜੇ ਦੋ ਮੁੱਖ ਭਾਗਾਂ ਤੋਂ ਬਣਿਆ ਹੁੰਦਾ ਹੈ?

    1. ਹਾਰਡਵੇਅਰ ਅਤੇ ਸਾਫ਼ਟਵੇਅਰ
    2. ਇਨਪੁੱਟ ਅਤੇ ਆਊਟਪੁੱਟ
    3. CPU ਅਤੇ ਮਾਨੀਟਰ
    4. RAM ਅਤੇ ROM
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਹਾਰਡਵੇਅਰ ਅਤੇ ਸਾਫ਼ਟਵੇਅਰ

    ਵਿਆਖਿਆ: ਕੰਪਿਊਟਰ ਸਿਸਟਮ ਦੇ ਦੋ ਮੁੱਖ ਭਾਗ ਹਾਰਡਵੇਅਰ ਅਤੇ ਸਾਫ਼ਟਵੇਅਰ ਹਨ, ਜੋ ਮਿਲ ਕੇ ਕੰਮ ਕਰਦੇ ਹਨ।

  2. ਕੰਪਿਊਟਰ ਦੇ ਉਹ ਭੌਤਿਕ ਭਾਗ ਜਿਨ੍ਹਾਂ ਨੂੰ ਦੇਖਿਆ ਅਤੇ ਛੂਹਿਆ ਜਾ ਸਕਦਾ ਹੈ, ਕੀ ਅਖਵਾਉਂਦੇ ਹਨ?

    1. ਸਾਫ਼ਟਵੇਅਰ
    2. ਫਰਮਵੇਅਰ
    3. ਡਾਟਾ
    4. ਹਾਰਡਵੇਅਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਹਾਰਡਵੇਅਰ

    ਵਿਆਖਿਆ: ਹਾਰਡਵੇਅਰ ਕੰਪਿਊਟਰ ਸਿਸਟਮ ਦੇ ਉਹ ਸਾਰੇ ਭੌਤਿਕ ਭਾਗ ਹਨ ਜਿਨ੍ਹਾਂ ਨੂੰ ਦੇਖਿਆ ਅਤੇ ਛੂਹਿਆ ਜਾ ਸਕਦਾ ਹੈ।

  3. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ ਹਾਰਡਵੇਅਰ ਦੀ ਉਦਾਹਰਨ ਹੈ?

    1. MS Word
    2. ਵੈੱਬ ਬ੍ਰਾਊਜ਼ਰ
    3. ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ
    4. ਹਾਰਡ ਡਿਸਕ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਹਾਰਡ ਡਿਸਕ

    ਵਿਆਖਿਆ: ਮਾਨੀਟਰ, ਕੀਬੋਰਡ, ਮਾਊਸ, CPU, ਮਦਰਬੋਰਡ, RAM, ROM, ਹਾਰਡ ਡਿਸਕ, ਪ੍ਰਿੰਟਰ ਅਤੇ ਸਪੀਕਰ ਹਾਰਡਵੇਅਰ ਦੀਆਂ ਉਦਾਹਰਨਾਂ ਹਨ।

  4. ਹਾਰਡਵੇਅਰ ਬਨਾਮ ਸਾਫ਼ਟਵੇਅਰ ਦੀ ਤੁਲਨਾ ਅਨੁਸਾਰ ਕਿਹੜੀ ਵਿਸ਼ੇਸ਼ਤਾ ਸਾਫ਼ਟਵੇਅਰ ਦੀ ਹੈ?

    1. ਭੌਤਿਕ ਤੌਰ 'ਤੇ ਨੁਕਸਾਨਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ
    2. ਭੌਤਿਕ ਨੁਕਸਾਨ ਹੋ ਸਕਦਾ ਹੈ
    3. ਛੂਹਿਆ ਜਾ ਸਕਦਾ ਹੈ
    4. ਭੌਤਿਕ ਭਾਗਾਂ ਤੋਂ ਬਣਿਆ ਹੈ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਭੌਤਿਕ ਤੌਰ 'ਤੇ ਨੁਕਸਾਨਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ

    ਵਿਆਖਿਆ: ਸਾਫ਼ਟਵੇਅਰ ਪ੍ਰੋਗਰਾਮਾਂ ਅਤੇ ਹਦਾਇਤਾਂ ਤੋਂ ਬਣਿਆ ਹੁੰਦਾ ਹੈ, ਇਸਨੂੰ ਛੂਹਿਆ ਨਹੀਂ ਜਾ ਸਕਦਾ ਅਤੇ ਭੌਤਿਕ ਨੁਕਸਾਨ ਨਹੀਂ ਹੁੰਦਾ।

  5. ਹਾਰਡਵੇਅਰ ਬਨਾਮ ਸਾਫ਼ਟਵੇਅਰ ਸਾਰਣੀ ਵਿੱਚ ਇਹਨਾਂ ਵਿੱਚੋਂ ਕਿਸਨੂੰ ਸਾਫ਼ਟਵੇਅਰ ਦੀ ਉਦਾਹਰਨ ਵਜੋਂ ਦਿੱਤਾ ਗਿਆ ਹੈ?

    1. ਕੀਬੋਰਡ
    2. ਮਾਨੀਟਰ
    3. MS Word
    4. ਪ੍ਰਿੰਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) MS Word

    ਵਿਆਖਿਆ: ਸਾਰਣੀ ਵਿੱਚ ਕੀਬੋਰਡ ਨੂੰ ਹਾਰਡਵੇਅਰ ਅਤੇ MS Word ਨੂੰ ਸਾਫ਼ਟਵੇਅਰ ਦੀ ਉਦਾਹਰਨ ਵਜੋਂ ਦਿੱਤਾ ਗਿਆ ਹੈ।

  6. ਕੰਪਿਊਟਰ ਦਾ ਮੁੱਖ ਸਰਕਟ ਬੋਰਡ, ਜੋ ਲਗਭਗ ਸਾਰੇ ਅੰਦਰੂਨੀ ਹਾਰਡਵੇਅਰ ਭਾਗਾਂ ਨੂੰ ਜੋੜਦਾ ਅਤੇ ਸੰਭਾਲਦਾ ਹੈ, ਕਿਹੜਾ ਹੈ?

    1. ਐਕਸਪੈਂਸ਼ਨ ਕਾਰਡ
    2. ਹੀਟ ਸਿੰਕ
    3. SMPS
    4. ਮਦਰਬੋਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਮੁੱਖ ਸਰਕਟ ਬੋਰਡ ਹੈ ਜੋ ਲਗਭਗ ਸਾਰੇ ਅੰਦਰੂਨੀ ਹਾਰਡਵੇਅਰ ਭਾਗਾਂ ਨੂੰ ਜੋੜਦਾ ਹੈ।

  7. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ ਮਦਰਬੋਰਡ ਦਾ ਦੂਜਾ ਨਾਮ ਹੈ?

    1. ਐਕਸਪੈਂਸ਼ਨ ਬੋਰਡ
    2. ਸਾਊਂਡ ਬੋਰਡ
    3. ਸਿਸਟਮ ਬੋਰਡ
    4. ਨੈੱਟਵਰਕ ਬੋਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਸਿਸਟਮ ਬੋਰਡ

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਦੇ ਹੋਰ ਨਾਮ ਮੇਨਬੋਰਡ, ਸਿਸਟਮ ਬੋਰਡ ਅਤੇ ਪ੍ਰਿੰਟਿਡ ਸਰਕਟ ਬੋਰਡ (PCB) ਹਨ।

  8. ਮਦਰਬੋਰਡ ਨੂੰ PCB ਵੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ। PCB ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Primary Circuit Board
    2. Power Control Board
    3. Printed Circuit Board
    4. Processor Connection Board
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Printed Circuit Board

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਨੂੰ PCB – Printed Circuit Board ਵੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ।

  9. ਕਿਹੜੇ ਭਾਗ ਨੂੰ ਕੰਪਿਊਟਰ ਸਿਸਟਮ ਦਾ 'ਦਿਲ' ਜਾਂ 'ਰੀੜ੍ਹ ਦੀ ਹੱਡੀ' ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. ਮਦਰਬੋਰਡ
    2. CPU
    3. ਮਾਨੀਟਰ
    4. ਹਾਰਡ ਡਿਸਕ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: ਮਹੱਤਵਪੂਰਨ ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: ਮਦਰਬੋਰਡ = ਕੰਪਿਊਟਰ ਸਿਸਟਮ ਦਾ ਦਿਲ/ਰੀੜ੍ਹ ਦੀ ਹੱਡੀ।

  10. ਮਦਰਬੋਰਡ ਕੰਪਿਊਟਰ ਦੇ ________ ਵਜੋਂ ਕੰਮ ਕਰਦਾ ਹੈ।

    1. ਬਿਜਲੀ ਉਤਪਾਦਕ
    2. ਸਥਾਈ ਸਟੋਰੇਜ
    3. ਡਿਸਪਲੇ ਯੂਨਿਟ
    4. ਸੰਚਾਰ ਕੇਂਦਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਸੰਚਾਰ ਕੇਂਦਰ

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਕੰਪਿਊਟਰ ਦੇ ਸੰਚਾਰ ਕੇਂਦਰ ਵਜੋਂ ਕੰਮ ਕਰਦਾ ਹੈ।

  11. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ ਮਦਰਬੋਰਡ ਦੇ ਕਾਰਜ ਵਜੋਂ ਦੱਸਿਆ ਗਿਆ ਹੈ?

    1. AC ਬਿਜਲੀ ਨੂੰ DC ਵਿੱਚ ਬਦਲਣਾ
    2. ਪ੍ਰੋਸੈਸਰ ਲਈ ਸਾਕਟ ਦੇ ਕੇ CPU ਨੂੰ ਥਾਂ ਦੇਣਾ
    3. ਧੁਨੀ ਤਰੰਗਾਂ ਨੂੰ ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਵਿੱਚ ਬਦਲਣਾ
    4. ਫਲੈਸ਼ ਮੈਮਰੀ ਨਾਲ ਡਾਟਾ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸਟੋਰ ਕਰਨਾ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਪ੍ਰੋਸੈਸਰ ਲਈ ਸਾਕਟ ਦੇ ਕੇ CPU ਨੂੰ ਥਾਂ ਦੇਣਾ

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਦੇ ਕਾਰਜ: ਸਾਰੇ ਹਾਰਡਵੇਅਰ ਨੂੰ ਜੋੜਨਾ, ਬਿਜਲੀ ਵੰਡਣਾ, ਸੰਚਾਰ ਸੰਭਵ ਬਣਾਉਣਾ ਅਤੇ CPU ਨੂੰ ਥਾਂ ਦੇਣਾ।

  12. ਮਦਰਬੋਰਡ ਉੱਤੇ ਮੈਮਰੀ ਸਲਾਟ ਮੁੱਖ ਤੌਰ 'ਤੇ ਕੀ ਲਗਾਉਣ ਲਈ ਵਰਤੇ ਜਾਂਦੇ ਹਨ?

    1. ਗ੍ਰਾਫਿਕਸ ਕਾਰਡ
    2. RAM ਮੋਡਿਊਲ
    3. SMPS
    4. CMOS ਬੈਟਰੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) RAM ਮੋਡਿਊਲ

    ਵਿਆਖਿਆ: ਮੈਮਰੀ ਸਲਾਟ RAM ਵਰਗੇ ਮੈਮਰੀ ਮੋਡਿਊਲ (ਅਤੇ ਕੁਝ ਸਿਸਟਮਾਂ ਵਿੱਚ ROM ਮੋਡਿਊਲ) ਲਗਾਉਣ ਲਈ ਵਰਤੇ ਜਾਂਦੇ ਹਨ।

  13. ਮਦਰਬੋਰਡ ਉੱਤੇ ਐਕਸਪੈਂਸ਼ਨ ਸਲਾਟ ਕਿਸ ਲਈ ਵਰਤੇ ਜਾਂਦੇ ਹਨ?

    1. BIOS ਸੈਟਿੰਗਾਂ ਸਟੋਰ ਕਰਨ ਲਈ
    2. AC ਬਿਜਲੀ ਨੂੰ DC ਵਿੱਚ ਬਦਲਣ ਲਈ
    3. ਵਾਧੂ ਕਾਰਡ ਲਗਾ ਕੇ ਨਵੀਆਂ ਹਾਰਡਵੇਅਰ ਸਮਰੱਥਾਵਾਂ ਜੋੜਨ ਲਈ
    4. ਪ੍ਰੋਸੈਸਰ ਨੂੰ ਠੰਢਾ ਕਰਨ ਲਈ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਵਾਧੂ ਕਾਰਡ ਲਗਾ ਕੇ ਨਵੀਆਂ ਹਾਰਡਵੇਅਰ ਸਮਰੱਥਾਵਾਂ ਜੋੜਨ ਲਈ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: ਐਕਸਪੈਂਸ਼ਨ ਸਲਾਟ = ਨਵੀਆਂ ਹਾਰਡਵੇਅਰ ਸਮਰੱਥਾਵਾਂ (ਵਾਧੂ ਕਾਰਡ) ਜੋੜਨ ਲਈ।

  14. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ ਐਕਸਪੈਂਸ਼ਨ ਸਲਾਟ ਵਿੱਚ ਲੱਗਣ ਵਾਲੇ ਕਾਰਡ ਦੀ ਉਦਾਹਰਨ ਹੈ?

    1. CMOS ਬੈਟਰੀ
    2. ਹੀਟ ਸਿੰਕ
    3. ਪਾਵਰ ਕਨੈਕਟਰ
    4. TV ਟਿਊਨਰ ਕਾਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) TV ਟਿਊਨਰ ਕਾਰਡ

    ਵਿਆਖਿਆ: ਗ੍ਰਾਫਿਕਸ ਕਾਰਡ, ਸਾਊਂਡ ਕਾਰਡ, ਨੈੱਟਵਰਕ ਕਾਰਡ ਅਤੇ TV ਟਿਊਨਰ ਕਾਰਡ ਐਕਸਪੈਂਸ਼ਨ ਕਾਰਡਾਂ ਦੀਆਂ ਉਦਾਹਰਨਾਂ ਹਨ।

  15. ਨੌਰਥਬ੍ਰਿਜ ਇੱਕ ਚਿੱਪਸੈੱਟ ਹੈ ਜੋ ਕਿਨ੍ਹਾਂ ਵਿਚਕਾਰ ਤੇਜ਼-ਗਤੀ ਸੰਚਾਰ ਲਈ ਜ਼ਿੰਮੇਵਾਰ ਹੈ?

    1. ਕੀਬੋਰਡ, ਮਾਊਸ ਅਤੇ ਪ੍ਰਿੰਟਰ
    2. CPU, RAM ਅਤੇ ਗ੍ਰਾਫਿਕਸ ਕੰਟਰੋਲਰ
    3. SMPS ਅਤੇ ਪਾਵਰ ਕਨੈਕਟਰ
    4. ਪੈੱਨ ਡਰਾਈਵ ਅਤੇ ਸਕੈਨਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) CPU, RAM ਅਤੇ ਗ੍ਰਾਫਿਕਸ ਕੰਟਰੋਲਰ

    ਵਿਆਖਿਆ: ਨੌਰਥਬ੍ਰਿਜ CPU, RAM ਅਤੇ ਗ੍ਰਾਫਿਕਸ ਕੰਟਰੋਲਰ ਵਿਚਕਾਰ ਤੇਜ਼-ਗਤੀ ਸੰਚਾਰ ਸੰਭਾਲਦਾ ਹੈ।

  16. ਆਧੁਨਿਕ ਪ੍ਰੋਸੈਸਰ ਅਕਸਰ ਮਦਰਬੋਰਡ ਦੇ ਕਿਹੜੇ ਭਾਗ ਦੇ ਕਾਰਜਾਂ ਨੂੰ CPU ਵਿੱਚ ਹੀ ਸ਼ਾਮਲ ਕਰ ਲੈਂਦੇ ਹਨ?

    1. ਨੌਰਥਬ੍ਰਿਜ
    2. CMOS ਬੈਟਰੀ
    3. SMPS
    4. PS/2 ਪੋਰਟ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਨੌਰਥਬ੍ਰਿਜ

    ਵਿਆਖਿਆ: ਨੋਟ: ਆਧੁਨਿਕ ਪ੍ਰੋਸੈਸਰ ਅਕਸਰ ਨੌਰਥਬ੍ਰਿਜ ਦੇ ਕਾਰਜ CPU ਵਿੱਚ ਹੀ ਸ਼ਾਮਲ ਕਰ ਲੈਂਦੇ ਹਨ।

  17. PCI ਸਲਾਟ ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Peripheral Component Interconnect
    2. Personal Computer Interface
    3. Primary Control Interconnect
    4. Parallel Component Interface
    ਉੱਤਰ ਵੇਖੋ

    ਵਿਆਖਿਆ: PCI = Peripheral Component Interconnect; ਇਹ ਸਾਊਂਡ ਕਾਰਡ, ਮੋਡਮ, ਨੈੱਟਵਰਕ ਕਾਰਡ ਅਤੇ ਵੀਡੀਓ ਕਾਰਡ ਜੋੜਦਾ ਹੈ।

  18. AGP ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Advanced Graphics Processor
    2. Analog Graphics Port
    3. Accelerated Graphics Port
    4. Auxiliary Graphics Panel
    ਉੱਤਰ ਵੇਖੋ

    ਵਿਆਖਿਆ: AGP ਦਾ ਪੂਰਾ ਰੂਪ Accelerated Graphics Port ਹੈ।

  19. AGP ਸਲਾਟ ਖ਼ਾਸ ਤੌਰ 'ਤੇ ਕਿਸ ਲਈ ਬਣਾਇਆ ਗਿਆ ਹੈ?

    2. ਗ੍ਰਾਫਿਕਸ ਕਾਰਡ

    4. ਹਾਰਡ ਡਿਸਕ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਗ੍ਰਾਫਿਕਸ ਕਾਰਡ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: AGP = ਗ੍ਰਾਫਿਕਸ ਕਾਰਡ ਸਲਾਟ।

  20. ਪ੍ਰੋਸੈਸਰ ਦੁਆਰਾ ਪੈਦਾ ਹੋਈ ਗਰਮੀ ਨੂੰ ਸੋਖਣ ਅਤੇ ਬਾਹਰ ਕੱਢਣ ਵਾਲੇ ਧਾਤੂ ਭਾਗ ਨੂੰ ਕੀ ਕਹਿੰਦੇ ਹਨ?

    1. CMOS ਬੈਟਰੀ
    2. ਨੌਰਥਬ੍ਰਿਜ
    3. ਹੀਟ ਸਿੰਕ
    4. ਪਾਵਰ ਕਨੈਕਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਹੀਟ ਸਿੰਕ

    ਵਿਆਖਿਆ: ਹੀਟ ਸਿੰਕ ਪ੍ਰੋਸੈਸਰ ਦੀ ਗਰਮੀ ਨੂੰ ਸੋਖ ਕੇ ਬਾਹਰ ਕੱਢਦਾ ਹੈ ਅਤੇ CPU ਨੂੰ ਜ਼ਿਆਦਾ ਗਰਮ ਹੋਣ ਤੋਂ ਬਚਾਉਂਦਾ ਹੈ।

  21. ਹੀਟ ਸਿੰਕ ਅਕਸਰ ਕਿਸ ਨਾਲ ਮਿਲ ਕੇ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ?

    1. CMOS ਬੈਟਰੀ ਅਤੇ BIOS
    2. SMPS ਅਤੇ ਪਾਵਰ ਕਨੈਕਟਰ
    3. ਮੈਮਰੀ ਸਲਾਟ ਅਤੇ RAM
    4. ਕੂਲਿੰਗ ਫ਼ੈਨ ਅਤੇ ਥਰਮਲ ਪੇਸਟ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਕੂਲਿੰਗ ਫ਼ੈਨ ਅਤੇ ਥਰਮਲ ਪੇਸਟ

    ਵਿਆਖਿਆ: ਹੀਟ ਸਿੰਕ ਅਕਸਰ ਕੂਲਿੰਗ ਫ਼ੈਨ ਅਤੇ ਥਰਮਲ ਪੇਸਟ ਨਾਲ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ।

  22. ਮਦਰਬੋਰਡ ਉੱਤੇ ਪਾਵਰ ਕਨੈਕਟਰ ਬਿਜਲੀ ਕਿੱਥੋਂ ਸਪਲਾਈ ਕਰਦਾ ਹੈ?

    4. ਹੀਟ ਸਿੰਕ

    ਵਿਆਖਿਆ: ਪਾਵਰ ਕਨੈਕਟਰ SMPS ਤੋਂ ਮਦਰਬੋਰਡ ਤੱਕ ਬਿਜਲੀ ਪਹੁੰਚਾਉਂਦਾ ਹੈ।

  23. ਕੰਪਿਊਟਰ ਬੰਦ ਹੋਣ 'ਤੇ ਵੀ BIOS ਸੈਟਿੰਗਾਂ, ਤਾਰੀਖ਼ ਅਤੇ ਸਮਾਂ ਕਿਹੜਾ ਭਾਗ ਸੰਭਾਲ ਕੇ ਰੱਖਦਾ ਹੈ?

    2. SMPS
    3. ਹੀਟ ਸਿੰਕ
    4. ਨੌਰਥਬ੍ਰਿਜ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: CMOS ਬੈਟਰੀ BIOS ਸੈਟਿੰਗਾਂ ਸੰਭਾਲਦੀ ਹੈ; ਇਹ ਤਾਰੀਖ਼, ਸਮਾਂ ਅਤੇ ਹਾਰਡਵੇਅਰ ਸੰਰਚਨਾ ਵੀ ਸਟੋਰ ਕਰਦੀ ਹੈ।

  25. SMPS ਕਿਸ ਨੂੰ ਕਿਸ ਵਿੱਚ ਬਦਲਦਾ ਹੈ?

    2. ਕੰਧ ਦੀ ਸਾਕਟ ਤੋਂ ਆਉਂਦੀ AC ਬਿਜਲੀ ਨੂੰ DC ਬਿਜਲੀ ਵਿੱਚ
    3. ਧੁਨੀ ਤਰੰਗਾਂ ਨੂੰ ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਵਿੱਚ
    4. ਐਨਾਲਾਗ ਸਿਗਨਲਾਂ ਨੂੰ ਡਿਜੀਟਲ ਸਿਗਨਲਾਂ ਵਿੱਚ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਕੰਧ ਦੀ ਸਾਕਟ ਤੋਂ ਆਉਂਦੀ AC ਬਿਜਲੀ ਨੂੰ DC ਬਿਜਲੀ ਵਿੱਚ

    ਵਿਆਖਿਆ: SMPS ਕੰਧ ਦੀ ਸਾਕਟ ਤੋਂ ਆਉਂਦੀ AC ਬਿਜਲੀ ਨੂੰ ਕੰਪਿਊਟਰ ਭਾਗਾਂ ਲਈ ਲੋੜੀਂਦੀ DC ਬਿਜਲੀ ਵਿੱਚ ਬਦਲਦਾ ਹੈ।
