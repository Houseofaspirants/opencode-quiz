ਸੈੱਟ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ।

ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

ਜਿਹੜਾ ਸਵਾਲ ਦੋ ਵਾਰ ਗਲਤ ਹੋਵੇ, ਉਹਨੂੰ ਆਪਣੀ ਕਾਪੀ ਵਿੱਚ ਲਿਖ ਲਓ - ਪ੍ਰੀਖਿਆ ਤੋਂ ਪਹਿਲਾਂ ਦੁਹਰਾਈ ਲਈ ਇਹੀ ਸਭ ਤੋਂ ਕੰਮ ਦੀ ਸੂਚੀ ਹੈ।

ਸੈਂਟਰਲ ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਨਿਟ (CPU) - ਭਾਗ 1: ਸਾਰੇ 25 ਸਵਾਲ

ਹਰ ਸਵਾਲ ਦਾ ਉੱਤਰ ਅਤੇ ਵਿਆਖਿਆ ਉਸਦੇ ਹੇਠਾਂ ਹੈ।

  1. ਕਿਸ ਭਾਗ ਨੂੰ ਅਕਸਰ 'ਕੰਪਿਊਟਰ ਦਾ ਦਿਮਾਗ਼' ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. CPU
    2. ਮਾਨੀਟਰ
    3. ਹਾਰਡ ਡਿਸਕ
    4. ਕੀਬੋਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) CPU

    ਵਿਆਖਿਆ: CPU ਨੂੰ ਕੰਪਿਊਟਰ ਦਾ ਦਿਮਾਗ਼ ਕਿਹਾ ਜਾਂਦਾ ਹੈ ਕਿਉਂਕਿ ਇਹ ਲਗਭਗ ਸਾਰੇ ਪ੍ਰੋਸੈਸਿੰਗ ਕਾਰਜਾਂ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦਾ ਅਤੇ ਕਰਦਾ ਹੈ।

  2. CPU ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Central Program Unit
    2. Control Processing Unit
    3. Central Processing Unit
    4. Computer Processing Unit
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Central Processing Unit

    ਵਿਆਖਿਆ: CPU ਦਾ ਪੂਰਾ ਰੂਪ Central Processing Unit ਹੈ।

  3. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ CPU ਦਾ ਦੂਜਾ ਨਾਮ ਨਹੀਂ ਹੈ?

    1. ਮਦਰਬੋਰਡ
    2. ਪ੍ਰੋਸੈਸਰ
    3. ਸੈਂਟਰਲ ਪ੍ਰੋਸੈਸਰ
    4. ਮਾਈਕ੍ਰੋਪ੍ਰੋਸੈਸਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: CPU ਨੂੰ ਪ੍ਰੋਸੈਸਰ, ਸੈਂਟਰਲ ਪ੍ਰੋਸੈਸਰ ਜਾਂ ਮਾਈਕ੍ਰੋਪ੍ਰੋਸੈਸਰ ਵੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ; ਮਦਰਬੋਰਡ ਉੱਤੇ CPU ਸਾਕਟ ਹੁੰਦੀ ਹੈ।

  4. ਕੱਚੇ ਡਾਟਾ ਨੂੰ ਅਰਥਪੂਰਨ ਜਾਣਕਾਰੀ ਵਿੱਚ ਬਦਲਣਾ CPU ਦਾ ਕਿਹੜਾ ਕਾਰਜ ਹੈ?

    1. ਹਦਾਇਤਾਂ ਲਾਗੂ (execute) ਕਰਨਾ
    2. ਇਨਪੁੱਟ ਅਤੇ ਆਊਟਪੁੱਟ ਡਿਵਾਈਸਾਂ ਦਾ ਪ੍ਰਬੰਧ ਕਰਨਾ
    3. ਸਾਫ਼ਟਵੇਅਰ ਚਲਾਉਣਾ
    4. ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਨਾ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਨਾ

    ਵਿਆਖਿਆ: 'ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਨਾ' ਕਾਰਜ ਅਧੀਨ CPU ਕੱਚੇ ਡਾਟਾ ਨੂੰ ਅਰਥਪੂਰਨ ਜਾਣਕਾਰੀ ਵਿੱਚ ਬਦਲਦਾ ਹੈ।

  5. CPU ਇੱਕ ਖ਼ਾਸ ਸਾਕਟ (CPU Socket) ਵਿੱਚ ਲਗਾਇਆ ਜਾਂਦਾ ਹੈ, ਜੋ ਕਿੱਥੇ ਸਥਿਤ ਹੁੰਦੀ ਹੈ?

    1. ਹਾਰਡ ਡਿਸਕ
    2. RAM ਮੋਡਿਊਲ
    3. ਮਦਰਬੋਰਡ
    4. ਮਾਨੀਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: CPU ਨੂੰ ਰੱਖਣ ਵਾਲੀ CPU ਸਾਕਟ ਮਦਰਬੋਰਡ ਉੱਤੇ ਹੁੰਦੀ ਹੈ।

  6. ਦੁਨੀਆ ਦਾ ਪਹਿਲਾ ਮਾਈਕ੍ਰੋਪ੍ਰੋਸੈਸਰ ਕਿਹੜਾ ਸੀ?

    1. Intel 4004
    2. Intel 8086
    3. Intel Core i3
    4. AMD Ryzen 3

    ਸਹੀ ਉੱਤਰ: (A) Intel 4004

    ਵਿਆਖਿਆ: ਦੁਨੀਆ ਦਾ ਪਹਿਲਾ ਮਾਈਕ੍ਰੋਪ੍ਰੋਸੈਸਰ Intel 4004 ਸੀ, ਜੋ Intel Corporation ਨੇ ਬਣਾਇਆ।

  7. Intel 4004 ਮਾਈਕ੍ਰੋਪ੍ਰੋਸੈਸਰ ਕਿਸ ਸਾਲ ਪੇਸ਼ ਕੀਤਾ ਗਿਆ ਸੀ?

    1. 1969
    2. 1971
    3. 1975

  8. CPU ਮੁੱਖ ਤੌਰ 'ਤੇ ਕਿਨ੍ਹਾਂ ਭਾਗਾਂ ਤੋਂ ਬਣਿਆ ਹੁੰਦਾ ਹੈ?

    1. ਕੰਟਰੋਲ ਯੂਨਿਟ, ALU ਅਤੇ ਹਾਰਡ ਡਿਸਕ
    2. ALU, ਮਾਨੀਟਰ ਅਤੇ ਰਜਿਸਟਰ
    3. ਕੰਟਰੋਲ ਯੂਨਿਟ, ਕੀਬੋਰਡ ਅਤੇ ALU
    4. ਕੰਟਰੋਲ ਯੂਨਿਟ, ALU ਅਤੇ ਰਜਿਸਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਕੰਟਰੋਲ ਯੂਨਿਟ, ALU ਅਤੇ ਰਜਿਸਟਰ

    ਵਿਆਖਿਆ: CPU ਦੇ ਮੁੱਖ ਭਾਗ ਕੰਟਰੋਲ ਯੂਨਿਟ (CU), ਅਰਿਥਮੈਟਿਕ ਲੌਜਿਕ ਯੂਨਿਟ (ALU) ਅਤੇ ਰਜਿਸਟਰ (ਮੈਮਰੀ ਯੂਨਿਟ) ਹਨ।

  9. CPU ਦਾ ਕਿਹੜਾ ਭਾਗ ਕੰਪਿਊਟਰ ਦੇ ਸਾਰੇ ਕਾਰਜਾਂ ਨੂੰ ਕੰਟਰੋਲ ਅਤੇ ਤਾਲਮੇਲ ਕਰਦਾ ਹੈ?

    1. ਅਰਿਥਮੈਟਿਕ ਲੌਜਿਕ ਯੂਨਿਟ (ALU)
    2. ਰਜਿਸਟਰ
    3. ਕੰਟਰੋਲ ਯੂਨਿਟ (CU)
    4. CPU ਸਾਕਟ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਕੰਟਰੋਲ ਯੂਨਿਟ (CU)

    ਵਿਆਖਿਆ: ਕੰਟਰੋਲ ਯੂਨਿਟ ਕੰਪਿਊਟਰ ਦੇ ਸਾਰੇ ਕਾਰਜਾਂ ਨੂੰ ਕੰਟਰੋਲ ਅਤੇ ਤਾਲਮੇਲ ਕਰਦਾ ਹੈ (CU = ਸਭ ਕੁਝ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ)।

  10. ਕੰਪਿਊਟਰ ਅੰਦਰ ਜਾਣਕਾਰੀ ਦੇ ਵਹਾਅ ਨੂੰ ਨਿਰਦੇਸ਼ਿਤ ਕਰਨ ਕਰਕੇ ਕੰਟਰੋਲ ਯੂਨਿਟ ਦੀ ਤੁਲਨਾ ਕਿਸ ਨਾਲ ਕੀਤੀ ਜਾਂਦੀ ਹੈ?

    1. ਟ੍ਰੈਫ਼ਿਕ ਪੁਲਿਸ ਅਫ਼ਸਰ
    2. ਕੈਲਕੁਲੇਟਰ
    3. ਲਾਇਬ੍ਰੇਰੀਅਨ
    4. ਡਾਕੀਆ

    ਸਹੀ ਉੱਤਰ: (A) ਟ੍ਰੈਫ਼ਿਕ ਪੁਲਿਸ ਅਫ਼ਸਰ

    ਵਿਆਖਿਆ: ਕੰਟਰੋਲ ਯੂਨਿਟ ਇੱਕ ਟ੍ਰੈਫ਼ਿਕ ਪੁਲਿਸ ਅਫ਼ਸਰ ਵਾਂਗ ਕੰਪਿਊਟਰ ਅੰਦਰ ਜਾਣਕਾਰੀ ਦੇ ਵਹਾਅ ਨੂੰ ਨਿਰਦੇਸ਼ਿਤ ਕਰਦਾ ਹੈ।

  11. ਕੰਟਰੋਲ ਯੂਨਿਟ ਦਾ ਕਿਹੜਾ ਕਾਰਜ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਹਦਾਇਤਾਂ ਸਹੀ ਕ੍ਰਮ ਵਿੱਚ ਲਾਗੂ ਹੋਣ?

    1. ਹਦਾਇਤਾਂ ਨੂੰ ਡੀਕੋਡ ਕਰਨਾ
    2. ਹਦਾਇਤਾਂ ਦਾ ਕ੍ਰਮ ਕਾਇਮ ਰੱਖਣਾ
    3. ਕੰਟਰੋਲ ਸਿਗਨਲ ਪੈਦਾ ਕਰਨਾ
    4. ਡਾਟਾ ਦੇ ਵਹਾਅ ਨੂੰ ਕੰਟਰੋਲ ਕਰਨਾ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਹਦਾਇਤਾਂ ਦਾ ਕ੍ਰਮ ਕਾਇਮ ਰੱਖਣਾ

    ਵਿਆਖਿਆ: 'ਹਦਾਇਤਾਂ ਦਾ ਕ੍ਰਮ ਕਾਇਮ ਰੱਖਣਾ' ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਹਦਾਇਤਾਂ ਸਹੀ ਕ੍ਰਮ ਵਿੱਚ ਲਾਗੂ ਹੋਣ।

  12. ਹਦਾਇਤਾਂ ਨੂੰ ਸਮਝਣਯੋਗ ਸਿਗਨਲਾਂ ਵਿੱਚ ਬਦਲਣਾ ਕੰਟਰੋਲ ਯੂਨਿਟ ਦਾ ਕਿਹੜਾ ਕਾਰਜ ਹੈ?

  13. ਪ੍ਰੋਗਰਾਮ ਕਾਊਂਟਰ (PC) ਕੀ ਸਟੋਰ ਕਰਦਾ ਹੈ?

    2. ਅਗਲੀ ਹਦਾਇਤ ਦਾ ਪਤਾ (address)
    3. ਮੌਜੂਦਾ ਹਦਾਇਤ ਦਾ opcode
    4. CPU ਦੀ ਕਲਾਕ ਸਪੀਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਅਗਲੀ ਹਦਾਇਤ ਦਾ ਪਤਾ (address)

    ਵਿਆਖਿਆ: ਪ੍ਰੋਗਰਾਮ ਕਾਊਂਟਰ ਅਗਲੀ ਹਦਾਇਤ ਦਾ ਪਤਾ (address) ਸਟੋਰ ਕਰਦਾ ਹੈ।

  14. ਡੀਕੋਡਿੰਗ ਦੌਰਾਨ Opcode CPU ਨੂੰ ਕੀ ਦੱਸਦਾ ਹੈ?

    3. ਨਤੀਜਾ ਕਿੱਥੇ ਸਟੋਰ ਕਰਨਾ ਹੈ
    4. ਅਗਲੀ ਹਦਾਇਤ ਦਾ ਪਤਾ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਕਿਹੜਾ ਕਾਰਜ (operation) ਕਰਨਾ ਹੈ

    ਵਿਆਖਿਆ: Opcode ਦੱਸਦਾ ਹੈ ਕਿ ਕਿਹੜਾ ਕਾਰਜ ਕਰਨਾ ਹੈ; Operand ਦੱਸਦਾ ਹੈ ਕਿ ਕਿਸ ਡਾਟਾ ਉੱਤੇ ਕਰਨਾ ਹੈ।

  16. ਜਦੋਂ ALU ਜਾਂਚਦਾ ਹੈ ਕਿ '50 > 30' ਸਹੀ ਹੈ ਜਾਂ ਗ਼ਲਤ, ਤਾਂ ਇਹ ਕਿਹੜਾ ਕਾਰਜ ਕਰ ਰਿਹਾ ਹੁੰਦਾ ਹੈ?

    1. ਗਣਿਤਕ (arithmetic) ਕਾਰਜ
    2. ਫੈੱਚ ਕਾਰਜ
    3. ਸਟੋਰੇਜ ਕਾਰਜ
    4. ਤਾਰਕਿਕ (logical) ਕਾਰਜ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਤਾਰਕਿਕ (logical) ਕਾਰਜ

    ਵਿਆਖਿਆ: ਵੱਧ ਤੋਂ (>) ਵਰਗੀਆਂ ਤੁਲਨਾਵਾਂ ALU ਦੁਆਰਾ ਕੀਤੇ ਜਾਂਦੇ ਤਾਰਕਿਕ ਕਾਰਜ ਹਨ।

  17. CU ਅਤੇ ALU ਦੀ ਤੁਲਨਾ ਅਨੁਸਾਰ ਕਿਹੜਾ ਕਥਨ ਸਹੀ ਹੈ?

    1. CU ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਦਾ ਹੈ, ਜਦਕਿ ALU ਨਹੀਂ ਕਰਦਾ
    2. CU ਅਤੇ ALU ਦੋਵੇਂ ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਦੇ ਹਨ
    3. CU ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਨਹੀਂ ਕਰਦਾ, ਜਦਕਿ ALU ਕਰਦਾ ਹੈ
    4. ਨਾ CU ਅਤੇ ਨਾ ALU ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਕਰਦਾ ਹੈ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) CU ਡਾਟਾ ਪ੍ਰੋਸੈੱਸ ਨਹੀਂ ਕਰਦਾ, ਜਦਕਿ ALU ਕਰਦਾ ਹੈ

    ਵਿਆਖਿਆ: ਡਾਟਾ ਪ੍ਰੋਸੈਸਿੰਗ: ਕੰਟਰੋਲ ਯੂਨਿਟ – ਨਹੀਂ, ALU – ਹਾਂ; CU ਨਿਗਰਾਨ (supervisor) ਹੈ ਅਤੇ ALU ਕੈਲਕੁਲੇਟਰ।

  18. ਕੰਪਿਊਟਰ ਵਿੱਚ ਸਭ ਤੋਂ ਤੇਜ਼ ਮੈਮਰੀ ਕਿਹੜੀ ਹੈ?

    1. ਹਾਰਡ ਡਿਸਕ
    2. ਰਜਿਸਟਰ
    3. RAM
    4. ਪੈੱਨ ਡਰਾਈਵ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਰਜਿਸਟਰ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: ਰਜਿਸਟਰ ਕੰਪਿਊਟਰ ਦੀ ਸਭ ਤੋਂ ਤੇਜ਼ ਮੈਮਰੀ ਹਨ; ਇਹ CPU ਅੰਦਰ ਬਹੁਤ ਛੋਟੀਆਂ ਅਤੇ ਬਹੁਤ ਤੇਜ਼ ਮੈਮਰੀ ਥਾਵਾਂ ਹਨ।

  19. MAR ਨਾਮਕ ਰਜਿਸਟਰ ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    2. Memory Arithmetic Register

    4. Memory Address Register

  20. ਆਧੁਨਿਕ CPU ਦੀ ਕਲਾਕ ਸਪੀਡ ਕਿਸ ਵਿੱਚ ਮਾਪੀ ਜਾਂਦੀ ਹੈ?

    2. ਮੈਗਾਬਾਈਟ (MB)

    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਗੀਗਾਹਰਟਜ਼ (GHz)

    ਵਿਆਖਿਆ: ਕਲਾਕ ਸਪੀਡ ਦੀ ਇਕਾਈ ਹਰਟਜ਼ (Hz) ਹੈ; ਆਧੁਨਿਕ CPU ਗੀਗਾਹਰਟਜ਼ (GHz) ਵਿੱਚ ਮਾਪੇ ਜਾਂਦੇ ਹਨ।

  21. 4.0 GHz ਉੱਤੇ ਚੱਲਣ ਵਾਲਾ ਪ੍ਰੋਸੈਸਰ ਪ੍ਰਤੀ ਸਕਿੰਟ ਲਗਭਗ ਕਿੰਨੇ ਕਲਾਕ ਸਾਈਕਲ ਕਰ ਸਕਦਾ ਹੈ?
