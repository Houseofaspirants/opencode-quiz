04 Coding And Decoding: ਨਮੂਨੇ ਦੇ ਸਵਾਲ

ਹਰ ਸੈੱਟ ਵਿੱਚੋਂ ਦੋ ਸਵਾਲ - ਉੱਤਰ ਵੇਖਣ ਲਈ ਦਬਾਓ।

  1. ਇੱਕ clerk ਸਿਰਫ਼ ਵੱਖ-ਵੱਖ ਅੱਖਰਾਂ ਦੇ alphabet ranks ਜੋੜਦਾ ਹੈ; ਦੁਹਰਾਏ ਅੱਖਰ ਮੁੜ ਨਹੀਂ ਗਿਣਦਾ। BATHINDA ਨੂੰ ਕਿਹੜਾ ਅੰਕ ਮਿਲੇਗਾ?

    1. 57
    2. 58
    3. 7
    4. 59
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) 58

    ਵਿਆਖਿਆ: A ਨੂੰ ਇੱਕ ਵਾਰ ਗਿਣੋ। B+A+T+H+I+N+D = 2+1+20+8+9+14+4 = 58।

  2. ਛੇ ਅੱਖਰਾਂ ਦਾ code ਅਸਲ ਥਾਵਾਂ 4,1,6,2,5,3 ਦੇ ਕ੍ਰਮ ਵਿੱਚ ਪੜ੍ਹਦਾ ਹੈ। code NKLAAR ਹੈ। ਕਿਹੜੇ ਸ਼ਬਦ ਦਾ ਕ੍ਰਮ ਬਦਲਿਆ ਗਿਆ ਸੀ?

    1. KANRAL
    2. AKLRAN
    3. KARLAN
    4. KARNAL
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) KARNAL

    ਵਿਆਖਿਆ: N,K,L,A,A,R ਨੂੰ ਕ੍ਰਮਵਾਰ ਥਾਵਾਂ 4,1,6,2,5,3 ਉੱਤੇ ਵਾਪਸ ਰੱਖੋ। ਅਸਲ ਥਾਵਾਂ 1–6 ਨੂੰ ਪੜ੍ਹ ਕੇ KARNAL ਮਿਲਦਾ ਹੈ।

  3. code ਵਿੱਚ ਪਹਿਲੇ ਸਵਰ ਦਾ rank, ਫਿਰ / ਅਤੇ ਫਿਰ ਵਿਅੰਜਨਾਂ ਦੇ ਕੁੱਲ ਆਉਣ ਦੀ ਗਿਣਤੀ ਹੁੰਦੀ ਹੈ। A,E,I,O,U ਸਵਰ ਹਨ। GURDASPUR ਦਾ code ਕਿਹੜਾ ਹੈ?

    1. 21/5
    2. 1/6
    3. 21/3
    4. 21/6
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) 21/6

    ਵਿਆਖਿਆ: ਪਹਿਲਾ ਸਵਰ U=21 ਹੈ। G,R,D,S,P,R ਕੁੱਲ ਛੇ ਵਿਅੰਜਨ ਹਨ, ਇਸ ਲਈ 21/6 ਬਣਦਾ ਹੈ।

  4. word codes ਤੈਅ ਹਨ ਅਤੇ ਕ੍ਰਮ ਕੋਈ ਵੀ ਹੋ ਸਕਦਾ ਹੈ: “Kiran wins today” = “ba se tu”; “Aman wins often” = “ri tu ko”। “wins” ਦਾ token ਕਿਹੜਾ ਹੈ?

    1. ba
    2. se
    3. tu
    4. ko
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) tu

    ਵਿਆਖਿਆ: ਇਕੱਲਾ ਸਾਂਝਾ ਸ਼ਬਦ wins ਅਤੇ ਇਕੱਲਾ ਸਾਂਝਾ token tu ਹੈ।

  5. ਇੱਕ filing code ਸਾਰੇ ਅੱਖਰਾਂ ਨੂੰ ਉਲਟੇ alphabet ਕ੍ਰਮ ਵਿੱਚ ਲਿਖਦਾ ਹੈ ਅਤੇ ਦੁਹਰਾਏ ਅੱਖਰ ਰੱਖਦਾ ਹੈ। AMBALA ਦਾ filing code ਕਿਹੜਾ ਹੈ?

    1. AAABLM
    2. MLBAAA
    3. MLABAA
    4. MLBAA
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) MLBAAA

    ਵਿਆਖਿਆ: ਵੱਡੇ rank ਤੋਂ ਛੋਟੇ ਵੱਲ M,L,B,A,A,A ਲਿਖੋ। code MLBAAA ਹੈ।

  6. ਇੱਕ ਤੈਅ mapping ਵਿੱਚ ਦੋ ਅੱਖਰਾਂ ਦਾ code ਇੱਕੋ ਹੋ ਸਕਦਾ ਹੈ: P→#, Q→#, R→@, S→7। #@# ਦੇ ਕਿੰਨੇ ਵੱਖਰੇ ਤਿੰਨ-ਅੱਖਰੀ ਅਸਲ ਰੂਪ ਹੋ ਸਕਦੇ ਹਨ?

    1. 2
    2. 4
    3. 8
    4. 3
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) 4

    ਵਿਆਖਿਆ: ਹਰ # ਵੱਖਰੇ ਤੌਰ ਉੱਤੇ P ਜਾਂ Q ਹੋ ਸਕਦਾ ਹੈ; @ ਸਿਰਫ਼ R ਹੈ। ਇਸ ਲਈ 2×1×2=4 ਅਸਲ ਰੂਪ ਹਨ।

  7. ਪਹਿਲਾਂ row ਫਿਰ column ਵਰਤੋ। columns: 0,1,2; row 0=A,B,A; row 1=C,A,D; row 2=B,D,C। ਜੇ ਕੋਈ cell ਮੁੜ ਨਾ ਵਰਤੋ ਅਤੇ ਪਹਿਲਾ A ਲਾਜ਼ਮੀ row 0 ਤੋਂ ਲਵੋ, ਤਾਂ ABACA ਦੇ ਕਿੰਨੇ coordinate ਕ੍ਰਮ ਬਣਦੇ ਹਨ?

    1. 24
    2. 18
    3. 16
    4. 12
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) 16

    ਵਿਆਖਿਆ: ਪਹਿਲੇ A ਦੀਆਂ 2 ਚੋਣਾਂ ਹਨ; ਬਾਕੀ A cells 2×1 ਤਰੀਕਿਆਂ ਨਾਲ ਲੱਗਦੇ ਹਨ। B ਅਤੇ C ਦੀਆਂ 2-2 ਚੋਣਾਂ ਹਨ, ਇਸ ਲਈ 2×2×1×2×2=16।

  8. ਉਹੀ ਇੱਕ-ਤੋਂ-ਇੱਕ character code MELA→4@7# ਅਤੇ AMAR→#4#8 ਦਿੰਦਾ ਹੈ। ਕਿਹੜੀ ਹੋਰ mapping ਲਾਜ਼ਮੀ ਗਲਤ ਹੈ?

    1. E→@
    2. R→7
    3. A→#
    4. L→7
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) R→7

    ਵਿਆਖਿਆ: ਮਿਸਾਲਾਂ ਤੋਂ M=4,E=@,L=7,A=#,R=8 ਤੈਅ ਹਨ। ਇਸ ਲਈ R→7, R→8 ਨਾਲ ਟਕਰਾਉਂਦਾ ਹੈ।

  9. ਤੈਅ codes ਵਿੱਚ ਕ੍ਰਮ ਕੋਈ ਵੀ ਹੈ: “books inspire minds” = “qa ve lu”; “stories inspire children” = “ve ro na”; “books delight children” = “qa mi na”। ਕਿਹੜਾ ਹੋਰ coded ਵਾਕ ਤਿੰਨਾਂ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ?

    1. stories delight minds = ro na lu
    2. stories delight minds = ro mi lu
    3. books inspire children = qa ve ro
    4. children delight books = mi lu qa
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) stories delight minds = ro mi lu

    ਵਿਆਖਿਆ: ਸ਼ਬਦ ਮਿਲਾਉਣ ਨਾਲ stories=ro, delight=mi ਅਤੇ minds=lu ਹਨ। ਇਸ ਲਈ ro mi lu ਵਾਲਾ ਹੋਰ code ਸਹੀ ਹੈ।

  10. ਇੱਕ label ਵਿੱਚ BANUR ਦਾ ਪੂਰਾ ਉਲਟਾ ਰੂਪ ਸੰਭਾਲਿਆ ਹੈ। ਸੰਭਾਲੇ label ਵਿੱਚ ਖੱਬੇ ਤੋਂ ਦੂਜੀ ਥਾਂ ਕਿਹੜਾ ਅੱਖਰ ਹੈ?

    1. R
    2. N
    3. U
    4. A
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) U

    ਵਿਆਖਿਆ: BANUR ਦਾ ਉਲਟਾ RUNAB ਹੈ। ਖੱਬੇ ਤੋਂ ਇਸ ਦਾ ਦੂਜਾ ਅੱਖਰ U ਹੈ।

  11. code ਤੈਅ, ਇੱਕ-ਤੋਂ-ਇੱਕ ਅਤੇ ਬਿਨਾਂ ਤੈਅ ਕ੍ਰਮ ਦੇ ਹੈ: “bright stars guide sailors” = “ab ef cd gh”; “stars guide travellers safely” = “cd gh ij kl”; “bright lamps shine safely” = “ab mn op kl”; “lamps guide ships” = “mn gh qr”। “stars” ਦਾ token ਕਿਹੜਾ ਹੈ?

    1. ij
    2. cd
    3. ef
    4. gh
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) cd

    ਵਿਆਖਿਆ: ਪਹਿਲੀਆਂ ਦੋ ਲਾਈਨਾਂ ਤੋਂ stars ਅਤੇ guide ਲਈ cd,gh ਬਚਦੇ ਹਨ। ਚੌਥੀ ਲਾਈਨ ਦਾ ਪਹਿਲੀ ਨਾਲ ਇਕੱਲਾ ਸਾਂਝਾ ਸ਼ਬਦ guide ਹੈ, ਇਸ ਲਈ guide=gh ਅਤੇ stars=cd।

  12. MEENA, MEHAR, MEET, MEGHA ਨੂੰ alphabet ਕ੍ਰਮ ਵਿੱਚ ਲਿਖੋ। ਹਰ code ਵਿੱਚ ਪਹਿਲਾ ਅੱਖਰ, sorted list ਵਿੱਚ 1 ਤੋਂ ਗਿਣੀ ਉਸ ਦੀ ਥਾਂ ਅਤੇ ਫਿਰ ਆਖ਼ਰੀ ਅੱਖਰ -1 ਕਰਕੇ ਲਿਖਦੇ ਹਨ। MEENA ਦਾ code ਕੀ ਹੈ?

    1. M1Z
    2. M2Z
    3. M3Z
    4. M1B
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) M1Z

    ਵਿਆਖਿਆ: ਕ੍ਰਮ MEENA,MEET,MEGHA,MEHAR ਹੈ। MEENA ਪਹਿਲਾਂ ਹੈ ਅਤੇ ਆਖ਼ਰੀ A ਪਿੱਛੇ ਜਾ ਕੇ Z ਬਣਦਾ ਹੈ, ਇਸ ਲਈ M1Z ਹੈ।
