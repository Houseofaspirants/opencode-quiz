ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

ਜਿਹੜਾ ਸਵਾਲ ਦੋ ਵਾਰ ਗਲਤ ਹੋਵੇ, ਉਹਨੂੰ ਆਪਣੀ ਕਾਪੀ ਵਿੱਚ ਲਿਖ ਲਓ - ਪ੍ਰੀਖਿਆ ਤੋਂ ਪਹਿਲਾਂ ਦੁਹਰਾਈ ਲਈ ਇਹੀ ਸਭ ਤੋਂ ਕੰਮ ਦੀ ਸੂਚੀ ਹੈ।

  1. MS Word ਮੁੱਖ ਤੌਰ 'ਤੇ ਕਿਸ ਕਿਸਮ ਦਾ software ਹੈ?

    1. Spreadsheet software
    2. Word processing software
    3. Presentation software
    4. Database management software
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Word processing software

    ਵਿਆਖਿਆ: MS Word ਇੱਕ word processor ਹੈ ਜਿਸ ਨਾਲ text documents ਬਣਾਏ, edit, format, save ਅਤੇ print ਕੀਤੇ ਜਾਂਦੇ ਹਨ। Excel spreadsheet, PowerPoint presentation ਅਤੇ Access database software ਹੈ।

  2. MS Word ਵਿੱਚ ਨਵਾਂ blank document ਖੋਲ੍ਹਣ 'ਤੇ ਉਸ ਦਾ default file name ਕੀ ਹੁੰਦਾ ਹੈ?

    1. Book1
    2. Presentation1
    3. Document1
    4. Untitled1
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Document1

    ਵਿਆਖਿਆ: Word ਵਿੱਚ ਨਵਾਂ document Document1 ਨਾਮ ਨਾਲ ਖੁੱਲ੍ਹਦਾ ਹੈ। Excel ਵਿੱਚ Book1 ਅਤੇ PowerPoint ਵਿੱਚ Presentation1 ਹੁੰਦਾ ਹੈ।

  3. MS Word 2007 ਅਤੇ ਉਸ ਤੋਂ ਬਾਅਦ ਦੇ versions ਵਿੱਚ save ਕੀਤੇ document ਦੀ default file extension ਕਿਹੜੀ ਹੈ?

    1. .doc
    2. .txt
    3. .dotx
    4. .docx
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) .docx

    ਵਿਆਖਿਆ: Word 2007 ਤੋਂ ਬਾਅਦ .docx default format ਹੈ। .doc ਪੁਰਾਣੇ Word 97-2003 ਦਾ format ਸੀ ਅਤੇ .dotx template ਹੁੰਦਾ ਹੈ।

  4. Macros ਵਾਲੀ Word file ਨੂੰ ਕਿਹੜੀ extension ਨਾਲ save ਕਰਨਾ ਪੈਂਦਾ ਹੈ?

    1. .docm
    2. .dotx
    3. .xps
    4. .docx
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) .docm

    ਵਿਆਖਿਆ: .docm macro-enabled document ਹੁੰਦਾ ਹੈ। ਆਮ .docx file ਵਿੱਚ macros save ਨਹੀਂ ਹੁੰਦੇ; macro-enabled template ਦੀ extension .dotm ਹੈ।

  5. ਹੇਠ ਲਿਖੀਆਂ file extensions ਅਤੇ ਉਹਨਾਂ ਦੇ ਅਰਥਾਂ 'ਤੇ ਵਿਚਾਰ ਕਰੋ: 1. .dotx – Word template 2. .xps – XML Paper Specification 3. .odt – Office Document Text ਉਪਰੋਕਤ ਵਿੱਚੋਂ ਕਿਹੜੇ ਜੋੜੇ ਸਹੀ ਮਿਲਾਏ ਗਏ ਹਨ?

    1. ਸਿਰਫ਼ 1 ਅਤੇ 2
    2. ਸਿਰਫ਼ 2 ਅਤੇ 3
    3. ਸਿਰਫ਼ 1 ਅਤੇ 3
    4. 1, 2 ਅਤੇ 3
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਸਿਰਫ਼ 1 ਅਤੇ 2

    ਵਿਆਖਿਆ: .dotx Word template ਹੈ ਅਤੇ .xps ਦਾ ਅਰਥ XML Paper Specification ਹੈ। .odt ਦਾ ਅਰਥ OpenDocument Text ਹੈ, 'Office Document Text' ਨਹੀਂ, ਇਸ ਲਈ ਜੋੜਾ 3 ਗ਼ਲਤ ਹੈ।

  6. MS Word ਖੋਲ੍ਹਣ 'ਤੇ ਕਿਹੜੀ tab default ਤੌਰ 'ਤੇ select ਹੁੰਦੀ ਹੈ?

    1. Insert
    2. Home
    3. File
    4. View
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Home

    ਵਿਆਖਿਆ: Home tab default tab ਹੈ। ਇਸ ਵਿੱਚ ਸਭ ਤੋਂ ਵੱਧ ਵਰਤੇ ਜਾਣ ਵਾਲੇ commands ਪੰਜ groups ਵਿੱਚ ਹੁੰਦੇ ਹਨ: Clipboard, Font, Paragraph, Styles ਅਤੇ Editing।

  7. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ group MS Word ਦੀ Home tab ਦਾ ਹਿੱਸਾ ਨਹੀਂ ਹੈ?

    1. Clipboard
    2. Styles
    3. Illustrations
    4. Editing
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Illustrations

    ਵਿਆਖਿਆ: Home tab ਵਿੱਚ Clipboard, Font, Paragraph, Styles ਅਤੇ Editing ਹਨ। Illustrations (Pictures, Shapes, SmartArt, Chart) Insert tab ਦਾ group ਹੈ।

  8. MS Word ਵਿੱਚ Ribbon ਨੂੰ ਸਭ ਤੋਂ ਵਧੀਆ ਕਿਸ ਦਾ ਸੰਗ੍ਰਹਿ ਕਿਹਾ ਜਾ ਸਕਦਾ ਹੈ?

    1. Documents ਅਤੇ templates
    2. ਸਿਰਫ਼ toolbars ਅਤੇ menus
    3. Rulers ਅਤੇ scroll bars

    ਸਹੀ ਉੱਤਰ: (D) Tabs, groups ਅਤੇ commands

    ਵਿਆਖਿਆ: Ribbon tabs ਵਿੱਚ ਵੰਡਿਆ ਹੁੰਦਾ ਹੈ; ਹਰ tab ਵਿੱਚ groups ਹੁੰਦੇ ਹਨ ਅਤੇ ਹਰ group ਵਿੱਚ ਸਬੰਧਤ commands ਹੁੰਦੇ ਹਨ।

  9. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ command default ਤੌਰ 'ਤੇ Quick Access Toolbar 'ਤੇ ਹੁੰਦੀ ਹੈ?

    2. Print Preview

  10. MS Word ਵਿੱਚ zoom ਦੀ range ਕਿੰਨੀ ਹੁੰਦੀ ਹੈ?

  11. MS Word ਦੇ Font Size box ਵਿੱਚ ਵੱਧ ਤੋਂ ਵੱਧ ਕਿੰਨਾ font size type ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ?

  12. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕੀ MS Word ਦੇ Status Bar 'ਤੇ default ਤੌਰ 'ਤੇ ਨਹੀਂ ਦਿਸਦਾ?

  13. Format Painter tool Home tab ਦੇ ਕਿਹੜੇ group ਵਿੱਚ ਹੁੰਦਾ ਹੈ?

  14. MS Word ਵਿੱਚ ਸਿਰਫ਼ formatting (text ਨਹੀਂ) copy ਅਤੇ paste ਕਰਨ ਲਈ ਕਿਹੜੀਆਂ shortcut keys ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ?

  15. MS Word ਵਿੱਚ H₂O ਸਹੀ ਲਿਖਣ ਲਈ '2' ਨੂੰ subscript ਕਰਨਾ ਪੈਂਦਾ ਹੈ। Subscript ਲਈ ਕਿਹੜੀ shortcut ਹੈ?

  16. MS Word ਵਿੱਚ ਕਿਹੜੀ key combination select ਕੀਤੇ text ਨੂੰ UPPERCASE, lowercase ਅਤੇ Capitalize Each Word ਵਿੱਚ ਵਾਰੀ-ਵਾਰੀ ਬਦਲਦੀ ਹੈ?
