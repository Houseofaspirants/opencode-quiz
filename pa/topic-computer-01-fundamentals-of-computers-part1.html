  1. ਅਧਿਆਇ ਅਨੁਸਾਰ, ਕੰਪਿਊਟਰ ਇੱਕ ਮਨੁੱਖ ਦੁਆਰਾ ਬਣਾਈ ______ ਮਸ਼ੀਨ ਹੈ।

    4. ਹਾਰਡ ਡਿਸਕ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) CPU

    ਵਿਆਖਿਆ: CPU ਨੂੰ ਕੰਪਿਊਟਰ ਦਾ ਦਿਮਾਗ ਕਿਹਾ ਜਾਂਦਾ ਹੈ।

  18. ਕਿਹੜੀ ਇਕਾਈ ਗਣਿਤਕ (arithmetic) ਅਤੇ ਤਾਰਕਿਕ (logical) ਕਾਰਜ ਕਰਦੀ ਹੈ?

    1. CU
    2. ਮੈਮਰੀ ਯੂਨਿਟ
    3. ਮਦਰਬੋਰਡ
    4. ALU
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ALU

    ਵਿਆਖਿਆ: ALU ਗਣਿਤਕ ਅਤੇ ਤਾਰਕਿਕ ਕਾਰਜ ਕਰਦੀ ਹੈ।

  19. ਕਿਹੜੀ ਇਕਾਈ ਕੰਪਿਊਟਰ ਦੀਆਂ ਸਾਰੀਆਂ ਗਤੀਵਿਧੀਆਂ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦੀ ਹੈ?

    1. ALU
    2. RAM
    3. CU
    4. SSD
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) CU

    ਵਿਆਖਿਆ: CU (ਕੰਟਰੋਲ ਯੂਨਿਟ) ਕੰਪਿਊਟਰ ਦੀਆਂ ਸਾਰੀਆਂ ਗਤੀਵਿਧੀਆਂ ਨੂੰ ਨਿਯੰਤਰਿਤ ਕਰਦੀ ਹੈ।

  20. ਅਧਿਆਇ ਦੀ ਤੁਰੰਤ ਦੁਹਰਾਈ ਅਨੁਸਾਰ, CPU = ?

    1. CU + ALU + ਮਾਨੀਟਰ
    2. CU + ALU + ਮੈਮਰੀ ਯੂਨਿਟ
    3. ALU + RAM + ਹਾਰਡ ਡਿਸਕ
    4. CU + ਮਦਰਬੋਰਡ + ਸਟੋਰੇਜ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) CU + ALU + ਮੈਮਰੀ ਯੂਨਿਟ

    ਵਿਆਖਿਆ: ਤੁਰੰਤ ਦੁਹਰਾਈ: CPU = CU + ALU + ਮੈਮਰੀ ਯੂਨਿਟ।

  21. ਮੈਮਰੀ ਦੀ ਵਰਤੋਂ ਪ੍ਰੋਸੈਸਿੰਗ ਦੌਰਾਨ ਡਾਟਾ ਅਤੇ ਹਦਾਇਤਾਂ ਦੇ ______ ਭੰਡਾਰਨ ਲਈ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

    1. ਸਥਾਈ
    2. ਔਫਲਾਈਨ
    3. ਅਸਥਾਈ
    4. ਬਾਹਰੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਅਸਥਾਈ

    ਵਿਆਖਿਆ: ਮੈਮਰੀ ਅਸਥਾਈ ਭੰਡਾਰਨ ਲਈ ਹੈ; ਯਾਦ ਰੱਖੋ ਮੈਮਰੀ = ਅਸਥਾਈ, ਸਟੋਰੇਜ = ਸਥਾਈ।

  22. ਅਧਿਆਇ ਵਿੱਚ ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਸਨੂੰ ਮੈਮਰੀ ਦੀ ਉਦਾਹਰਨ ਵਜੋਂ ਦਿੱਤਾ ਗਿਆ ਹੈ?

    1. ਪੈੱਨ ਡਰਾਈਵ
    2. CD/DVD
    3. ਹਾਰਡ ਡਿਸਕ ਡਰਾਈਵ
    4. ਕੈਸ਼ ਮੈਮਰੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਕੈਸ਼ ਮੈਮਰੀ

    ਵਿਆਖਿਆ: ਅਧਿਆਇ ਵਿੱਚ RAM ਅਤੇ ਕੈਸ਼ ਮੈਮਰੀ ਨੂੰ ਮੈਮਰੀ ਦੀਆਂ ਉਦਾਹਰਨਾਂ ਵਜੋਂ ਦਿੱਤਾ ਗਿਆ ਹੈ।

  23. ਕੰਪਿਊਟਰ ਦੇ ਸਾਰੇ ਭਾਗਾਂ ਨੂੰ ਜੋੜਨ ਵਾਲੇ ਮੁੱਖ ਸਰਕਟ ਬੋਰਡ ਨੂੰ ਕੀ ਕਹਿੰਦੇ ਹਨ?

    1. ਪ੍ਰੋਸੈਸਰ
    2. ਹਾਰਡ ਡਿਸਕ
    3. ਮੈਮਰੀ
    4. ਮਦਰਬੋਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: ਮਦਰਬੋਰਡ ਮੁੱਖ ਸਰਕਟ ਬੋਰਡ ਹੈ ਜੋ ਕੰਪਿਊਟਰ ਦੇ ਸਾਰੇ ਭਾਗਾਂ ਨੂੰ ਜੋੜਦਾ ਹੈ।

  24. ਕਿਸ ਭਾਗ ਨੂੰ "ਕੰਪਿਊਟਰ ਦੀ ਰੀੜ੍ਹ ਦੀ ਹੱਡੀ (Backbone)" ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. ਮਦਰਬੋਰਡ
    2. CPU
    3. RAM
    4. ਮਾਨੀਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਮਦਰਬੋਰਡ

    ਵਿਆਖਿਆ: ਯਾਦ ਰੱਖੋ: ਮਦਰਬੋਰਡ = ਕੰਪਿਊਟਰ ਦੀ ਰੀੜ੍ਹ ਦੀ ਹੱਡੀ।

  25. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ ਸਟੋਰੇਜ ਡਿਵਾਈਸ ਹੈ ਜੋ ਡਾਟਾ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸਟੋਰ ਕਰਦੀ ਹੈ?

    1. RAM
    2. ਸਾਲਿਡ ਸਟੇਟ ਡਰਾਈਵ (SSD)
    3. ਕੈਸ਼ ਮੈਮਰੀ
    4. ALU
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਸਾਲਿਡ ਸਟੇਟ ਡਰਾਈਵ (SSD)

    ਵਿਆਖਿਆ: ਸਟੋਰੇਜ ਡਿਵਾਈਸ ਡਾਟਾ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸਟੋਰ ਕਰਦੀ ਹੈ, ਜਿਵੇਂ HDD, SSD, ਪੈੱਨ ਡਰਾਈਵ, CD/DVD।
