ਸੈੱਟ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ।

ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

Computer System - ਭਾਗ 2: ਸਾਰੇ 25 ਸਵਾਲ

ਹਰ ਸਵਾਲ ਦਾ ਉੱਤਰ ਅਤੇ ਵਿਆਖਿਆ ਉਸਦੇ ਹੇਠਾਂ ਹੈ।

  1. ਕੰਪਿਊਟਰ ਦੀ ਪਾਵਰ ਸਪਲਾਈ ਯੂਨਿਟ SMPS ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Switched Mode Power Supply
    2. System Main Power Supply
    3. Single Mode Power Source
    4. Switched Memory Power System
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Switched Mode Power Supply

    ਵਿਆਖਿਆ: SMPS = Switched Mode Power Supply, ਜੋ ਕੰਪਿਊਟਰ ਦੀ ਪਾਵਰ ਸਪਲਾਈ ਯੂਨਿਟ ਹੈ।

  2. ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਇੱਕ ਇਨਪੁੱਟ ਡਿਵਾਈਸ ਹੈ ਜੋ ਕਿਸ ਨੂੰ ਬਦਲਦੀ ਹੈ?

    1. ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਨੂੰ ਆਵਾਜ਼ ਵਿੱਚ
    2. AC ਬਿਜਲੀ ਨੂੰ DC ਵਿੱਚ
    3. ਧੁਨੀ ਤਰੰਗਾਂ ਨੂੰ ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਵਿੱਚ
    4. ਚਿੱਤਰਾਂ ਨੂੰ ਡਿਜੀਟਲ ਡਾਟਾ ਵਿੱਚ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਧੁਨੀ ਤਰੰਗਾਂ ਨੂੰ ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਵਿੱਚ

    ਵਿਆਖਿਆ: ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਇੱਕ ਇਨਪੁੱਟ ਡਿਵਾਈਸ ਹੈ ਜੋ ਧੁਨੀ ਤਰੰਗਾਂ ਨੂੰ ਬਿਜਲਈ ਸਿਗਨਲਾਂ ਵਿੱਚ ਬਦਲਦੀ ਹੈ।

  3. ਅਧਿਆਇ ਅਨੁਸਾਰ ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਦਾ ਖੋਜੀ ਕੌਣ ਹੈ?

    1. ਡੇਵਿਡ ਐੱਸ. ਲੀ
    2. ਅਲੈਗਜ਼ੈਂਡਰ ਗ੍ਰਾਹਮ ਬੈੱਲ
    3. ਥਾਮਸ ਐਡੀਸਨ
    4. ਐਮਿਲ ਬਰਲਿਨਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਐਮਿਲ ਬਰਲਿਨਰ

    ਵਿਆਖਿਆ: ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਦਾ ਖੋਜੀ ਐਮਿਲ ਬਰਲਿਨਰ (1877) ਦੱਸਿਆ ਗਿਆ ਹੈ।

  4. ਐਮਿਲ ਬਰਲਿਨਰ ਨੇ ਮਾਈਕ੍ਰੋਫ਼ੋਨ ਦੀ ਖੋਜ ਕਿਸ ਸਾਲ ਕੀਤੀ?

    1. 1871
    2. 1877
    3. 1887
    4. 1897
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) 1877

    ਵਿਆਖਿਆ: ਮਾਈਕ੍ਰੋਫ਼ੋਨ – ਖੋਜੀ: ਐਮਿਲ ਬਰਲਿਨਰ, 1877 ਵਿੱਚ।

  5. ਪੈੱਨ ਡਰਾਈਵ (USB ਫਲੈਸ਼ ਡਰਾਈਵ) ਕਿਹੜੀ ਮੈਮਰੀ ਤਕਨੀਕ ਵਰਤਦੀ ਹੈ?

    1. ਫਲੈਸ਼ ਮੈਮਰੀ

    4. CMOS ਮੈਮਰੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਫਲੈਸ਼ ਮੈਮਰੀ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: ਪੈੱਨ ਡਰਾਈਵ ਫਲੈਸ਼ ਮੈਮਰੀ ਤਕਨੀਕ ਵਰਤਦੀ ਹੈ।

  6. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ USB ਫਲੈਸ਼ ਡਰਾਈਵ ਦੀ ਵਿਸ਼ੇਸ਼ਤਾ ਨਹੀਂ ਹੈ?

    1. ਪੋਰਟੇਬਲ (ਨਾਲ ਲਿਜਾਣਯੋਗ)

    3. USB ਇੰਟਰਫੇਸ
    4. ਸਿਰਫ਼ ਪੜ੍ਹਨਯੋਗ (ਦੁਬਾਰਾ ਨਹੀਂ ਲਿਖੀ ਜਾ ਸਕਦੀ)
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਸਿਰਫ਼ ਪੜ੍ਹਨਯੋਗ (ਦੁਬਾਰਾ ਨਹੀਂ ਲਿਖੀ ਜਾ ਸਕਦੀ)

    ਵਿਆਖਿਆ: USB ਫਲੈਸ਼ ਡਰਾਈਵ ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ: ਪੋਰਟੇਬਲ, ਦੁਬਾਰਾ ਲਿਖਣਯੋਗ ਅਤੇ USB ਇੰਟਰਫੇਸ।

  7. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜਾ ਮੈਮਰੀ ਕਾਰਡ ਦੀ ਕਿਸਮ ਹੈ?

    2. MicroSD ਕਾਰਡ

    ਵਿਆਖਿਆ: ਮੈਮਰੀ ਕਾਰਡ ਦੀਆਂ ਕਿਸਮਾਂ: SD ਕਾਰਡ, MicroSD ਕਾਰਡ ਅਤੇ MiniSD ਕਾਰਡ।

  8. ਕੰਪਿਊਟਰ ਉੱਤੇ ਉਹ ਕਨੈਕਸ਼ਨ ਬਿੰਦੂ ਜਿੱਥੇ ਬਾਹਰੀ ਡਿਵਾਈਸਾਂ ਜੋੜੀਆਂ ਜਾਂਦੀਆਂ ਹਨ ਅਤੇ ਜੋ ਡਾਟਾ ਲਈ 'ਦਰਵਾਜ਼ਿਆਂ' ਵਾਂਗ ਕੰਮ ਕਰਦੇ ਹਨ, ਕੀ ਅਖਵਾਉਂਦੇ ਹਨ?

    1. ਪੋਰਟ
    2. ਰਜਿਸਟਰ
    3. ਚਿੱਪਸੈੱਟ

    ਵਿਆਖਿਆ: ਪੋਰਟ ਉਹ ਕਨੈਕਸ਼ਨ ਬਿੰਦੂ ਹਨ ਜਿੱਥੇ ਬਾਹਰੀ ਡਿਵਾਈਸਾਂ ਜੁੜਦੀਆਂ ਹਨ; ਇਹ ਡਾਟਾ ਦੇ ਆਉਣ-ਜਾਣ ਲਈ ਦਰਵਾਜ਼ਿਆਂ ਵਾਂਗ ਹਨ।

  9. USB ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. Universal System Bus
    2. Unique Serial Bus
    3. United Serial Board
    4. Universal Serial Bus

    ਵਿਆਖਿਆ: USB = Universal Serial Bus; ਇਹ ਸਭ ਤੋਂ ਆਮ ਪੋਰਟ ਹੈ, ਜੋ ਕੀਬੋਰਡ, ਮਾਊਸ, ਪ੍ਰਿੰਟਰ, ਪੈੱਨ ਡਰਾਈਵ ਅਤੇ ਸਕੈਨਰ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਹੈ।

  10. PATA, ਜੋ ਸਮਾਨਾਂਤਰ ਡਾਟਾ ਟ੍ਰਾਂਸਫ਼ਰ ਵਾਲੀ ਪੁਰਾਣੀ ਹਾਰਡ ਡਿਸਕ ਪੋਰਟ ਹੈ, ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    2. Primary Advanced Technology Adapter
    3. Parallel Access Transfer Architecture
    4. Peripheral Advanced Technology Attachment
    ਉੱਤਰ ਵੇਖੋ

    ਵਿਆਖਿਆ: PATA = Parallel Advanced Technology Attachment; ਸਮਾਨਾਂਤਰ ਡਾਟਾ ਟ੍ਰਾਂਸਫ਼ਰ ਵਾਲੀ ਪੁਰਾਣੀ ਤਕਨੀਕ।

  11. ਆਧੁਨਿਕ ਕੰਪਿਊਟਰਾਂ ਵਿੱਚ SATA ਨੇ ਕਿਸਦੀ ਥਾਂ ਲੈ ਲਈ ਹੈ?

  12. ਹਾਰਡ ਡਿਸਕ ਲਈ ਵਰਤੀ ਜਾਂਦੀ SATA ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

  13. ਸਰਵਰਾਂ ਅਤੇ ਉੱਚ-ਕਾਰਗੁਜ਼ਾਰੀ ਸਟੋਰੇਜ ਸਿਸਟਮਾਂ ਵਿੱਚ ਕਿਹੜਾ ਹਾਰਡ ਡਿਸਕ ਪੋਰਟ/ਇੰਟਰਫੇਸ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ?

  14. ਕਿਹੜਾ ਪੋਰਟ ਇੱਕੋ ਸਮੇਂ ਕਈ ਬਿੱਟ ਭੇਜਦਾ ਹੈ ਅਤੇ ਪ੍ਰਿੰਟਰਾਂ ਤੇ ਸਕੈਨਰਾਂ ਲਈ ਵਰਤਿਆ ਜਾਂਦਾ ਹੈ?

    2. ਇੱਕ ਸਮੇਂ ਅੱਠ ਬਾਈਟ

  19. VGA ਪੋਰਟ ਕਿਸ ਕਿਸਮ ਦਾ ਸਿਗਨਲ ਲੈ ਕੇ ਜਾਂਦੀ ਹੈ?

    1. ਡਿਜੀਟਲ ਆਡੀਓ ਅਤੇ ਵੀਡੀਓ ਸਿਗਨਲ
    2. ਨੈੱਟਵਰਕ ਡਾਟਾ ਸਿਗਨਲ
    3. ਐਨਾਲਾਗ ਵੀਡੀਓ ਸਿਗਨਲ
    4. ਬਿਜਲੀ (ਪਾਵਰ) ਸਿਗਨਲ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਐਨਾਲਾਗ ਵੀਡੀਓ ਸਿਗਨਲ

    ਵਿਆਖਿਆ: VGA ਪੋਰਟ ਐਨਾਲਾਗ ਵੀਡੀਓ ਸਿਗਨਲ ਲੈ ਕੇ ਜਾਂਦੀ ਹੈ।

  20. ਕਿਹੜਾ ਪੋਰਟ ਇੱਕੋ ਕੇਬਲ ਰਾਹੀਂ ਆਡੀਓ ਅਤੇ ਵੀਡੀਓ ਦੋਵੇਂ ਭੇਜਦਾ ਹੈ?

    1. VGA
    2. HDMI
    3. PS/2
    4. ਈਥਰਨੈੱਟ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) HDMI

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: HDMI ਇੱਕੋ ਕੇਬਲ ਰਾਹੀਂ ਆਡੀਓ ਅਤੇ ਵੀਡੀਓ ਦੋਵੇਂ ਲੈ ਕੇ ਜਾਂਦਾ ਹੈ।

  21. HDMI ਦਾ ਪੂਰਾ ਰੂਪ ਕੀ ਹੈ?

    1. High Digital Media Input
    2. Hybrid Definition Multimedia Interface
    3. High Definition Multimedia Interface
    4. High Density Media Interconnect
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) High Definition Multimedia Interface

    ਵਿਆਖਿਆ: HDMI = High Definition Multimedia Interface।

  22. ਤੇਜ਼-ਗਤੀ ਡਾਟਾ ਟ੍ਰਾਂਸਫ਼ਰ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਫ਼ਾਇਰਵਾਇਰ ਪੋਰਟ ਕਿਸਨੇ ਵਿਕਸਿਤ ਕੀਤੀ?

    1. Apple
    2. IBM
    3. Intel
    4. Microsoft
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Apple

    ਵਿਆਖਿਆ: ਫ਼ਾਇਰਵਾਇਰ ਪੋਰਟ Apple ਨੇ ਵਿਕਸਿਤ ਕੀਤੀ ਅਤੇ ਇਹ ਤੇਜ਼ ਡਾਟਾ ਟ੍ਰਾਂਸਫ਼ਰ, ਡਿਜੀਟਲ ਕੈਮਰਿਆਂ ਅਤੇ ਬਾਹਰੀ ਸਟੋਰੇਜ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਹੈ।

  23. ਫ਼ਾਇਰਵਾਇਰ ਨੂੰ ਹੋਰ ਕਿਸ ਨਾਮ ਨਾਲ ਜਾਣਿਆ ਜਾਂਦਾ ਹੈ?

    1. IEEE 1394
    2. IEEE 802.3
    3. IEEE 1284
    4. IEEE 802.11
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) IEEE 1394

    ਵਿਆਖਿਆ: ਫ਼ਾਇਰਵਾਇਰ ਦਾ ਦੂਜਾ ਨਾਮ IEEE 1394 ਹੈ।

  24. ਕੰਪਿਊਟਰਾਂ ਨੂੰ ਨੈੱਟਵਰਕ ਨਾਲ ਜੋੜਨ ਵਾਲੀ ਈਥਰਨੈੱਟ ਪੋਰਟ ਨੂੰ ਹੋਰ ਕੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. VGA ਪੋਰਟ
    2. PS/2 ਪੋਰਟ
    3. LAN ਪੋਰਟ
    4. AGP ਪੋਰਟ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) LAN ਪੋਰਟ

    ਵਿਆਖਿਆ: ਪ੍ਰੀਖਿਆ ਨੁਕਤਾ: ਈਥਰਨੈੱਟ ਪੋਰਟ = LAN ਪੋਰਟ; ਇੰਟਰਨੈੱਟ ਕਨੈਕਸ਼ਨ ਅਤੇ ਲੋਕਲ ਏਰੀਆ ਨੈੱਟਵਰਕ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਹੈ।

  25. ਕਿਹੜਾ ਭਾਗ CPU, RAM, ਸਟੋਰੇਜ ਡਿਵਾਈਸਾਂ ਅਤੇ ਐਕਸਪੈਂਸ਼ਨ ਕਾਰਡਾਂ ਵਿਚਕਾਰ ਸੰਚਾਰ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ?

    1. ਹੀਟ ਸਿੰਕ
    2. CMOS ਬੈਟਰੀ
    3. ਚਿੱਪਸੈੱਟ
    4. ਪਾਵਰ ਕਨੈਕਟਰ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਚਿੱਪਸੈੱਟ

    ਵਿਆਖਿਆ: ਚਿੱਪਸੈੱਟ CPU, RAM, ਸਟੋਰੇਜ ਡਿਵਾਈਸਾਂ ਅਤੇ ਐਕਸਪੈਂਸ਼ਨ ਕਾਰਡਾਂ ਵਿਚਕਾਰ ਸੰਚਾਰ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦਾ ਹੈ।
