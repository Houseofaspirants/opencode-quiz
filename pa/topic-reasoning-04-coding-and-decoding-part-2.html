    ਵਿਆਖਿਆ: output ਦੀਆਂ ਥਾਵਾਂ 2,4,6 ਤੋਂ SAN ਅਤੇ 1,3,5 ਤੋਂ GAM ਮਿਲਦਾ ਹੈ। ਜੋੜ ਕੇ SANGAM ਬਣਦਾ ਹੈ।

  20. ਤਿੰਨ records ਵਿੱਚ ਪੂਰੇ ਸ਼ਬਦ ਨੂੰ ਸਹੀ ਉਲਟਿਆ ਗਿਆ ਹੈ। ਕਿਹੜੇ record ਵਿੱਚ ਗਲਤੀ ਹੈ?

    1. KULLU → ULLUK
    2. KOTLI → ILTOK
    3. MANDI → IDNMA
    4. SHIMLA → ALMIHS
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) MANDI → IDNMA

    ਵਿਆਖਿਆ: MANDI ਨੂੰ ਉਲਟਣ ਨਾਲ IDNAM ਬਣਦਾ ਹੈ। IDNMA ਵਿੱਚ ਆਖ਼ਰੀ ਦੋ ਅੱਖਰ ਬਦਲੇ ਹੋਏ ਹਨ।

  21. ਪੂਰੇ ਅੰਕ ਦਾ encoder f(n)=n²-2n ਵਰਤਦਾ ਹੈ। ਜੇ output 120 ਹੈ, ਤਾਂ ਕਿਹੜਾ ਧਨਾਤਮਕ input ਵਰਤਿਆ ਗਿਆ ਸੀ?

    1. 14
    2. 10
    3. 12
    4. 11
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) 12

    ਵਿਆਖਿਆ: n²-2n ਨੂੰ (n-1)²-1 ਲਿਖੋ। ਇਸ ਲਈ (n-1)²=121 ਅਤੇ ਧਨਾਤਮਕ input 12 ਹੈ।

  22. ਮੂਲ codes: A→4, U→9, R→%, 3→K, 6→@। ਅਸਲ characters ਜਾਂਚੋ। ਦੋਵੇਂ ਸ਼ਰਤਾਂ ਇਕੱਠੀਆਂ ਲਾਓ: ਸਵਰ ਸਿਰਿਆਂ ਦੇ ਮੂਲ codes ਆਪਸ ਵਿੱਚ ਬਦਲੋ; ਹਰ ਅਸਲ ਟਾਂਕ digit ਦਾ code # ਕਰੋ। A3R6U ਦਾ ਆਖ਼ਰੀ code ਲੱਭੋ।

    1. 9K%@4
    2. 9#%@4
    3. 9#%#4
    4. 4#%@9
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) 9#%@4

    ਵਿਆਖਿਆ: ਮੂਲ code 4K%@9 ਹੈ। ਸਵਰ ਸਿਰਿਆਂ ਦੇ codes 4 ਅਤੇ 9 ਬਦਲੋ ਅਤੇ ਸਿਰਫ਼ ਅਸਲ ਟਾਂਕ digit 3 ਦਾ code ਬਦਲੋ: 9#%@4।

  23. codes ਤੈਅ, ਇੱਕ-ਤੋਂ-ਇੱਕ ਅਤੇ ਬਿਨਾਂ ਤੈਅ ਕ੍ਰਮ ਦੇ ਹਨ। “buses reach Ludhiana” = “fa mi so”; “trains reach Delhi” = “mi ku na”; “buses leave Delhi” = “fa te na”। “so te ku” Decode ਕਰੋ।

    1. Ludhiana leave Delhi
    2. buses leave trains
    3. Ludhiana leave trains
    4. Ludhiana reach trains
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Ludhiana leave trains

    ਵਿਆਖਿਆ: ਸਾਂਝੇ ਸ਼ਬਦਾਂ ਤੋਂ buses=fa, reach=mi ਅਤੇ Delhi=na ਮਿਲਦੇ ਹਨ। ਬਚੇ codes so=Ludhiana, te=leave ਅਤੇ ku=trains ਹਨ।

  24. ਪਹਿਲਾਂ RUPAR ਦੇ ਹਰ ਅੱਖਰ ਨੂੰ alphabet ਦੇ ਉਲਟੇ ਅੱਖਰ ਨਾਲ ਬਦਲੋ। ਫਿਰ code ਵਿੱਚ ਸਿਰਫ਼ ਅਸਲ ਟਾਂਕ ਥਾਵਾਂ 1,3,5 ਰੱਖੋ। ਕਿਹੜੇ ਤਿੰਨ ਅੱਖਰ ਬਚਦੇ ਹਨ?

    1. IFI
    2. IKI
    3. IRK
    4. UKZ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) IKI

    ਵਿਆਖਿਆ: ਬਚੇ ਅਸਲ ਅੱਖਰ R,P,R ਹਨ। ਇਨ੍ਹਾਂ ਦੇ ਉਲਟੇ I,K,I ਹਨ, ਇਸ ਲਈ IKI ਬਣਦਾ ਹੈ।

  25. ਇੱਕੋ shift ਨਾਲ DELHI ਤੋਂ ZAHDE ਬਣਦਾ ਹੈ। ਇਸੇ shift ਨਾਲ PUNE ਦਾ ਕਿਹੜਾ code ਛਪੇਗਾ?
