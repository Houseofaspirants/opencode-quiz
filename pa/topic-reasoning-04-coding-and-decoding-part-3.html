    3. 0T
    4. 0R
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) 0T

    ਵਿਆਖਿਆ: A ਤਿੰਨ ਵਾਰ ਅਤੇ T,R,N ਦੋ-ਦੋ ਵਾਰ ਹਨ। ਕੋਈ ਅੱਖਰ ਸਿਰਫ਼ ਇੱਕ ਵਾਰ ਨਹੀਂ ਆਇਆ; ਦੁਹਰਾਏ ਅੱਖਰਾਂ ਵਿੱਚ ਸਭ ਤੋਂ ਵੱਡਾ T ਹੈ, ਇਸ ਲਈ 0T।

  20. ਲਗਾਤਾਰ ਅੱਖਰਾਂ ਨੂੰ 1,3,5,7 ਥਾਵਾਂ ਅੱਗੇ ਕੀਤਾ ਜਾਂਦਾ ਹੈ। ROPA ਦੇ code S R U _ ਵਿੱਚ ਆਖ਼ਰੀ ਅੱਖਰ ਕਿਹੜਾ ਆਵੇਗਾ? ਖਾਲੀ ਥਾਂ ਅੱਖਰ ਵੱਖ ਕਰਦੀ ਹੈ।

    1. E
    2. G
    3. I
    4. H
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) H

    ਵਿਆਖਿਆ: ਚੌਥਾ ਅੱਖਰ A +7 ਹੁੰਦਾ ਹੈ: 1+7=8=H। ਪਹਿਲੀਆਂ shifts ਨਾਲ S,R,U ਮਿਲਦੇ ਹਨ।

  21. codes ਤੈਅ, ਇੱਕ-ਤੋਂ-ਇੱਕ ਅਤੇ ਬਿਨਾਂ ਤੈਅ ਕ੍ਰਮ ਦੇ ਹਨ: “young players train” = “xa bu li”; “players win medals” = “bu fo ne”; “young teams win” = “li ga fo”; “teams train daily” = “ga xa ru”। “medals young daily” ਦੇ code set ਵਿੱਚੋਂ “medals” ਦਾ code ਹਟਾਓ। ਕਿਹੜਾ ਜੋੜਾ ਬਚੇਗਾ?

    1. li ru
    2. ne ru
    3. li ga
    4. xa ru
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) li ru

    ਵਿਆਖਿਆ: ਸ਼ਬਦ ਮਿਲਾਉਣ ਨਾਲ young=li, teams=ga, train=xa ਅਤੇ daily=ru ਮਿਲਦੇ ਹਨ। medals ਹਟਾਉਣ ਨਾਲ li ru ਬਚਦਾ ਹੈ।

  22. codes ਵੱਡੇ ਅਤੇ ਛੋਟੇ ਅੱਖਰਾਂ ਵਿੱਚ ਫ਼ਰਕ ਕਰਦੇ ਹਨ: a→%, A→7, m→2, M→#। ਬਿਲਕੁਲ ਇਸੇ ਤਰ੍ਹਾਂ ਲਿਖੇ aMA ਦਾ code ਕਿਹੜਾ ਹੈ?

    1. %27
    2. %#%
    3. %#7
    4. 7#7
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) %#7

    ਵਿਆਖਿਆ: ਅੱਖਰ ਦੇ ਨਾਲ ਉਸ ਦਾ ਵੱਡਾ ਜਾਂ ਛੋਟਾ ਰੂਪ ਵੀ ਵੇਖੋ: a→%, M→#, A→7। code %#7 ਹੈ।

  23. ਅੱਠ ਅੱਖਰਾਂ ਦੇ code ਵਿੱਚ ਦੋ ਤੈਅ shifts ਵਾਰੀ-ਵਾਰੀ ਲੱਗਦੀਆਂ ਹਨ। MARIGOLD ਤੋਂ PZUHJNOC ਬਣਦਾ ਹੈ। ਉਹੀ shifts CHANDPUR ਉੱਤੇ ਲਾ ਕੇ ਸਿਰਫ਼ ਥਾਵਾਂ 2,4,6,8 ਦੱਸੋ।

    1. GMSQ
    2. GMOQ
    3. GMOR
    4. KQSU
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) GMOQ

    ਵਿਆਖਿਆ: ਮਿਸਾਲ ਵਿੱਚ +3,-1 ਵਾਰੀ-ਵਾਰੀ ਹਨ। ਮੰਗੀਆਂ ਜਿਸਤ ਥਾਵਾਂ H,N,P,R ਨੂੰ -1 ਕਰਕੇ GMOQ ਮਿਲਦਾ ਹੈ।

  24. ਇੱਕੋ +9 ਵਾਲਾ encoder ਇੱਕੋ ਪੰਜ-ਅੱਖਰੀ string ਉੱਤੇ ਤਿੰਨ ਵਾਰ ਲੱਗਦਾ ਹੈ। DANCE ਤੋਂ ਸ਼ੁਰੂ ਕਰਕੇ ਆਖ਼ਰੀ string ਕੀ ਹੋਵੇਗੀ?

    2. EBODF

  25. ਚਾਰ ਅੱਖਰਾਂ ਦੇ ਸ਼ਬਦ ਦਾ code ਟਾਂਕ ਥਾਵਾਂ ਦੇ ranks ਦੇ ਜੋੜ ਵਿੱਚੋਂ ਜਿਸਤ ਥਾਵਾਂ ਦਾ ਜੋੜ ਘਟਾ ਕੇ ਬਣਦਾ ਹੈ। KOTA ਦਾ code ਲੱਭੋ।
