Fundamentals of Computers - Part 1 ਬਾਰੇ

ਸੈੱਟ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ।

ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

ਜਿਹੜਾ ਸਵਾਲ ਦੋ ਵਾਰ ਗਲਤ ਹੋਵੇ, ਉਹਨੂੰ ਆਪਣੀ ਕਾਪੀ ਵਿੱਚ ਲਿਖ ਲਓ - ਪ੍ਰੀਖਿਆ ਤੋਂ ਪਹਿਲਾਂ ਦੁਹਰਾਈ ਲਈ ਇਹੀ ਸਭ ਤੋਂ ਕੰਮ ਦੀ ਸੂਚੀ ਹੈ।

ਸਵਾਲ ਬੈਂਕ

Fundamentals of Computers - Part 1: ਸਾਰੇ 20 ਸਵਾਲ

ਹਰ ਸਵਾਲ ਦਾ ਉੱਤਰ ਅਤੇ ਵਿਆਖਿਆ ਉਸਦੇ ਹੇਠਾਂ ਹੈ।

  1. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ computer ਦੀ ਸਭ ਤੋਂ ਸਹੀ ਪਰਿਭਾਸ਼ਾ ਕਿਹੜੀ ਹੈ?

    1. ਇੱਕ device ਜੋ ਸਿਰਫ਼ data store ਕਰਦੀ ਹੈ
    2. ਇੱਕ ਪੂਰੀ ਤਰ੍ਹਾਂ mechanical calculating device
    3. ਇੱਕ electronic device ਜੋ data ਲੈਂਦੀ, process ਕਰਦੀ, store ਕਰਦੀ ਅਤੇ output ਦਿੰਦੀ ਹੈ
    4. ਇੱਕ device ਜੋ ਸਿਰਫ਼ documents print ਕਰਨ ਲਈ ਵਰਤੀ ਜਾਂਦੀ ਹੈ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਇੱਕ electronic device ਜੋ data ਲੈਂਦੀ, process ਕਰਦੀ, store ਕਰਦੀ ਅਤੇ output ਦਿੰਦੀ ਹੈ

    ਵਿਆਖਿਆ: Computer ਇੱਕ electronic device ਹੈ ਜੋ data ਨੂੰ ਲੈਂਦੀ, process ਕਰਦੀ, store ਕਰਦੀ ਅਤੇ ਲਾਭਦਾਇਕ information ਨੂੰ output ਵਜੋਂ ਦਿੰਦੀ ਹੈ।

  2. Computer ਵਿੱਚ ਪਾਏ ਗਏ ਕੱਚੇ, ਅਣਵਿਵਸਥਿਤ ਤੱਥਾਂ ਨੂੰ ਕੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. Data
    2. Information
    3. Output
    4. Instructions
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Data

    ਵਿਆਖਿਆ: Data ਕੱਚੀ, ਅਣਵਿਵਸਥਿਤ ਜਾਣਕਾਰੀ ਹੁੰਦੀ ਹੈ, ਜਿਵੇਂ 45, 78, 92, ਜੋ input devices ਰਾਹੀਂ ਪਾਈ ਜਾਂਦੀ ਹੈ।

  3. Data + Processing = ?

    1. Instructions
    2. Memory
    3. Storage
    4. Information
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) Information

    ਵਿਆਖਿਆ: Information ਪ੍ਰੋਸੈਸ ਕੀਤਾ ਅਤੇ ਵਿਵਸਥਿਤ data ਹੁੰਦਾ ਹੈ, ਇਸ ਲਈ Data + Processing = Information।

  4. Computer ਦੇ ਮੁੱਢਲੇ ਕੰਮ-ਚੱਕਰ ਦਾ ਸਹੀ ਕ੍ਰਮ ਕਿਹੜਾ ਹੈ?

    1. Processing → Input → Output
    2. Input → Processing → Output
    3. Output → Processing → Input
    4. Input → Output → Processing
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Input → Processing → Output

    ਵਿਆਖਿਆ: ਪਹਿਲਾਂ data ਪਾਇਆ ਜਾਂਦਾ ਹੈ (input), ਫਿਰ CPU ਉਸਨੂੰ process ਕਰਦੀ ਹੈ ਅਤੇ ਅੰਤ ਵਿੱਚ output ਵਜੋਂ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ।

  5. ਕਿਸੇ ਖ਼ਾਸ ਕੰਮ ਲਈ computer ਨੂੰ ਦਿੱਤੇ ਗਏ ਹੁਕਮਾਂ ਨੂੰ ਕੀ ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. Data
    2. Instructions
    3. Information
    4. Output
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Instructions

    ਵਿਆਖਿਆ: Instructions ਉਹ commands ਹਨ ਜਿਵੇਂ file save ਕਰਨਾ, folder open ਕਰਨਾ ਜਾਂ document print ਕਰਨਾ।

  6. Computer ਦਾ 'ਦਿਮਾਗ਼' ਕਿਸ ਨੂੰ ਕਿਹਾ ਜਾਂਦਾ ਹੈ?

    1. Motherboard
    2. RAM
    3. Monitor
    4. CPU
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) CPU

    ਵਿਆਖਿਆ: CPU ਗਣਨਾਵਾਂ ਕਰਦੀ, ਕਾਰਜਾਂ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦੀ ਅਤੇ data ਨੂੰ process ਕਰਦੀ ਹੈ, ਇਸ ਲਈ ਇਸਨੂੰ computer ਦਾ ਦਿਮਾਗ਼ ਕਿਹਾ ਜਾਂਦਾ ਹੈ।

  7. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ input device ਹੈ?

    1. Keyboard
    2. Monitor
    3. Printer
    4. Speaker
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Keyboard

    ਵਿਆਖਿਆ: Keyboard ਰਾਹੀਂ computer ਵਿੱਚ text ਪਾਇਆ ਜਾਂਦਾ ਹੈ; monitor, printer ਅਤੇ speaker output devices ਹਨ।

  8. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ output device ਹੈ?

    1. Mouse
    2. Scanner
    3. Monitor
    4. Webcam
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Monitor

    ਵਿਆਖਿਆ: Monitor process ਕੀਤੀ ਜਾਣਕਾਰੀ ਦਿਖਾਉਂਦਾ ਹੈ। Mouse, scanner ਅਤੇ webcam input devices ਹਨ।

  9. Computer ਦੀ speed ਤੋਂ ਕੀ ਭਾਵ ਹੈ?

    1. ਮਾਨੀਟਰ ਦੀ screen ਦਾ ਆਕਾਰ
    2. ਹਾਰਡ ਡਿਸਕ ਦੀ storage capacity
    3. Computer ਵਰਤਣ ਵਾਲੇ users ਦੀ ਗਿਣਤੀ
    4. ਇੱਕ ਸਕਿੰਟ ਵਿੱਚ process ਹੋਣ ਵਾਲੀਆਂ instructions ਦੀ ਗਿਣਤੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਇੱਕ ਸਕਿੰਟ ਵਿੱਚ process ਹੋਣ ਵਾਲੀਆਂ instructions ਦੀ ਗਿਣਤੀ

    ਵਿਆਖਿਆ: Speed ਇੱਕ ਸਕਿੰਟ ਵਿੱਚ computer ਦੁਆਰਾ process ਕੀਤੀਆਂ ਜਾਣ ਵਾਲੀਆਂ instructions ਦੀ ਗਿਣਤੀ ਹੁੰਦੀ ਹੈ।

  10. Computer ਦੀ speed ਮਾਪਣ ਲਈ ਵਰਤੀਆਂ ਜਾਂਦੀਆਂ ਇਕਾਈਆਂ ਵਿੱਚੋਂ ਸਭ ਤੋਂ ਛੋਟੀ ਕਿਹੜੀ ਹੈ?

    1. Nanosecond (ns)
    2. Picosecond (ps)
    3. Microsecond (μs)
    4. Millisecond (ms)
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Picosecond (ps)

    ਵਿਆਖਿਆ: Picosecond (10⁻¹² s) nanosecond (10⁻⁹ s), microsecond (10⁻⁶ s) ਅਤੇ millisecond (10⁻³ s) ਤੋਂ ਛੋਟੀ ਹੁੰਦੀ ਹੈ।

  11. Intel Core i7 ਅਤੇ AMD Ryzen ਕਿਸ ਦੀਆਂ ਉਦਾਹਰਣਾਂ ਹਨ?

    1. Storage devices
    2. Output devices
    3. Processors (CPU)
    4. Operating systems
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Processors (CPU)

    ਵਿਆਖਿਆ: ਇਹ processors (CPU) ਹਨ ਜੋ instructions ਨੂੰ execute ਕਰਦੇ ਅਤੇ data ਨੂੰ process ਕਰਦੇ ਹਨ।

  12. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ ਸਥਾਈ (permanent) storage device ਹੈ?

    1. SSD
    2. RAM
    3. Cache Memory
    4. Motherboard
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) SSD

    ਵਿਆਖਿਆ: HDD, SSD, pen drive ਅਤੇ CD/DVD data ਨੂੰ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸਟੋਰ ਕਰਦੇ ਹਨ, ਜਦਕਿ RAM ਅਤੇ cache ਅਸਥਾਈ memory ਹਨ।

  13. Computer ਦੇ ਸਾਰੇ ਹਿੱਸਿਆਂ ਨੂੰ ਜੋੜਨ ਵਾਲਾ ਮੁੱਖ circuit board ਕਿਹੜਾ ਹੈ?

    1. Motherboard
    2. Hard Disk Drive
    3. Cache Memory
    4. Scanner
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Motherboard

    ਵਿਆਖਿਆ: Motherboard CPU, RAM, storage, input ਅਤੇ output devices ਨੂੰ ਜੋੜਦਾ ਹੈ; ਇਹ computer ਦੀ ਰੀੜ੍ਹ ਦੀ ਹੱਡੀ (backbone) ਹੈ।

  14. Memory ਅਤੇ Storage ਬਾਰੇ ਕਿਹੜਾ ਕਥਨ ਸਹੀ ਹੈ?

    1. Memory ਸਥਾਈ ਹੈ, Storage ਅਸਥਾਈ ਹੈ
    2. Memory ਅਤੇ Storage ਦੋਵੇਂ ਸਥਾਈ ਹਨ
    3. Memory ਅਸਥਾਈ ਹੈ, Storage ਸਥਾਈ ਹੈ
    4. Memory ਅਤੇ Storage ਦੋਵੇਂ ਅਸਥਾਈ ਹਨ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) Memory ਅਸਥਾਈ ਹੈ, Storage ਸਥਾਈ ਹੈ

    ਵਿਆਖਿਆ: Memory processing ਦੌਰਾਨ data ਨੂੰ ਅਸਥਾਈ ਤੌਰ 'ਤੇ ਰੱਖਦੀ ਹੈ, ਜਦਕਿ storage data ਨੂੰ ਸਥਾਈ ਤੌਰ 'ਤੇ ਸੰਭਾਲਦੀ ਹੈ।

  15. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ storage device ਨਹੀਂ ਹੈ?

    1. Pen Drive
    2. Scanner
    3. SSD
    4. CD/DVD
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Scanner

    ਵਿਆਖਿਆ: Scanner ਇੱਕ input device ਹੈ ਜੋ documents ਸਕੈਨ ਕਰਦੀ ਹੈ; ਬਾਕੀ ਸਾਰੇ data ਸਟੋਰ ਕਰਦੇ ਹਨ।

  16. Computer ਵਿੱਚ ਆਵਾਜ਼ (sound) ਪਾਉਣ ਲਈ ਕਿਹੜੀ device ਵਰਤੀ ਜਾਂਦੀ ਹੈ?

    1. Speaker
    2. Projector
    3. Printer
    4. Microphone
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) Microphone

    ਵਿਆਖਿਆ: Microphone ਆਵਾਜ਼ ਦੀ input device ਹੈ, ਜਦਕਿ speaker ਆਵਾਜ਼ ਨੂੰ output ਵਜੋਂ ਪੈਦਾ ਕਰਦਾ ਹੈ।

  17. CPU ਦੀ ਕਿਹੜੀ unit computer ਦੀਆਂ ਸਾਰੀਆਂ ਗਤੀਵਿਧੀਆਂ ਨੂੰ ਕੰਟਰੋਲ ਅਤੇ ਤਾਲਮੇਲ ਕਰਦੀ ਹੈ?

    1. Arithmetic Logic Unit (ALU)
    2. Control Unit (CU)
    3. Memory Unit
    4. Cache Memory
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) Control Unit (CU)

    ਵਿਆਖਿਆ: Control Unit (CU) ਸਾਰੀਆਂ ਗਤੀਵਿਧੀਆਂ ਨੂੰ ਕੰਟਰੋਲ ਕਰਦੀ ਹੈ, ਜਦਕਿ ALU arithmetic ਅਤੇ logical operations ਕਰਦੀ ਹੈ।

  18. CPU ਕਿਹਨਾਂ ਭਾਗਾਂ ਤੋਂ ਬਣੀ ਹੁੰਦੀ ਹੈ?

    1. CU + ALU + Memory Unit
    2. ALU + RAM + Hard Disk
    3. CU + Monitor + Keyboard
    4. Motherboard + ALU + Printer
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) CU + ALU + Memory Unit

    ਵਿਆਖਿਆ: ਨੋਟਸ ਅਨੁਸਾਰ CPU = CU + ALU + Memory Unit।

  19. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੀ ਸੂਚੀ ਵਿੱਚ ਸਿਰਫ਼ input devices ਹਨ?

    1. Keyboard, Printer, Mouse
    2. Monitor, Speaker, Scanner
    3. Projector, Webcam, Microphone
    4. Keyboard, Scanner, Webcam
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) Keyboard, Scanner, Webcam

    ਵਿਆਖਿਆ: Keyboard, scanner ਅਤੇ webcam ਤਿੰਨੇ input devices ਹਨ; ਬਾਕੀ ਹਰ ਸੂਚੀ ਵਿੱਚ printer, monitor, speaker ਜਾਂ projector ਵਰਗੀ output device ਹੈ।

  20. ਹੇਠ ਲਿਖਿਆਂ ਵਿੱਚੋਂ ਕਿਹੜੇ memory (ਅਸਥਾਈ ਸਟੋਰੇਜ) ਦੀਆਂ ਉਦਾਹਰਣਾਂ ਹਨ?

    1. HDD ਅਤੇ SSD
    2. Pen Drive ਅਤੇ CD/DVD
    3. RAM ਅਤੇ Cache Memory
    4. CPU ਅਤੇ Motherboard
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) RAM ਅਤੇ Cache Memory

    ਵਿਆਖਿਆ: RAM ਅਤੇ Cache Memory processing ਦੌਰਾਨ data ਨੂੰ ਅਸਥਾਈ ਤੌਰ 'ਤੇ ਰੱਖਦੀਆਂ ਹਨ ਅਤੇ CPU ਨਾਲ ਤੇਜ਼ ਸੰਚਾਰ ਸੰਭਵ ਬਣਾਉਂਦੀਆਂ ਹਨ।
