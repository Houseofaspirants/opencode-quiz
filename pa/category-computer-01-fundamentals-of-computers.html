ਨਮੂਨਾ ਸਵਾਲ

ਕੰਪਿਊਟਰ ਦੀ ਮੁੱਢਲੀ ਜਾਣਕਾਰੀ: ਨਮੂਨੇ ਦੇ ਸਵਾਲ

ਹਰ ਸੈੱਟ ਵਿੱਚੋਂ ਦੋ ਸਵਾਲ - ਉੱਤਰ ਵੇਖਣ ਲਈ ਦਬਾਓ।

  1. ਅਧਿਆਇ ਅਨੁਸਾਰ, ਕੰਪਿਊਟਰ ਇੱਕ ਮਨੁੱਖ ਦੁਆਰਾ ਬਣਾਈ ______ ਮਸ਼ੀਨ ਹੈ।

    1. ਮਕੈਨੀਕਲ
    2. ਹਾਈਡ੍ਰੌਲਿਕ
    3. ਇਲੈਕਟ੍ਰਾਨਿਕ
    4. ਚੁੰਬਕੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (C) ਇਲੈਕਟ੍ਰਾਨਿਕ

    ਵਿਆਖਿਆ: ਕੰਪਿਊਟਰ ਮਨੁੱਖ ਦੁਆਰਾ ਬਣਾਈ ਇਲੈਕਟ੍ਰਾਨਿਕ ਮਸ਼ੀਨ ਹੈ ਜੋ ਡਾਟਾ ਲੈ ਕੇ, ਪ੍ਰੋਸੈਸ ਕਰਕੇ ਸੂਚਨਾ ਦਿੰਦੀ ਹੈ।

  2. ਕੰਪਿਊਟਰ ਦੇ ਮੁੱਢਲੇ ਕਾਰਜ-ਚੱਕਰ ਦਾ ਸਹੀ ਕ੍ਰਮ ਕਿਹੜਾ ਹੈ?

    1. Input → Processing → Output
    2. Processing → Input → Output
    3. Output → Processing → Input
    4. Input → Output → Processing
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) Input → Processing → Output

    ਵਿਆਖਿਆ: ਕੰਪਿਊਟਰ ਦਾ ਮੁੱਢਲਾ ਕੰਮ Input → Processing → Output ਚੱਕਰ ਅਨੁਸਾਰ ਹੁੰਦਾ ਹੈ।

  3. ਵੀਡੀਓ ਇਨਪੁੱਟ ਕਰਨ ਲਈ ਕਿਹੜੀ ਇਨਪੁੱਟ ਡਿਵਾਈਸ ਵਰਤੀ ਜਾਂਦੀ ਹੈ?

    1. ਵੈੱਬਕੈਮ
    2. ਮਾਈਕ੍ਰੋਫੋਨ
    3. ਸਕੈਨਰ
    4. ਕੀਬੋਰਡ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਵੈੱਬਕੈਮ

    ਵਿਆਖਿਆ: ਅਧਿਆਇ ਦੀ ਸਾਰਣੀ ਵਿੱਚ ਵੈੱਬਕੈਮ ਵੀਡੀਓ ਇਨਪੁੱਟ ਕਰਨ ਵਾਲੀ ਡਿਵਾਈਸ ਹੈ।

  4. ਇਨਪੁੱਟ ਡਿਵਾਈਸ ਵਜੋਂ ਮਾਈਕ੍ਰੋਫੋਨ ਦਾ ਕੰਮ ਹੈ:

    1. ਵੀਡੀਓ ਇਨਪੁੱਟ ਕਰਨਾ
    2. ਦਸਤਾਵੇਜ਼ ਸਕੈਨ ਕਰਨਾ
    3. ਪੁਆਇੰਟ ਅਤੇ ਕਲਿੱਕ ਕਰਨਾ
    4. ਆਵਾਜ਼ ਇਨਪੁੱਟ ਕਰਨਾ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) ਆਵਾਜ਼ ਇਨਪੁੱਟ ਕਰਨਾ

    ਵਿਆਖਿਆ: ਮਾਈਕ੍ਰੋਫੋਨ ਆਵਾਜ਼ ਇਨਪੁੱਟ ਕਰਨ ਵਾਲੀ ਡਿਵਾਈਸ ਹੈ।
