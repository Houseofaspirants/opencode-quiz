ਇਹ ਸਵਾਲ ਪੰਜਾਬ ਦੀਆਂ ਸਰਕਾਰੀ ਪ੍ਰੀਖਿਆਵਾਂ ਦੇ ਪੈਟਰਨ ਉੱਤੇ ਬਣਾਏ ਗਏ ਹਨ: ਚਾਰ ਵਿਕਲਪ, ਇੱਕ ਸਹੀ ਉੱਤਰ ਅਤੇ ਹਰ ਉੱਤਰ ਦੀ ਵਿਆਖਿਆ। ਇਹੀ ਸੈੱਟ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵੀ ਮੌਜੂਦ ਹੈ।

ਜਿਹੜਾ ਸਵਾਲ ਦੋ ਵਾਰ ਗਲਤ ਹੋਵੇ, ਉਹਨੂੰ ਆਪਣੀ ਕਾਪੀ ਵਿੱਚ ਲਿਖ ਲਓ - ਪ੍ਰੀਖਿਆ ਤੋਂ ਪਹਿਲਾਂ ਦੁਹਰਾਈ ਲਈ ਇਹੀ ਸਭ ਤੋਂ ਕੰਮ ਦੀ ਸੂਚੀ ਹੈ।

    3. Ctrl + Shift + D ਅਤੇ Ctrl + Shift + T
    4. Alt + Shift + D ਅਤੇ Alt + Shift + T
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (D) Alt + Shift + D ਅਤੇ Alt + Shift + T

    ਵਿਆਖਿਆ: Alt + Shift + D ਮੌਜੂਦਾ date ਅਤੇ Alt + Shift + T ਮੌਜੂਦਾ time ਪਾਉਂਦੀ ਹੈ। Ctrl + D Font dialog ਖੋਲ੍ਹਦੀ ਹੈ ਅਤੇ Ctrl + T hanging indent ਬਣਾਉਂਦੀ ਹੈ।

  23. MS Word ਦੀਆਂ shortcut keys ਬਾਰੇ ਹੇਠ ਲਿਖੇ ਕਥਨਾਂ 'ਤੇ ਵਿਚਾਰ ਕਰੋ: 1. Ctrl + ] font size ਨੂੰ ਇੱਕ point ਵਧਾਉਂਦੀ ਹੈ। 2. Ctrl + 2 double line spacing ਲਾਗੂ ਕਰਦੀ ਹੈ। 3. Ctrl + T hanging indent ਬਣਾਉਂਦੀ ਹੈ। ਉਪਰੋਕਤ ਵਿੱਚੋਂ ਕਿਹੜੇ ਕਥਨ ਸਹੀ ਹਨ?

    2. ਸਿਰਫ਼ 2 ਅਤੇ 3

    4. 1, 2 ਅਤੇ 3
    ਉੱਤਰ ਵੇਖੋ

    ਵਿਆਖਿਆ: ਤਿੰਨੋਂ ਸਹੀ ਹਨ: Ctrl + ] / Ctrl + [ font size ਨੂੰ 1 point ਬਦਲਦੀਆਂ ਹਨ, Ctrl + 1 / Ctrl + 2 single / double spacing ਲਾਗੂ ਕਰਦੀਆਂ ਹਨ, ਅਤੇ Ctrl + T hanging indent ਬਣਾਉਂਦੀ ਹੈ।

  24. MS Word ਵਿੱਚ ਕਿਸੇ ਸ਼ਬਦ 'ਤੇ double-click ਕਰਨ ਨਾਲ ਸ਼ਬਦ select ਹੁੰਦਾ ਹੈ। Triple-click ਕਰਨ ਨਾਲ ਕੀ select ਹੁੰਦਾ ਹੈ?

  25. MS Word ਵਿੱਚ cursor ਵਾਲੀ ਥਾਂ 'ਤੇ bookmark ਲਾਉਣ ਲਈ ਕਿਹੜੀ shortcut ਹੈ?
