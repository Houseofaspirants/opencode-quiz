ਸਮਾਨਤਾ (Analogy): ਨਮੂਨੇ ਦੇ ਸਵਾਲ

ਹਰ ਸੈੱਟ ਵਿੱਚੋਂ ਦੋ ਸਵਾਲ - ਉੱਤਰ ਵੇਖਣ ਲਈ ਦਬਾਓ।

  1. ਇਸੇ ਤਰ੍ਹਾਂ ਦਾ ਸੰਬੰਧ ਚੁਣੋ: ਆਸਟ੍ਰੇਲੀਆ : ਕੈਨਬਰਾ :: ਆਸਟ੍ਰੀਆ : ?

    1. ਵਿਯੇਨਾ
    2. ਢਾਕਾ
    3. ਥਿੰਫੂ
    4. ਬਗਦਾਦ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (A) ਵਿਯੇਨਾ

    ਵਿਆਖਿਆ: ਦੂਜਾ ਸ਼ਬਦ ਪਹਿਲੇ ਦੇਸ਼ ਦੀ ਰਾਜਧਾਨੀ ਹੈ। ਇੱਥੇ ਆਸਟ੍ਰੇਲੀਆ ਦਾ ਜੋੜ ਕੈਨਬਰਾ ਨਾਲ ਹੈ; ਇਸੇ ਤਰ੍ਹਾਂ ਆਸਟ੍ਰੀਆ ਦਾ ਜੋੜ ਵਿਯੇਨਾ ਨਾਲ ਹੈ।

  2. ਇਸੇ ਤਰ੍ਹਾਂ ਦਾ ਸੰਬੰਧ ਚੁਣੋ: ਆਸਟ੍ਰੀਆ : ਵਿਯੇਨਾ :: ਬੰਗਲਾਦੇਸ਼ : ?

    1. ਥਿੰਫੂ
    2. ਢਾਕਾ
    3. ਬਗਦਾਦ
    4. ਕੋਪਨਹੇਗਨ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਢਾਕਾ

    ਵਿਆਖਿਆ: ਦੂਜਾ ਸ਼ਬਦ ਪਹਿਲੇ ਦੇਸ਼ ਦੀ ਰਾਜਧਾਨੀ ਹੈ। ਇੱਥੇ ਆਸਟ੍ਰੀਆ ਦਾ ਜੋੜ ਵਿਯੇਨਾ ਨਾਲ ਹੈ; ਇਸੇ ਤਰ੍ਹਾਂ ਬੰਗਲਾਦੇਸ਼ ਦਾ ਜੋੜ ਢਾਕਾ ਨਾਲ ਹੈ।

  3. ਇਸੇ ਤਰ੍ਹਾਂ ਦਾ ਸੰਬੰਧ ਚੁਣੋ: ਅੰਗੂਰ : ਗੁੱਛਾ :: ਸਿਪਾਹੀ : ?

    1. ਟੀਮ
    2. ਫੌਜ
    3. ਮੰਤਰੀ ਮੰਡਲ
    4. ਕਾਲੋਨੀ
    ਉੱਤਰ ਵੇਖੋ

    ਸਹੀ ਉੱਤਰ: (B) ਫੌਜ

    ਵਿਆਖਿਆ: ਦੂਜਾ ਸ਼ਬਦ ਪਹਿਲੇ ਵਿੱਚ ਦਿੱਤੇ ਜੀਵਾਂ ਜਾਂ ਵਿਅਕਤੀਆਂ ਦੇ ਸਮੂਹ ਦਾ ਨਾਂ ਹੈ। ਇੱਥੇ ਅੰਗੂਰ ਦਾ ਜੋੜ ਗੁੱਛਾ ਨਾਲ ਹੈ; ਇਸੇ ਤਰ੍ਹਾਂ ਸਿਪਾਹੀ ਦਾ ਜੋੜ ਫੌਜ ਨਾਲ ਹੈ।

  4. ਇਸੇ ਤਰ੍ਹਾਂ ਦਾ ਸੰਬੰਧ ਚੁਣੋ: ਸਿਪਾਹੀ : ਫੌਜ :: ਖਿਡਾਰੀ : ?
