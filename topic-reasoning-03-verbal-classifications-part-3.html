Question bank

Verbal Classifications MCQ – Part 3: all 25 questions

Read the question, pick an option, then open the answer.

  1. A computer course lists programming languages. Which entry belongs to the operating-system category instead?

    1. Java
    2. Linux
    3. C++
    4. Python
    Show answer

    Answer: (B) Linux

    Explanation: Linux is an operating system. Python, Java and C++ are programming languages.

  2. Take alphabet positions. In three groups, the square of the middle position equals the product of the outer positions. Which group fails?

    1. ADP
    2. ILP
    3. DFI
    4. DJX
    Show answer

    Answer: (D) DJX

    Explanation: DJX gives 10² = 100 but 4 × 24 = 96. The other checks are 4² = 1 × 16, 6² = 4 × 9 and 12² = 9 × 16.

  3. Subtracting 1 turns all but one of these values into a perfect cube. Identify the exception.

    1. 2199
    2. 3376
    3. 1332
    4. 730
    Show answer

    Answer: (A) 2199

    Explanation: Subtract 1: 729 = 9³, 1331 = 11³ and 3375 = 15³. But 2199 − 1 = 2198, whereas 13³ = 2197.

  4. Most pairs express opposite meanings. Which pair expresses similar meanings instead?

    1. Rigid : Flexible
    2. Expand : Contract
    3. Frugal : Thrifty
    4. Scarce : Abundant
    Show answer

    Answer: (C) Frugal : Thrifty

    Explanation: Frugal and thrifty both describe economical use of resources. Each other pair has opposite meanings.

  5. A laboratory classifies processes by whether a new substance is formed. Which process belongs with physical changes rather than the other three?

    1. Burning of magnesium
    2. Sublimation of camphor
    3. Rusting of iron
    4. Souring of milk
    Show answer

    Answer: (B) Sublimation of camphor

    Explanation: Camphor changes directly from solid to vapour without forming a new substance. The other processes form new substances and are chemical changes.

  6. For each pair, count common positive factors of the two numbers. Which pair has more than one?

    1. 39 : 65
    2. 49 : 64
    3. 22 : 35
    4. 27 : 40
    Show answer

    Answer: (A) 39 : 65

    Explanation: 39 and 65 share 1 and 13. Each other pair is coprime and shares only 1.

  7. A code should contain two letters appearing twice each and one letter appearing once. Which code violates this frequency rule?

    1. ABACB
    2. GHIGH
    3. MMMPQ
    4. DEEDF
    Show answer

    Answer: (C) MMMPQ

    Explanation: MMMPQ has frequencies 3, 1 and 1. The other codes have frequencies 2, 2 and 1.

  8. Which gas is outside the noble-gas family represented by the other three?

    1. Chlorine
    2. Neon
    3. Argon
    4. Krypton
    Show answer

    Answer: (A) Chlorine

    Explanation: Chlorine is a halogen. Neon, argon and krypton are noble gases.

  9. Compare the number of distinct prime factors, ignoring repeated powers. Which number has a different count?

    1. 200
    2. 363
    3. 242
    4. 390
    Show answer

    Answer: (D) 390

    Explanation: 390 = 2 × 3 × 5 × 13 has four distinct prime factors. 200 = 2³ × 5², 242 = 2 × 11² and 363 = 3 × 11² each have two.

  10. Gurleen labels three quantities as vectors. Which quantity needs a scalar label?

    1. Work
    2. Momentum
    3. Acceleration
    4. Displacement
    Show answer

    Answer: (A) Work

    Explanation: Work has magnitude but no direction and is scalar. Displacement, acceleration and momentum have magnitude and direction.

  11. The alphabet is cyclic, so Z is followed by A. Which group does not advance four positions at every step?

    1. ZDHL
    2. XBFK
    3. UYCG
    4. WAEI
    Show answer

    Answer: (B) XBFK

    Explanation: X to B and B to F advance 4 positions, but F to K advances 5. The other groups advance 4 throughout.

  12. Read each pair as a collective noun followed by a member of that collection. Which relationship is reversed?

    1. Jury : Juror
    2. Bouquet : Flower
    3. Sailor : Crew
    4. Orchestra : Musician
    Show answer

    Answer: (C) Sailor : Crew

    Explanation: A crew is a group of sailors, so Sailor : Crew runs from member to collection. The others run from collection to member.

  13. A packing machine accepts only numbers divisible by 8. Which label should trigger rejection?

    1. 1768
    2. 1032
    3. 1348
    4. 2216
    Show answer

    Answer: (C) 1348

    Explanation: The last three digits of 1348 give 348 = 8 × 43 + 4. The other numbers divide by 8 as 129, 221 and 277.

  14. Karan transforms a three-digit number using the same digit-based operation in each pair. Which pair is inconsistent with the other three?

    1. 643 : 61
    2. 427 : 91
    3. 316 : 46
    4. 528 : 93
    Show answer

    Answer: (B) 427 : 91

    Explanation: For 427, 4² + 2² + 7² = 16 + 4 + 49 = 69, not 91. The other digit-square sums are 46, 93 and 61.

  15. In a Patiala language class, Reena groups nouns naming qualities or states rather than physical objects. Which noun is misplaced?

    1. Freedom
    2. Courage
    3. Wisdom
    4. Medal
    Show answer

    Answer: (D) Medal

    Explanation: A medal is a physical object. Courage, wisdom and freedom name abstract qualities or states.

  16. With A = 1 to Z = 26, add all three positions in each group. Which total is not 40?

    1. FLV
    2. HLT
    3. DKY
    4. GMS
    Show answer

    Answer: (D) GMS

    Explanation: GMS totals 7 + 13 + 19 = 39. DKY gives 4 + 11 + 25 = 40, FLV gives 6 + 12 + 22 = 40 and HLT gives 8 + 12 + 20 = 40.

  17. Three farming practices mainly help conserve soil. Which practice tends to accelerate soil erosion?

    1. Terrace farming
    2. Overgrazing
    3. Contour ploughing
    4. Strip cropping
    Show answer

    Answer: (B) Overgrazing

    Explanation: Overgrazing removes protective vegetation and exposes soil. The other practices slow runoff or protect the soil surface.

  18. Look for larva-to-adult relationships. Which pair instead connects an organism with its food?

    1. Tadpole : Frog
    2. Maggot : Fly
    3. Silkworm : Mulberry leaf
    4. Caterpillar : Butterfly
    Show answer

    Answer: (C) Silkworm : Mulberry leaf

    Explanation: A silkworm eats mulberry leaves; it does not develop into a leaf. The other first terms develop into the second terms.

  19. Look at the hundreds, tens and units digits in that order. Which number's digits do not form an arithmetic progression?

    1. 741
    2. 258
    3. 572
    4. 864
    Show answer

    Answer: (C) 572

    Explanation: 572 has digit differences +2 and −5. The others have equal differences: +3, −3 and −2 respectively.

  20. Compare each three-letter block with the block after the colon. The intended shifts are +2, +3 and +4 positions. Which mapping is faulty?

    1. BDF : DGJ
    2. JMP : LPS
    3. NQR : PTV
    4. GIK : ILO
    Show answer

    Answer: (B) JMP : LPS

    Explanation: JMP should map to LPT: J + 2 = L, M + 3 = P and P + 4 = T. LPS shifts the last letter by only 3; the other mappings fit.

  21. A library labels three works as dramatic forms intended for performance. Which is a personal record rather than a dramatic form?

    1. Diary
    2. Tragedy
    3. Farce
    4. Comedy
    Show answer

    Answer: (A) Diary

    Explanation: A diary records personal experiences or events. Tragedy, comedy and farce are dramatic forms.

  22. Increase the first number by 1, then square it. Which pair does not give the stated second number?

    1. 18 : 360
    2. 13 : 196
    3. 10 : 121
    4. 21 : 484
    Show answer

    Answer: (A) 18 : 360

    Explanation: For 18, (18 + 1)² = 19² = 361, not 360. The other second terms equal (first + 1)².

  23. Use standard botanical structures, not kitchen names. Which underground food is a modified root rather than a modified stem?

    1. Turmeric
    2. Ginger
    3. Potato
    4. Sweet potato
    Show answer

    Answer: (D) Sweet potato

    Explanation: Sweet potato is a storage root. Potato is a stem tuber, while ginger and turmeric are rhizomes, which are modified stems.

  24. Rearrange the letters of each group alphabetically. Which group cannot become a run of four consecutive letters?

    1. HFEG
    2. WVUX
    3. RPTU
    4. NMLK
    Show answer

    Answer: (C) RPTU

    Explanation: RPTU sorts to PRTU, which is not consecutive. The others sort to EFGH, KLMN and UVWX.

  25. Define n! as the product of all integers from 1 through n. Which number is not equal to n! for any positive integer n?

    1. 5040
    2. 720
    3. 40320
    4. 2880
    Show answer

    Answer: (D) 2880

    Explanation: 720 = 6!, 5040 = 7! and 40320 = 8!. Since 720 < 2880 < 5040, 2880 lies strictly between consecutive factorials.
