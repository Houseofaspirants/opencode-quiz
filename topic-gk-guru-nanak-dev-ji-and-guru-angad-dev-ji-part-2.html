Question bank

Guru Nanak Dev Ji and Guru Angad Dev Ji - Part 2: all 6 questions

Read the question, pick an option, then open the answer.

  1. Where did Guru Nanak Dev Ji introduce the community kitchen system, or Langar Pratha, according to the notes?

    1. Batala
    2. Matte di Sarai
    3. Kartarpur
    4. Khadur Sahib
    Show answer

    Answer: (C) Kartarpur

    Explanation: The notes explicitly identify Kartarpur as the place where Guru Nanak Dev Ji introduced Langar Pratha. Batala, Matte di Sarai and Khadur Sahib are not identified as the place of its introduction in the source. The same chapter also places Kartarpur on the bank of the Ravi river.

  2. Consider the following statements about Bhai Mardana Ji. 1. The notes identify him as a companion of Guru Nanak Dev Ji. 2. The notes identify him as Muslim. Which statement(s) is/are correct?

    1. 1 only
    2. Both 1 and 2
    3. 2 only
    4. Neither 1 nor 2
    Show answer

    Answer: (B) Both 1 and 2

    Explanation: Statement 1 is correct because Bhai Mardana Ji is named in the companions entry for Guru Nanak Dev Ji. Statement 2 is also correct because that entry identifies him as Muslim. Therefore, choices rejecting either statement do not agree with the notes. The same section describes Guru Nanak Dev Ji’s missionary journeys as Udasis.

  3. Who gave Guru Angad Dev Ji the name Angad?

    1. Bhai Mardana Ji
    2. Pheru Mal Ji
    3. Bhai Bala Ji
    4. Guru Nanak Dev Ji
    Show answer

    Answer: (D) Guru Nanak Dev Ji

    Explanation: The notes explicitly state that Guru Nanak Dev Ji renamed Bhai Lehna Ji as Angad. Bhai Mardana Ji, Pheru Mal Ji and Bhai Bala Ji are not credited with this naming in the source. Guru Angad Dev Ji’s contributions also include standardising Gurmukhi for writing Punjabi.

  4. At which place was the Akhand Path associated with the beginning of Guru Nanak Dev Ji’s marriage-anniversary celebration tradition organised?

    1. Jagannath Puri
    2. Gurdwara Kandh Sahib
    3. Rameshwaram
    4. Kartarpur Sahib
    Show answer

    Answer: (B) Gurdwara Kandh Sahib

    Explanation: The notes specifically name Gurdwara Kandh Sahib as the venue of this Akhand Path. Jagannath Puri, Rameshwaram and Kartarpur Sahib are not identified as its venue in that account. The same account names the priest Kesra Singh as its organiser.

  5. Match List I with List II according to the notes. List I: A. Present-day name given for Ceylon; B. Location associated with Matte di Sarai; C. Place where Guru Nanak Dev Ji merged into Jyoti Jot List II: 1. Sri Muktsar Sahib; 2. Kartarpur Sahib; 3. Sri Lanka Choose the correct code (A–B–C).

    1. 1–2–3
    2. 2–3–1
    3. 3–1–2
    4. 3–2–1
    Show answer

    Answer: (C) 3–1–2

    Explanation: A matches 3 because the notes identify Ceylon as Sri Lanka. B matches 1 because Matte di Sarai is followed by Sri Muktsar Sahib in the birth entry. C matches 2 because Guru Nanak Dev Ji’s Jyoti Jot place is Kartarpur Sahib, so each other code contains an incorrect association. The notes also include Medina among the places visited by Guru Nanak Dev Ji.

  6. Assertion (A): The chapter deals with the first and second Sikh Gurus. Reason (R): Guru Nanak Dev Ji is identified as the first Sikh Guru and Guru Angad Dev Ji as the second Sikh Guru. Choose the correct option.

    1. Both A and R are true, and R is the correct explanation of A
    2. Both A and R are true, but R is not the correct explanation of A
    3. A is true, but R is false
    4. A is false, but R is true
    Show answer

    Answer: (A) Both A and R are true, and R is the correct explanation of A

    Explanation: A is true because the chapter covers Guru Nanak Dev Ji and Guru Angad Dev Ji as the first two Sikh Gurus. R is true because their sections are marked Guru 1 and Guru 2 respectively. These ordinal positions directly explain A, so the other options incorrectly reject either a statement or their explanatory relationship. The chapter also records Guru Angad Dev Ji’s Guruship as thirteen years.
