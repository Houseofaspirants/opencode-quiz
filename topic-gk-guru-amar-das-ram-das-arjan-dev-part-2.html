Question bank

Guru Amar Das Ji, Ram Das Ji & Arjan Dev Ji - Part 2: all 9 questions

Read the question, pick an option, then open the answer.

  1. Which Guru composed Anand Sahib?

    1. Guru Nanak Dev Ji
    2. Guru Ram Das Ji
    3. Guru Amar Das Ji
    4. Guru Arjan Dev Ji
    Show answer

    Answer: (C) Guru Amar Das Ji

    Explanation: The chapter lists Anand Sahib among the compositions of Guru Amar Das Ji. The other three options do not match the author identified in this section. The notes also place Guru Amar Das Ji in the Bhalla family.

  2. Which locality is identified as the birthplace of Guru Ram Das Ji?

    1. Basarke, Amritsar
    2. Goindwal Sahib
    3. Kartarpur, Jalandhar
    4. Chuna Mandi, Lahore
    Show answer

    Answer: (D) Chuna Mandi, Lahore

    Explanation: The revision table gives Chuna Mandi in Lahore as the birthplace of Guru Ram Das Ji. Basarke, Goindwal Sahib and Kartarpur do not match the place recorded for him. The same entry states that he was born in the Sodhi family.

  3. Who was the wife of Guru Ram Das Ji?

    1. Mata Mansa Devi Ji
    2. Bibi Bhani Ji
    3. Mata Daya Kaur
    4. Mata Bakht Kaur
    Show answer

    Answer: (B) Bibi Bhani Ji

    Explanation: The notes name Bibi Bhani Ji as the wife of Guru Ram Das Ji. Mansa Devi Ji is listed as Guru Amar Das Ji’s wife, Daya Kaur as Guru Ram Das Ji’s mother, and Bakht Kaur as Guru Amar Das Ji’s mother. The notes also identify Bibi Bhani Ji as a daughter of Guru Amar Das Ji.

  4. Where was Guru Arjan Dev Ji born?

    1. Goindwal Sahib
    2. Basarke, Amritsar
    3. Chuna Mandi, Lahore
    4. Sri Hargobindpur
    Show answer

    Answer: (A) Goindwal Sahib

    Explanation: The notes give Goindwal Sahib as the birthplace of Guru Arjan Dev Ji. Basarke, Chuna Mandi and Sri Hargobindpur do not match the birthplace in his revision table. That table records his birth date as 15 April 1563.

  5. According to the chapter, which Guru founded Sri Hargobindpur?

    1. Guru Amar Das Ji
    2. Guru Ram Das Ji
    3. Guru Arjan Dev Ji
    4. Guru Hargobind Sahib Ji
    Show answer

    Answer: (C) Guru Arjan Dev Ji

    Explanation: Sri Hargobindpur is listed among the cities founded by Guru Arjan Dev Ji. The other three options therefore do not match the attribution made in the chapter. The same list also includes Tarn Taran and Kartarpur in Jalandhar.

  6. Which place did Emperor Akbar visit, as recorded in the section on Guru Amar Das Ji?

    1. Tarn Taran
    2. Goindwal Sahib
    3. Kartarpur, Jalandhar
    4. Sri Hargobindpur
    Show answer

    Answer: (B) Goindwal Sahib

    Explanation: The chapter records Emperor Akbar’s visit to Goindwal Sahib. Tarn Taran, Kartarpur in Jalandhar and Sri Hargobindpur are not identified as the destination of this visit. Goindwal Sahib is also associated in the chapter with Baoli Sahib, a step-well.

  7. Under which Guru’s compositions does the chapter list Pothi Sahib, also called the Goindwal Pothis?

    1. Guru Nanak Dev Ji
    2. Guru Ram Das Ji
    3. Guru Arjan Dev Ji
    4. Guru Amar Das Ji
    Show answer

    Answer: (D) Guru Amar Das Ji

    Explanation: The chapter places Pothi Sahib, or the Goindwal Pothis, in the compositions section for Guru Amar Das Ji. It does not place this entry under the other three Gurus listed in the options. The notes describe these pothis as a collection of the bani of earlier Gurus, Bhagat Kabir Ji and Bhagat Namdev Ji.

  8. Match List I with List II: List I A. Guru Amar Das Ji B. Guru Ram Das Ji C. Guru Arjan Dev Ji List II (Period of guruship) 1. 1574–1581 2. 1581–1606 3. 1552–1574 Select the correct code:

    1. A–3, B–1, C–2
    2. A–1, B–3, C–2
    3. A–2, B–1, C–3
    4. A–3, B–2, C–1
    Show answer

    Answer: (A) A–3, B–1, C–2

    Explanation: Guru Amar Das Ji’s guruship is given as 1552–1574, so A matches 3. Guru Ram Das Ji’s period is 1574–1581, so B matches 1. Guru Arjan Dev Ji’s period is 1581–1606, so C matches 2. The notes give their respective durations as 22, 7 and 25 years.

  9. Consider the following statements: 1. Guru Amar Das Ji was the third Sikh Guru. 2. Guru Ram Das Ji was the fourth Sikh Guru. Which of the above is/are correct?

    1. 1 only
    2. 2 only
    3. Both 1 and 2
    4. Neither 1 nor 2
    Show answer

    Answer: (C) Both 1 and 2

    Explanation: Statement 1 is correct because the chapter identifies Guru Amar Das Ji as Guru 3. Statement 2 is correct because it identifies Guru Ram Das Ji as Guru 4. The chapter continues this sequence with Guru Arjan Dev Ji as the fifth Sikh Guru.
