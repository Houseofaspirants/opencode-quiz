Question bank

Analogy MCQ – Part 4: all 25 questions

Read the question, pick an option, then open the answer.

  1. A training chart requires worker → tool → operation, as in Goldsmith : Crucible : Melting. Which row should Jaspreet approve?

    1. Welder : Welding : Electrode holder
    2. Woodcarver : Chisel : Carving
    3. Mason : Wall : Building
    4. Plumber : Pipe : Spanner
    Show answer

    Answer: (B) Woodcarver : Chisel : Carving

    Explanation: A woodcarver uses a chisel for carving. The other rows place a material, operation or product where the tool should be.

  2. Each input is divided by the same fixed integer: 91 : 13 and 119 : 17. What is the partner of 161?

    1. 23
    2. 21
    3. 24
    4. 7
    Show answer

    Answer: (A) 23

    Explanation: 91/13=119/17=7, so divide by 7. Thus 161/7=23.

  3. FJMR → MFRJ and BGLP → LBPG reveal a fixed rearrangement of four positions. Which group is the image of HNQV?

    1. NHVQ
    2. QHVN
    3. VQNH
    4. QVHN
    Show answer

    Answer: (B) QHVN

    Explanation: Read original positions in the order 3, 1, 4, 2. From HNQV that gives Q, H, V, N.

  4. The first pair means “difficult to understand : clear”: Obscure : Lucid. Which pair has the same opposing relationship?

    1. Ambiguous : Unambiguous
    2. Vague : Indefinite
    3. Puzzling : Confusing
    4. Explicit : Definite
    Show answer

    Answer: (A) Ambiguous : Unambiguous

    Explanation: Obscure and lucid oppose unclear and clear meanings. Ambiguous and unambiguous also contrast uncertainty of meaning with clarity.

  5. Digit reversal and digit multiplication are both used in (24, 34) and (36, 45). The second entry equals the reversed first entry minus its digit product. Which pair follows?

    1. (48, 54)
    2. (68, 40)
    3. (29, 76)
    4. (57, 40)
    Show answer

    Answer: (D) (57, 40)

    Explanation: For 57, reverse to 75 and subtract 5×7=35: 75−35=40. The other pairs fail the same calculation.

  6. An animal analogy card groups Deer : Fawn with Cat : Kitten. Which description explains both links, without confusing a sound or a home with a young one?

    1. Adult animal → Its young one
    2. Male animal → Female animal
    3. Young one → Its usual shelter
    4. Animal → Its characteristic sound
    Show answer

    Answer: (A) Adult animal → Its young one

    Explanation: Fawn and kitten name the young of deer and cat respectively. Both pairs run adult animal → young one.

  7. Nations using the same currency are paired, as in Germany : Italy. Which pair can replace it on that basis?

    1. India : Bangladesh
    2. Japan : South Korea
    3. Switzerland : Sweden
    4. Belgium : Austria
    Show answer

    Answer: (D) Belgium : Austria

    Explanation: Germany and Italy both use the euro, as do Belgium and Austria. The countries in each other pair use different currencies.

  8. Using A=1 to Z=26, BE7 becomes YV40 and CF9 becomes XU36. Letters are replaced by opposites; the number uses their reverse-position sum and the input number. Encode MQ8.

    1. MQ16
    2. NJ24
    3. NJ46
    4. NJ16
    Show answer

    Answer: (D) NJ16

    Explanation: Subtract the input number from the reverse-position sum: BE gives 25+22−7=40. For MQ, the opposite letters are NJ and 14+10−8=16, giving NJ16.

  9. Complete the material link without selecting a maker or a machine: Coir mat : Coconut fibre :: Bamboo basket : X.

    1. Weaving
    2. Market
    3. Bamboo strips
    4. Basket weaver
    Show answer

    Answer: (C) Bamboo strips

    Explanation: The second term names the material of the product. A bamboo basket is made from bamboo strips.

  10. In a digit-based analogy, an input maps to the sum of the squares of its digits. If the units digit is 7 and the output is 74, which input is possible?

    1. 57
    2. 67
    3. 37
    4. 47
    Show answer

    Answer: (A) 57

    Explanation: The tens digit has square 74−7²=25, so it is 5. The input is 57, and 5²+7²=74.

  11. Two conversions are CODE → BPCF and GAME → FBLF. Vowels and consonants shift in opposite directions by one place. What does TIDE become?

    1. SJCF
    2. UHED
    3. UJEF
    4. SHCD
    Show answer

    Answer: (A) SJCF

    Explanation: Vowels move +1 and consonants −1. Thus T→S, I→J, D→C and E→F, giving SJCF.

  12. If Abundant : Ample is a synonym analogy, select the pair that keeps the same relation in both everyday and formal usage.

    1. Prudent : Reckless
    2. Inferior : Superior
    3. Impartial : Unbiased
    4. Hostile : Friendly
    Show answer

    Answer: (C) Impartial : Unbiased

    Explanation: Abundant and ample mean plentiful. Impartial and unbiased both mean free from favouritism; the other pairs are opposites.

  13. A storekeeper pairs amounts that total 100, for example (37, 63). Which further pair is analogous?

    1. (65, 36)
    2. (19, 80)
    3. (28, 71)
    4. (46, 54)
    Show answer

    Answer: (D) (46, 54)

    Explanation: Use the complementary amount, 100−46=54. Every other offered pair totals 99 or 101.

  14. A correct chain has instrument → quantity → SI unit. For the reference Voltmeter : Potential difference : Volt, assess I. Ammeter : Electric current : Ampere; II. Anemometer : Wind speed : Metre per second; III. Hygrometer : Humidity : Kelvin. Which chains preserve all three roles?

    1. II and III only
    2. I and III only
    3. I and II only
    4. III only
    Show answer

    Answer: (C) I and II only

    Explanation: I and II correctly connect an instrument, its quantity and that quantity’s SI unit. III fails because kelvin measures temperature, not humidity.

  15. Consider I. Pigeon : Coo; II. Elephant : Trumpet; III. Rooster : Coop. Which entries are analogous to Wolf : Howl, rather than animal : home?

    1. III only
    2. I and III
    3. I and II
    4. II and III
    Show answer

    Answer: (C) I and II

    Explanation: Coo and trumpet are characteristic animal sounds, matching wolf → howl. Coop names a shelter, so III is a different relation.

  16. A whole-number product rule connects 3 with 60, 5 with 210 and 7 with 504. Infer the shared rule and find the partner of 11; do not split digits.

    1. 1320
    2. 1331
    3. 132
    4. 1716
    Show answer

    Answer: (D) 1716

    Explanation: Use n(n+1)(n+2). For 11, 11×12×13=132×13=1716.

  17. On a part-to-whole board, three entries follow the reference Petal : Flower. Which entry needs its direction reversed to belong?

    1. Link : Chain
    2. Zipper : Zipper tooth
    3. Rung : Ladder
    4. Lens : Camera
    Show answer

    Answer: (B) Zipper : Zipper tooth

    Explanation: A zipper tooth is part of a zipper, so Zipper : Zipper tooth runs whole → part. The other entries already run part → whole.

  18. A code ignores direction and uses the absolute gap between alphabet positions. CF : 3 :: HK : 3 :: BW : X. What is X?

    1. 19
    2. 25
    3. 46
    4. 21
    Show answer

    Answer: (D) 21

    Explanation: B=2 and W=23, so the absolute gap is 23−2=21.

  19. Both missing words must be antonyms of their partners: Audacious : X; Impetuous : Y. Which combined choice satisfies both links?

    1. Cautious; Impulsive
    2. Cautious; Deliberate
    3. Timid; Hasty
    4. Reckless; Deliberate
    Show answer

    Answer: (B) Cautious; Deliberate

    Explanation: Cautious opposes audacious risk-taking, and deliberate opposes impetuous action without thought. Every other choice fails at least one link.

  20. A two-step rule squares a two-digit input and adds its reversal: 12 : 165 and 23 : 561. Apply the rule to 34.

    1. 1156
    2. 1199
    3. 1849
    4. 1189
    Show answer

    Answer: (B) 1199

    Explanation: Square first, then add the reversed input: 34²+43=1156+43=1199.

  21. The relation Ohm : Electrical resistance must be retained when choosing a second unit–quantity pair. Which entry confuses a measuring instrument with a unit and therefore fails?

    1. Coulomb : Electric charge
    2. Farad : Capacitance
    3. Ammeter : Electric current
    4. Tesla : Magnetic flux density
    Show answer

    Answer: (C) Ammeter : Electric current

    Explanation: An ammeter is an instrument; ampere is the unit of current. Tesla, coulomb and farad are units paired with the correct quantities.

  22. A pair means number → count of all positive divisors, including 1 and itself: (18, 6), (30, 8). Which pair has the same interpretation?

    1. (28, 8)
    2. (36, 9)
    3. (49, 4)
    4. (24, 6)
    Show answer

    Answer: (B) (36, 9)

    Explanation: Since 36=2²×3², its divisor count is (2+1)(2+1)=9. The actual counts for 24, 28 and 49 are 8, 6 and 3.

  23. Digits determine both changes in CH24 → IN8 and FK35 → NS15. Shift each letter forward by the digit sum and replace the number by the digit product. What is the output for MP46?

    1. WZ24
    2. QT24
    3. WZ10
    4. WZ46
    Show answer

    Answer: (A) WZ24

    Explanation: The digit sum is 4+6=10, so M→W and P→Z. The digit product is 4×6=24, giving WZ24.

  24. Keep the end letters fixed and swap only the middle two, as in BRIM : BIRM. Which group corresponds to CLAP?

    1. LCPA
    2. CAPL
    3. CALP
    4. PLAC
    Show answer

    Answer: (C) CALP

    Explanation: In CLAP, interchange L and A while keeping C and P fixed. The result is CALP.

  25. An ordered pair maps to one value: (24, 16) : 5 and (35, 21) : 4. Infer the common sum-and-difference rule and find the value for (42, 30).

    1. 72
    2. 12
    3. 7
    4. 6
    Show answer

    Answer: (D) 6

    Explanation: Divide the sum by the difference: (42+30)/(42−30)=72/12=6.
