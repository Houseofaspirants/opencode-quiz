Question bank

Analogy MCQ – Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. In a factory chart, Sugar : Sugarcane is followed by a second product–source pair. Which replacement keeps the relation while using a different industry?

    1. Coffee beans : Coffee drink
    2. Iron ore : Steel
    3. Silk : Silkworm rearing
    4. Linen fabric : Flax fibres
    Show answer

    Answer: (D) Linen fabric : Flax fibres

    Explanation: Sugar is obtained from sugarcane; linen fabric is made from flax fibres. The other entries reverse the order or name a process.

  2. The relation 52 → 39 represents subtracting 13. A second entry starts at 86; what is its corresponding value?

    1. 73
    2. 74
    3. 99
    4. 63
    Show answer

    Answer: (A) 73

    Explanation: Keep the subtraction unchanged: 86−13=73.

  3. The pair WARD : AWDR is formed by interchanging neighbouring letters in pairs. Which transformation follows the same arrangement?

    1. FORK : RFKO
    2. FORK : OFKR
    3. FORK : KROF
    4. FORK : ORKF
    Show answer

    Answer: (B) FORK : OFKR

    Explanation: Swap positions 1 and 2, then 3 and 4. FORK becomes OFKR.

  4. Which pair cannot be placed beside Conceal : Reveal in a collection restricted to antonym pairs?

    1. Accept : Reject
    2. Obsolete : Outdated
    3. Optimistic : Pessimistic
    4. Expand : Shrink
    Show answer

    Answer: (B) Obsolete : Outdated

    Explanation: Conceal and reveal are opposites. Obsolete and outdated are synonyms, whereas the other pairs are opposites.

  5. Ravinder identifies the same whole-number rule in (4, 67) and (6, 219). Which pair will pass his test?

    1. (7, 347)
    2. (10, 1000)
    3. (9, 732)
    4. (8, 516)
    Show answer

    Answer: (C) (9, 732)

    Explanation: Cube the first number and add 3: 4³+3=67 and 6³+3=219. Only 9³+3=732 matches.

  6. A farm chart links Goat to Bleat. If the second column always names a sound, which alternative is a valid parallel entry?

    1. Goose : Gosling
    2. Owl : Hoot
    3. Eagle : Eyrie
    4. Duck : Waddle
    Show answer

    Answer: (B) Owl : Hoot

    Explanation: Bleat is a goat’s sound, and hoot is an owl’s sound. Home, young one and movement are different relations.

  7. A unit-to-quantity analogy is Joule : Energy. For Candela : X, which quantity belongs at X?

    1. Amount of substance
    2. Luminous intensity
    3. Illuminance
    4. Electric charge
    Show answer

    Answer: (B) Luminous intensity

    Explanation: Joule measures energy; candela is the SI unit of luminous intensity. Illuminance uses lux, not candela.

  8. With A=1 to Z=26, a tag changes BG9 to DI23 and FM8 to HO86. Apply the same +2 letter shift and the same number rule to KT5; the number rule uses the original letters’ position product.

    1. MV225
    2. MV110
    3. MV291
    4. MU225
    Show answer

    Answer: (A) MV225

    Explanation: Shift each letter by +2, and add the original position product to the input number: 2×7+9=23 and 6×13+8=86. KT5 gives MV and 11×20+5=225, hence MV225.

  9. Choose the entry that completes both a workplace link and a tool link: Pilot : Cockpit :: Blacksmith : X; Pilot : Control stick :: Blacksmith : Y.

    1. Forge; Hammer
    2. Hammer; Forge
    3. Iron; Anvil
    4. Forge; Horseshoe
    Show answer

    Answer: (A) Forge; Hammer

    Explanation: A blacksmith works at a forge and uses a hammer. The blanks require workplace first and tool second.

  10. Keep the digits together only while reading the input; then add the input to its digit-reversed form. If 37 : 110 and 46 : 110, what is paired with 58?

    1. 85
    2. 13
    3. 143
    4. 27
    Show answer

    Answer: (C) 143

    Explanation: The rule adds the number and its reversal: 37+73=110. Hence 58+85=143.

  11. Compare DGJM → FELK and HKPS → JIRQ. The same alternating shifts are used in both. Transform QTWA, continuing cyclically through the alphabet.

    1. OTUY
    2. SRYC
    3. SVYC
    4. SRYY
    Show answer

    Answer: (D) SRYY

    Explanation: Use +2, −2, +2, −2: Q→S, T→R, W→Y and A→Y. The result is SRYY.

  12. In a passage, “a succinct reply” means “a concise reply”. Which replacement preserves meaning in the same way?

    1. A reluctant witness → An eager witness
    2. A temporary post → A permanent post
    3. A meticulous check → A thorough check
    4. A hostile crowd → A friendly crowd
    Show answer

    Answer: (C) A meticulous check → A thorough check

    Explanation: Succinct and concise both mean brief. Meticulous and thorough both describe a careful, detailed check; the other replacements reverse meaning.

  13. Without splitting digits, reproduce the fixed gap in (48, 59). Which pair should be selected?

    1. (65, 75)
    2. (73, 84)
    3. (39, 49)
    4. (82, 94)
    Show answer

    Answer: (B) (73, 84)

    Explanation: The second number exceeds the first by 11. Only 84−73=11.

  14. A travel-data analogy uses Peru : Lima : Sol. Which row preserves country → capital → currency throughout?

    1. Japan : Tokyo : Won
    2. Turkey : Istanbul : Turkish lira
    3. Egypt : Cairo : Egyptian pound
    4. Brazil : Buenos Aires : Real
    Show answer

    Answer: (C) Egypt : Cairo : Egyptian pound

    Explanation: Egypt’s capital is Cairo and its currency is the Egyptian pound. The other rows contain an incorrect capital or currency.

  15. Aditi uses the template Young one : Adult : Usual human-provided shelter. Which row fits it completely?

    1. Piglet : Pig : Stable
    2. Foal : Horse : Kennel
    3. Puppy : Dog : Burrow
    4. Calf : Cow : Cowshed
    Show answer

    Answer: (D) Calf : Cow : Cowshed

    Explanation: A calf is a young cow, and cows are kept in a cowshed. Each other row gives the wrong shelter for its adult animal.

  16. Under a rule consisting of a cube minus a fixed multiple of the input, 4 maps to 56 and 6 maps to 204. What value corresponds to 9?

    1. 727
    2. 713
    3. 711
    4. 693
    Show answer

    Answer: (C) 711

    Explanation: The deduction is 2n because 4³−56=8 and 6³−204=12. Therefore 9³−2×9=729−18=711.

  17. Faridkot’s science club pairs Seismograph : Ground vibrations. Which second pair keeps the relation recording instrument → phenomenon recorded?

    1. Microscope : Magnification
    2. Periscope : Submarine
    3. Electrocardiograph : Electrical activity of the heart
    4. Telescope : Astronomer
    Show answer

    Answer: (C) Electrocardiograph : Electrical activity of the heart

    Explanation: A seismograph records ground vibrations; an electrocardiograph records the heart’s electrical activity. The other pairs name a function, location or user.

  18. Opposite alphabet letters pair to a position total of 27. Under E : V, which letter is paired with R?

    1. I
    2. H
    3. J
    4. S
    Show answer

    Answer: (A) I

    Explanation: R has position 18, so the opposite position is 27−18=9, which is I.

  19. The chain Cool → Cold → Freezing increases intensity at each step. Which chain has the same increasing structure throughout?

    1. Terrified → Afraid → Uneasy
    2. Warm → Scalding → Hot
    3. Tired → Exhausted → Fresh
    4. Pleased → Delighted → Ecstatic
    Show answer

    Answer: (D) Pleased → Delighted → Ecstatic

    Explanation: Pleased, delighted and ecstatic represent progressively stronger happiness. The other chains decrease intensity or change direction.

  20. A pairing counts the unordered pairs possible among n people: 5 : 10 and 8 : 28. What should stand beside 12?

    1. 78
    2. 132
    3. 144
    4. 66
    Show answer

    Answer: (D) 66

    Explanation: Use n(n−1)/2, since each pair is counted twice in n(n−1). For 12 people, 12×11/2=66.

  21. The order in Spoke : Wheel : Bicycle is part → larger part → complete vehicle. Which sequence matches that nesting?

    1. Tyre : Road : Car
    2. Piston : Engine : Car
    3. Car : Engine : Piston
    4. Driver : Engine : Car
    Show answer

    Answer: (B) Piston : Engine : Car

    Explanation: A piston is part of an engine, and the engine is part of a car. This preserves the two successive part-to-whole links.

  22. Two references are (125, 25) and (343, 49). Which new pair is formed from the cube and square of the same positive integer?

    1. (1728, 144)
    2. (512, 128)
    3. (729, 27)
    4. (1000, 10)
    Show answer

    Answer: (A) (1728, 144)

    Explanation: The entries are (n³, n²): (5³, 5²) and (7³, 7²). Thus (12³, 12²)=(1728, 144) fits.

  23. One coding rule yields ACE : 22 and BDF : 28. Using A=1 to Z=26, choose the value of GIK when each position is weighted by its place in the three-letter group.

    1. 54
    2. 27
    3. 189
    4. 58
    Show answer

    Answer: (D) 58

    Explanation: Use 1×first position + 2×second + 3×third: ACE gives 1+6+15=22 and BDF gives 2+8+18=28. Thus GIK gives 7+18+33=58.

  24. Take A=1 to Z=26 and add the positions. GH is related to 15; which number is related to NP?

    1. 30
    2. 224
    3. 2
    4. 31
    Show answer

    Answer: (A) 30

    Explanation: G+H=7+8=15. Likewise N+P=14+16=30.

  25. A ration-conversion analogy is 18 : 45 :: 26 : 65 :: 34 : X. Preserve the same ratio and find X.

    1. 75
    2. 85
    3. 68
    4. 102
    Show answer

    Answer: (B) 85

    Explanation: Multiply by 5/2: 18×5/2=45 and 26×5/2=65. Hence 34×5/2=85.
