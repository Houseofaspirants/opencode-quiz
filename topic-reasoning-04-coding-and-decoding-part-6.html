Question bank

Coding and Decoding MCQ – Part 6: all 25 questions

Read the question, pick an option, then open the answer.

  1. A code is fixed, one-to-one and unordered: “bright stars guide sailors” = “ab ef cd gh”; “stars guide travellers safely” = “cd gh ij kl”; “bright lamps shine safely” = “ab mn op kl”; “lamps guide ships” = “mn gh qr”. Which token represents “stars”?

    1. ij
    2. cd
    3. ef
    4. gh
    Show answer

    Answer: (B) cd

    Explanation: The first two lines leave stars and guide as cd,gh. The fourth line shares only guide with the first, identifying guide=gh and therefore stars=cd.

  2. Sort the list MEENA, MEHAR, MEET, MEGHA alphabetically. Each code is the first letter, its 1-based position in the sorted list, then the last letter shifted -1. What is MEENA’s code?

    1. M1Z
    2. M2Z
    3. M3Z
    4. M1B
    Show answer

    Answer: (A) M1Z

    Explanation: The order is MEENA,MEET,MEGHA,MEHAR. MEENA is first, and its last A moves back to Z, giving M1Z.

  3. A word uses +2,-3 alternately from the left. The code is then read from right to left and its final two letters are exchanged. What final string is produced from DEVINDER?

    1. FBXFPAGO
    2. OGAPFXBF
    3. TBFKKSGA
    4. OGAPFXFB
    Show answer

    Answer: (D) OGAPFXFB

    Explanation: The shifted word is FBXFPAGO. Reverse it and exchange only its final pair to obtain OGAPFXFB.

  4. Encoding has two stages: reverse the whole word; then move each vowel in the reversed word +2 and each consonant -1. Using A,E,I,O,U as vowels, find the code of EDUCATE.

    1. GCWBCSG
    2. GVCEWFG
    3. GSCBWCG
    4. DVZETFD
    Show answer

    Answer: (C) GSCBWCG

    Explanation: Reverse to ETACUDE, then classify those original reversed letters. Applying +2 to E,A,U,E and -1 to T,C,D gives GSCBWCG.

  5. At each position, move the original letter forward by the number of vowels seen so far, including the current letter. A,E,I,O,U are vowels. What is the code for BIKRAM?

    1. BJLSBN
    2. CJLSCO
    3. BJMSCO
    4. BJLSCO
    Show answer

    Answer: (D) BJLSCO

    Explanation: Cumulative vowel counts are 0,1,1,1,2,2. Apply those shifts to BIKRAM to obtain BJLSCO.

  6. A word’s code is the sum of (letter rank × frequency of that letter), counting each distinct letter ONCE, plus the square of the number of distinct letters. Find the code for MALERKOTLA.

    1. 172
    2. 116
    3. 208
    4. 159
    Show answer

    Answer: (A) 172

    Explanation: Rank × frequency summed over distinct letters equals the ordinary occurrence sum, 108. There are 8 distinct letters, so add 8² to get 172.

  7. Split a nine-letter input into three blocks of three, and write the blocks in order 2,3,1 without reversing them. If the output is JALANDHAR, which input produced it?

    1. JALHARAND
    2. HARANDJAL
    3. ANDHARJAL
    4. HARJALAND
    Show answer

    Answer: (D) HARJALAND

    Explanation: The output blocks are JAL|AND|HAR, corresponding to original blocks 2,3,1. Restore them as HAR|JAL|AND.

  8. At a sports camp, real CAP is named SHOE, SHOE is named BELT, and BELT is named CAP. Which real item does the code word BELT identify?

    1. BELT
    2. CAP
    3. SOCK
    4. SHOE
    Show answer

    Answer: (D) SHOE

    Explanation: Find the arrow ending at code BELT: real SHOE→BELT. Thus the real item is SHOE.

  9. A device reverses its input exactly once each time it is pressed. After three presses on NURPUR, which string is displayed?

    1. RUPRUN
    2. RUPNUR
    3. RURPUN
    4. NURPUR
    Show answer

    Answer: (A) RUPRUN

    Explanation: Two reversals cancel; the third leaves one reversal. NURPUR therefore displays as RUPRUN.

  10. A three-letter word is coded as the product of its ranks divided by their greatest common divisor. What number represents FLR?

    1. 1296
    2. 216
    3. 36
    4. 6
    Show answer

    Answer: (B) 216

    Explanation: Ranks are 6,12,18 with greatest common divisor 6. The code is (6×12×18)÷6=216.

  11. Codes are fixed and unordered: “Aman likes chess” = “lo pa si”; “Rita likes hockey” = “tu pa ve”; “Aman plays hockey” = “lo ne ve”. Which token belongs to a SPORT mentioned in the first sentence?

    1. si
    2. lo
    3. ve
    4. pa
    Show answer

    Answer: (A) si

    Explanation: The common pairs give Aman=lo and likes=pa. The first sentence’s remaining word chess has code si.

  12. A nonzero fixed forward shift between 1 and 25 is applied twice. Every letter returns to its original value. How many places does each application move?

    1. 25
    2. 14
    3. 13
    4. 12
    Show answer

    Answer: (C) 13

    Explanation: Twice the shift must complete one 26-letter cycle. Hence the shift is 26÷2=13.

  13. A four-digit label swaps only its first and last digits. Internal digits stay fixed. Which label is produced from 4069?

    1. 9604
    2. 9064
    3. 9046
    4. 4960
    Show answer

    Answer: (B) 9064

    Explanation: Exchange endpoint digits 4 and 9, retaining 0 and 6 in the middle. The result is 9064.

  14. A word is encoded by a single fixed shift. The original begins and ends with J and R, while the code begins with Q. Which letter must end the code?

    1. Y
    2. Z
    3. X
    4. K
    Show answer

    Answer: (A) Y

    Explanation: J→Q is +7. Apply the same shift to the original final R: 18+7=25=Y.

  15. Under alphabet-opposite coding, what is the ordinary rank of the coded letter that replaces P?

    1. 16
    2. 11
    3. 10
    4. 12
    Show answer

    Answer: (B) 11

    Explanation: P has rank 16. Its opposite has rank 27-16=11, which is K.

  16. For a seven-letter word, shift a letter forward by its distance from the nearer END, counting an endpoint as distance 1. After encoding, reverse the entire result. Find the final code for RAJPURA.

    1. HXZTMCS
    2. SCMTXTB
    3. BTXTMCS
    4. ASWSLBR
    Show answer

    Answer: (C) BTXTMCS

    Explanation: Distances from the nearer end are 1,2,3,4,3,2,1. The intermediate code is SCMTXTB; reversing gives BTXTMCS.

  17. Fixed mappings: A→2,B→%,C→2,D→#. For the pattern AB?D, the code is 2%2#. How many letters in the given mapping can fill the missing place?

    1. 4
    2. 2
    3. 3
    4. 1
    Show answer

    Answer: (B) 2

    Explanation: The missing letter must have code 2. Both A and C qualify, giving two possible letters.

  18. Opposite coding is followed by sorting the resulting letters alphabetically. Which sorted code belongs to NIMRAT?

    1. MRNIZG
    2. AIMNRT
    3. GIMNRZ
    4. ZRNMIG
    Show answer

    Answer: (C) GIMNRZ

    Explanation: The opposites form MRNIZG. Sorting those letters gives GIMNRZ.

  19. Base: U→5,A→1,S→8,H→%. Examine original USHA and apply all actions in order: (1) if endpoints are vowels, exchange their current codes; (2) if any original interior consonant is present, replace the LAST code by #; (3) if the original first letter is U, replace the FIRST code by @. Find the final code.

    1. @8%#
    2. #8%@
    3. 18%#
    4. @8%5
    Show answer

    Answer: (A) @8%#

    Explanation: Base 58%1 becomes 18%5 after the swap, then 18%#, then @8%#. All conditions are checked on the original USHA.

  20. A numeric code stores, for each letter, 27 plus its ordinary rank, except that every repeated occurrence after the first stores 0. What is the code for MANSA?

    1. 40-28-41-46-28
    2. 40-28-41-46-0
    3. 13-1-14-19-0
    4. 40-0-41-46-0
    Show answer

    Answer: (B) 40-28-41-46-0

    Explanation: First occurrences M,A,N,S give 40,28,41,46. The final A repeats, so its stored value is 0.

  21. A six-letter name is coded using the repeating shifts 0,+2,-2. Which original positions of RAVINA remain unchanged in its code?

    1. 2,5
    2. 1,3
    3. 3,6
    4. 1,4
    Show answer

    Answer: (D) 1,4

    Explanation: Only a zero shift leaves a letter unchanged. In this block, zero occurs at places 1 and 4.

  22. Coordinates use row then column. Matrix I: columns 0,1,2; row 0=T,A,R; row 1=N,U,P. Matrix II: columns 5,6,7; row 5=A,R,T; row 6=U,N,A. Which code for TARAN uses the SMALLEST available coordinate for each letter, treating each pair as a two-digit number?

    1. 00-01-02-01-66
    2. 00-01-02-55-10
    3. 00-01-02-01-10
    4. 57-55-56-67-66
    Show answer

    Answer: (C) 00-01-02-01-10

    Explanation: Minimum cells are T=00,A=01,R=02,N=10. Reuse A=01 to obtain 00-01-02-01-10.

  23. A code moves the first letter of a word to the last place without disturbing the remaining order. Which code belongs to DHURI?

    1. HUIDR
    2. IRUHD
    3. HURID
    4. IDHUR
    Show answer

    Answer: (C) HURID

    Explanation: Keep HURI in order and append the first letter D. The result is HURID.

  24. Each letter’s ordinary rank is squared and written as a separate number. A four-letter message is 256-1-324-121. Which message does it encode?

    1. PARKS
    2. PARK
    3. QARK
    4. PBRK
    Show answer

    Answer: (B) PARK

    Explanation: Positive square roots are 16,1,18,11. These ranks give P,A,R,K.

  25. A fixed mapping gives DERA→6#@8 and READ→@#86. After coding AADAR, how many @ symbols appear?

    1. 0
    2. 3
    3. 2
    4. 1
    Show answer

    Answer: (D) 1

    Explanation: The symbol @ represents R. AADAR has exactly one R, so @ appears once.
