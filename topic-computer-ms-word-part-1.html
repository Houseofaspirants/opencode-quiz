Question bank

MS Word (Microsoft Word) - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. MS Word is primarily which type of software?

    1. Spreadsheet software
    2. Word processing software
    3. Presentation software
    4. Database management software
    Show answer

    Answer: (B) Word processing software

    Explanation: MS Word is a word processor used to create, edit, format, save and print text documents. Excel is a spreadsheet, PowerPoint is presentation software and Access is a database program.

  2. When a new blank document is opened in MS Word, what is its default file name?

    1. Book1
    2. Presentation1
    3. Document1
    4. Untitled1
    Show answer

    Answer: (C) Document1

    Explanation: A new Word document opens as Document1. Excel uses Book1 and PowerPoint uses Presentation1.

  3. Which is the default file extension of a document saved in MS Word 2007 and later versions?

    1. .doc
    2. .txt
    3. .dotx
    4. .docx
    Show answer

    Answer: (D) .docx

    Explanation: .docx is the default format from Word 2007 onwards. .doc was the format of Word 97-2003, and .dotx is a template.

  4. A Word file that contains macros must be saved with which extension?

    1. .docm
    2. .dotx
    3. .xps
    4. .docx
    Show answer

    Answer: (A) .docm

    Explanation: .docm is a macro-enabled document. A normal .docx file cannot store macros; .dotm is the macro-enabled template.

  5. Consider the following pairs of file extensions and their meaning: 1. .dotx – Word template 2. .xps – XML Paper Specification 3. .odt – Office Document Text Which of the pairs given above is/are correctly matched?

    1. 1 and 2 only
    2. 2 and 3 only
    3. 1 and 3 only
    4. 1, 2 and 3
    Show answer

    Answer: (A) 1 and 2 only

    Explanation: .dotx is a Word template and .xps stands for XML Paper Specification. .odt stands for OpenDocument Text, not 'Office Document Text', so pair 3 is wrong.

  6. Which tab is selected by default when MS Word is opened?

    1. Insert
    2. Home
    3. File
    4. View
    Show answer

    Answer: (B) Home

    Explanation: The Home tab is the default tab. It holds the most-used commands in five groups: Clipboard, Font, Paragraph, Styles and Editing.

  7. Which of the following groups is NOT a part of the Home tab in MS Word?

    1. Clipboard
    2. Styles
    3. Illustrations
    4. Editing
    Show answer

    Answer: (C) Illustrations

    Explanation: Home tab has Clipboard, Font, Paragraph, Styles and Editing. Illustrations (Pictures, Shapes, SmartArt, Chart) is a group of the Insert tab.

  8. In MS Word, the Ribbon is best described as a collection of:

    1. Documents and templates
    2. Only toolbars and menus
    3. Rulers and scroll bars
    4. Tabs, groups and commands
    Show answer

    Answer: (D) Tabs, groups and commands

    Explanation: The Ribbon is organised into tabs; each tab has groups, and each group contains related commands.

  9. Which of the following commands is available on the Quick Access Toolbar by default?

    1. Undo
    2. Print Preview
    3. Format Painter
    4. Spelling & Grammar
    Show answer

    Answer: (A) Undo

    Explanation: By default the Quick Access Toolbar shows Save, Undo and Redo/Repeat. Other commands can be added by the user.

  10. The zoom range available in MS Word is:

    1. 25% to 200%
    2. 10% to 500%
    3. 1% to 1000%
    4. 10% to 400%
    Show answer

    Answer: (B) 10% to 500%

    Explanation: Word allows zooming from 10% to 500% using the zoom slider on the status bar or the View tab.

  11. What is the maximum font size that can be typed into the Font Size box of MS Word?

    1. 72
    2. 409
    3. 1638
    4. 999
    Show answer

    Answer: (C) 1638

    Explanation: Word accepts font sizes from 1 to 1638 points (in half-point steps). The drop-down list only goes to 72, but larger values can be typed.

  12. Which of the following is NOT displayed on the Status Bar of MS Word by default?

    1. Page number
    2. Word count
    3. Language
    4. Font name
    Show answer

    Answer: (D) Font name

    Explanation: The status bar shows the page number, word count, proofing language, view buttons and zoom. The font name is shown in the Font group of the Home tab.

  13. The Format Painter tool is found in which group of the Home tab?

    1. Clipboard
    2. Font
    3. Paragraph
    4. Styles
    Show answer

    Answer: (A) Clipboard

    Explanation: Format Painter is in the Clipboard group along with Cut, Copy and Paste. It copies formatting from one piece of text and applies it to another.

  14. Which keyboard shortcuts are used to copy and paste only the formatting (not the text) in MS Word?

    1. Ctrl + C and Ctrl + V
    2. Ctrl + Shift + C and Ctrl + Shift + V
    3. Alt + C and Alt + V
    4. Ctrl + Alt + C and Ctrl + Alt + V
    Show answer

    Answer: (B) Ctrl + Shift + C and Ctrl + Shift + V

    Explanation: Ctrl + Shift + C copies the formatting of the selected text and Ctrl + Shift + V pastes that formatting - the keyboard version of Format Painter.

  15. To write H₂O correctly in MS Word, the '2' must be formatted as subscript. Which shortcut applies subscript?

    1. Ctrl + Shift + =
    2. Ctrl + Shift + S
    3. Ctrl + =
    4. Alt + =
    Show answer

    Answer: (C) Ctrl + =

    Explanation: Ctrl + = applies subscript (as in H₂O). Ctrl + Shift + = (Ctrl + Shift + +) applies superscript (as in X²).

  16. In MS Word, which key combination cycles the selected text through UPPERCASE, lowercase and Capitalize Each Word?

    1. Ctrl + F3
    2. Alt + F3
    3. Ctrl + Shift + A
    4. Shift + F3
    Show answer

    Answer: (D) Shift + F3

    Explanation: Shift + F3 toggles the case of the selected text between lowercase, UPPERCASE and Capitalize Each Word. The full Change Case menu is in the Font group.

  17. If the text 'Computer' is changed to 'cOMPUTER', which Change Case option has been applied?

    1. tOGGLE cASE
    2. Sentence case
    3. lowercase
    4. Capitalize Each Word
    Show answer

    Answer: (A) tOGGLE cASE

    Explanation: tOGGLE cASE reverses the case of every letter: capitals become small letters and small letters become capitals.

  18. Which alignment spreads the text evenly so that it lines up with both the left and the right margins?

    1. Center
    2. Justify
    3. Right
    4. Left
    Show answer

    Answer: (B) Justify

    Explanation: Justify (Ctrl + J) adjusts the spacing between words so that every full line touches both the left and the right margin.

  19. Match the shortcut with its alignment: (a) Ctrl + E (b) Ctrl + R (c) Ctrl + L (d) Ctrl + J (i) Left (ii) Justify (iii) Center (iv) Right

    1. a-iii, b-iv, c-i, d-ii
    2. a-iv, b-iii, c-i, d-ii
    3. a-iii, b-iv, c-ii, d-i
    4. a-i, b-iv, c-iii, d-ii
    Show answer

    Answer: (A) a-iii, b-iv, c-i, d-ii

    Explanation: Ctrl + E = Center, Ctrl + R = Right, Ctrl + L = Left and Ctrl + J = Justify.

  20. Which shortcut opens the Replace option to replace one word with another throughout a document?

    1. Ctrl + R
    2. Ctrl + F
    3. Ctrl + H
    4. Ctrl + G
    Show answer

    Answer: (C) Ctrl + H

    Explanation: Ctrl + H opens the Find and Replace dialog on the Replace tab. Ctrl + F is Find, Ctrl + G is Go To and Ctrl + R is right align.

  21. Header, Footer and Page Number options are available in which tab of MS Word?

    1. Design
    2. References
    3. Layout
    4. Insert
    Show answer

    Answer: (D) Insert

    Explanation: Header, Footer and Page Number are in the Header & Footer group of the Insert tab.

  22. Drop Cap, which makes the first letter of a paragraph large, is found in which group of the Insert tab?

    1. Text
    2. Symbols
    3. Illustrations
    4. Pages
    Show answer

    Answer: (A) Text

    Explanation: The Text group of the Insert tab contains Text Box, WordArt, Drop Cap, Signature Line and Date & Time.

  23. SmartArt and Charts are inserted from which group of the Insert tab?

    1. Tables
    2. Illustrations
    3. Links
    4. Media
    Show answer

    Answer: (B) Illustrations

    Explanation: The Illustrations group contains Pictures, Shapes, Icons, SmartArt, Chart and Screenshot.

  24. In MS Word 2016, faded text such as 'CONFIDENTIAL' placed behind the content of every page is called a Watermark. It is found in which tab?

    1. Insert
    2. Review
    3. Design
    4. View
    Show answer

    Answer: (C) Design

    Explanation: From Word 2013 onwards, Watermark, Page Color and Page Borders are in the Page Background group of the Design tab (in Word 2007/2010 they were in Page Layout).

  25. Which shortcut inserts a page break so that the text after the cursor starts on a new page?

    1. Shift + Enter
    2. Alt + Enter
    3. Ctrl + Shift + P
    4. Ctrl + Enter
    Show answer

    Answer: (D) Ctrl + Enter

    Explanation: Ctrl + Enter inserts a page break. Shift + Enter only inserts a line break within the same paragraph.
