Question bank

Coding and Decoding MCQ – Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. A clerk adds the alphabet ranks of distinct letters only; repeated occurrences are ignored. What number is assigned to BATHINDA?

    1. 57
    2. 58
    3. 7
    4. 59
    Show answer

    Answer: (B) 58

    Explanation: Count A once. B+A+T+H+I+N+D = 2+1+20+8+9+14+4 = 58.

  2. A six-letter code reads original places 4,1,6,2,5,3. The code is NKLAAR. Which word was rearranged?

    1. KANRAL
    2. AKLRAN
    3. KARLAN
    4. KARNAL
    Show answer

    Answer: (D) KARNAL

    Explanation: Put N,K,L,A,A,R back at places 4,1,6,2,5,3 respectively. Reading original positions 1–6 gives KARNAL.

  3. Coordinates are row first, column second. Columns: 0 1 2; row 0: J A L; row 1: A M R; row 2: R L A. Which sequence correctly codes JAL?

    1. 00-22-12
    2. 00-10-21
    3. 00-11-21
    4. 00-01-20
    Show answer

    Answer: (B) 00-10-21

    Explanation: Read each pair separately: 00=J, 10=A and 21=L. Alternative A or L cells are allowed, but every pair must match.

  4. Base: A→2,E→5,I→8,N→%,R→7. Count vowels in the original input and apply ONLY the first matching rule: (1) exactly two vowels: replace both endpoint codes by #; (2) both endpoints vowels: reverse the full base code, then replace its middle code by @; (3) otherwise retain the base. Encode ANIRE.

    1. #%87#
    2. 2%@75
    3. 57@%2
    4. 578%2
    Show answer

    Answer: (C) 57@%2

    Explanation: ANIRE has three vowels, so rule 1 fails and rule 2 applies. Reverse 2%875 to 578%2, then replace its middle code: 57@%2.

  5. Each word has one fixed code and token order is arbitrary: “farmers sell wheat” = “zu pa ni”; “traders buy wheat” = “ko ni re”; “farmers buy seeds” = “pa re lo”. Find the code for “sell seeds”.

    1. zu lo
    2. zu re
    3. ko lo
    4. pa lo
    Show answer

    Answer: (A) zu lo

    Explanation: Common words identify wheat=ni, farmers=pa and buy=re. The remaining codes are sell=zu and seeds=lo.

  6. A ticket machine uses L→7, O→@, H→4, R→%, I→2. Which ticket prints for LOHRI?

    1. 7@4%2
    2. 2%4@7
    3. 7@%42
    4. 7@4%7
    Show answer

    Answer: (A) 7@4%2

    Explanation: Replace letters in their original order: L O H R I → 7 @ 4 % 2.

  7. At a fair, real objects are renamed once: DRUM→FLUTE, FLUTE→FLAG, FLAG→LAMP. Simran actually picks up a FLUTE. Which code name must the announcer use?

    1. FLUTE
    2. DRUM
    3. LAMP
    4. FLAG
    Show answer

    Answer: (D) FLAG

    Explanation: Follow the arrow from the real object FLUTE once. Its assigned name is FLAG.

  8. An encoder reverses a six-letter word, then applies +1,-2,+3,-4,+5,-6. Its output is FJSIJN. What was the input?

    1. TEMQLE
    2. TEMPLEE
    3. TEMPLE
    4. ELPMET
    Show answer

    Answer: (C) TEMPLE

    Explanation: Undo the shifts to recover E L P M E T in reverse order, then reverse to obtain TEMPLE.

  9. A label contains, in order, the middle letter of an odd-length word, its number of distinct letters, and its last letter moved +2. What is the label for PATIALA?

    1. T5C
    2. I5C
    3. I7C
    4. I5B
    Show answer

    Answer: (B) I5C

    Explanation: PATIALA has middle letter I and five distinct letters P,A,T,I,L. The last A moves to C, giving I5C.

  10. In a fixed digit substitution, 248 is written as 591 and 826 as 157. What is the code for 6824?

    1. 7195
    2. 7159
    3. 7519
    4. 1759
    Show answer

    Answer: (B) 7159

    Explanation: The pairs are 6→7, 8→1, 2→5 and 4→9. Hence 6824 becomes 7159.

  11. A name is encoded as two-digit alphabet ranks after every original letter moves +3 cyclically. Decode 17080816.

    1. NEEM
    2. NEEN
    3. NEEL
    4. QHHP
    Show answer

    Answer: (A) NEEM

    Explanation: Split into 17,08,08,16 to obtain QHHP. Move each letter back 3 places to get NEEM.

  12. A fixed one-to-one word code ignores order. “clean village roads” = “ti mu ka”; “village schools open” = “mu zo pe”; “clean schools shine” = “ti zo ra”; “roads shine daily” = “ka ra fu”. Which code set means “open clean daily”?

    1. pe mu fu
    2. pe ti fu
    3. pe ti ra
    4. zo ti fu
    Show answer

    Answer: (B) pe ti fu

    Explanation: The overlaps give clean=ti, village=mu, schools=zo and shine=ra. The unmatched words give open=pe and daily=fu, so use pe ti fu.

  13. A student’s name was encoded by moving every letter 5 places backward. The code is HPNFVI. Which original name was entered?

    1. MUSLAN
    2. MUSKAM
    3. MUTKAN
    4. MUSKAN
    Show answer

    Answer: (D) MUSKAN

    Explanation: Undo -5 with +5: H→M, P→U, N→S, F→K, V→A and I→N. The name is MUSKAN.

  14. Odd places move +3 and even places move -2, counting from the left. A coded surname is VGQEK. Recover the surname.

    1. SILGH
    2. YETCN
    3. UINGH
    4. SINGH
    Show answer

    Answer: (D) SINGH

    Explanation: Undo the alternating shifts with -3,+2,-3,+2,-3. VGQEK becomes SINGH.

  15. Use opposite alphabet pairs A↔Z, B↔Y, and so on. Which code represents JASS?

    1. QZHH
    2. QZII
    3. QAHH
    4. RZHH
    Show answer

    Answer: (A) QZHH

    Explanation: Opposite ranks add to 27: J→Q, A→Z and S→H. Thus JASS becomes QZHH.

  16. In a seven-letter word, keep the middle letter fixed, move the final three letters to the front, and move the first three to the end without reversing either group. Code PUNJABI.

    1. ABIPUNJ
    2. PUNJIBA
    3. ABIJPUN
    4. IBAJNUP
    Show answer

    Answer: (C) ABIJPUN

    Explanation: Split PUNJABI as PUN | J | ABI. Exchanging the outer groups gives ABIJPUN.

  17. A single fixed shift changes JHELUM to MKHOXP. Which additional entry breaks this rule?

    1. CHENAB → FKHQDE
    2. RAVI → UDYK
    3. BEAS → EHDV
    4. SUTLEJ → VXWOHM
    Show answer

    Answer: (B) RAVI → UDYK

    Explanation: Every letter moves +3. RAVI must become UDYL, so RAVI → UDYK is the incorrect entry.

  18. At place i, encoding adds i² to the alphabet rank and wraps within A–Z. Which original produces the code SMEUQ?

    1. RKCJL
    2. TQNEP
    3. RIVER
    4. RIVFR
    Show answer

    Answer: (C) RIVER

    Explanation: Subtract 1,4,9,16,25 from successive letters. S→R, M→I, E→V, U→E and Q→R, giving RIVER.

  19. A number label lists each letter’s reverse alphabet value plus its place counted from the right, starting at 1. There is no numeric wraparound. Find the label for REWA.

    1. 13-24-6-27
    2. 10-24-7-30
    3. 13-25-6-27
    4. 9-22-4-26
    Show answer

    Answer: (C) 13-25-6-27

    Explanation: Reverse values are 9,22,4,26; add right-hand places 4,3,2,1. The label is 13-25-6-27.

  20. A one-to-one character mapping gives SEAT→$7@4 and EAST→7@$4. What does 4@$7 represent?

    1. TASE
    2. TSEA
    3. EAST
    4. TSAE
    Show answer

    Answer: (A) TASE

    Explanation: From SEAT, 4=T, @=A, $=S and 7=E. Therefore 4@$7 decodes to TASE.

  21. A scanner repeats +2,-1,-1 across a whole string without restarting at spaces. It reads MOGA ROPAR. After spaces are removed, what are the last five coded letters?

    1. QNRCT
    2. TNOCQ
    3. QNRZQ
    4. QOQZQ
    Show answer

    Answer: (C) QNRZQ

    Explanation: MOGA occupies places 1–4. Places 5–9 use -1,-1,+2,-1,-1, so ROPAR becomes QNRZQ.

  22. At a Patiala desk, every letter is moved 4 places forward in the alphabet, with Z followed by A. Which label replaces KIRAN?

    1. OMVER
    2. OMVEQ
    3. GENWJ
    4. NLUDQ
    Show answer

    Answer: (A) OMVER

    Explanation: Add 4 to each letter: K→O, I→M, R→V, A→E, N→R. The code is OMVER.

  23. For a five-letter badge, the shift at place i is 2i, counting i=1 from the left. Select the badge code for NEPAL.

    1. PIVIV
    2. OGSEQ
    3. PGRCN
    4. XMVEN
    Show answer

    Answer: (A) PIVIV

    Explanation: Use shifts +2,+4,+6,+8,+10. NEPAL becomes PIVIV.

  24. Harpreet stores the complete name NABHA from right to left, keeping every letter. What is stored?

    1. ABHAN
    2. ANBHA
    3. AHBNA
    4. AHBAN
    Show answer

    Answer: (D) AHBAN

    Explanation: Read NABHA from the final letter to the first: A-H-B-A-N.

  25. For a five-letter word, multiply the endpoint ranks, add the three inner ranks, then subtract the word length. What is the code of FORTS?

    1. 167
    2. 73
    3. 56
    4. 162
    Show answer

    Answer: (D) 162

    Explanation: Calculate 6×19 + (15+18+20) - 5 = 162. Multiply only the endpoint ranks.
