Question bank

MS Word (Microsoft Word) - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. In page setup, the extra margin space added to the inside edge of pages for binding is called:

    1. Header margin
    2. Indent
    3. Gutter margin
    4. Mirror margin
    Show answer

    Answer: (C) Gutter margin

    Explanation: The gutter margin adds extra space to the side or top margin so that text is not hidden after the document is bound.

  2. Margins, Orientation, Size and Columns are part of which group in the Layout (Page Layout) tab?

    1. Paragraph
    2. Arrange
    3. Page Background
    4. Page Setup
    Show answer

    Answer: (D) Page Setup

    Explanation: The Page Setup group of the Layout tab contains Margins, Orientation, Size, Columns, Breaks, Line Numbers and Hyphenation.

  3. What is the default page orientation of a new document in MS Word?

    1. Portrait
    2. Landscape
    3. Vertical-Landscape
    4. Horizontal
    Show answer

    Answer: (A) Portrait

    Explanation: A new document opens in Portrait orientation (taller than wide). Landscape (wider than tall) can be chosen from Layout > Orientation.

  4. Which tab of MS Word is used to insert a Table of Contents?

    1. Insert
    2. References
    3. Home
    4. Review
    Show answer

    Answer: (B) References

    Explanation: Table of Contents, Footnotes, Citations & Bibliography, Captions, Index and Table of Authorities are all on the References tab.

  5. A note that appears at the end of the whole document (rather than at the bottom of the page) is called:

    1. Footnote
    2. Footer
    3. Endnote
    4. Caption
    Show answer

    Answer: (C) Endnote

    Explanation: A footnote appears at the bottom of the same page; an endnote is collected at the end of the document or section. Both are inserted from the References tab.

  6. In the References tab of MS Word, 'Table of Authorities' is mainly used to list:

    1. Figures and tables
    2. Chapter headings with page numbers
    3. Authors of the document
    4. Legal references such as cases and statutes
    Show answer

    Answer: (D) Legal references such as cases and statutes

    Explanation: A Table of Authorities lists legal citations (cases, statutes, rules) in a legal document. Chapter headings with page numbers form a Table of Contents.

  7. A school wants to send the same invitation letter to 500 parents, each with a different name and address. Which feature of MS Word is most suitable?

    1. Mail Merge
    2. Macro
    3. Track Changes
    4. Compare
    Show answer

    Answer: (A) Mail Merge

    Explanation: Mail Merge (Mailings tab) combines one main document with a data source of names and addresses to create personalised copies.

  8. Mail Merge combines a main document with a:

    1. Template
    2. Data source
    3. Macro
    4. Style sheet
    Show answer

    Answer: (B) Data source

    Explanation: Mail Merge = main document + data source (a list such as an Excel sheet, Outlook contacts or a Word table).

  9. Which function key opens the Spelling & Grammar check in MS Word?

    1. F5
    2. F12
    3. F7
    4. F1
    Show answer

    Answer: (C) F7

    Explanation: F7 starts the Spelling & Grammar check. F1 opens Help, F5 opens Go To and F12 opens Save As.

  10. The Thesaurus, which suggests synonyms such as 'Joyful' for 'Happy', is opened with:

    1. Ctrl + F7
    2. Alt + F7
    3. F7
    4. Shift + F7
    Show answer

    Answer: (D) Shift + F7

    Explanation: Shift + F7 opens the Thesaurus. It is in the Proofing group of the Review tab.

  11. Which is the correct keyboard shortcut to open the Word Count dialog box in MS Word?

    1. Ctrl + Shift + G
    2. Ctrl + Shift + W
    3. Ctrl + Shift + 9
    4. Alt + Shift + W
    Show answer

    Answer: (A) Ctrl + Shift + G

    Explanation: Ctrl + Shift + G opens the Word Count dialog, which shows pages, words, characters, paragraphs and lines. Word Count is also in the Proofing group of the Review tab.

  12. Which feature of MS Word records every insertion, deletion and formatting change so that a reviewer can later accept or reject them?

    1. Compare
    2. Track Changes
    3. Restrict Editing
    4. Comments
    Show answer

    Answer: (B) Track Changes

    Explanation: Track Changes (Review tab) marks each edit so it can be accepted or rejected. Compare shows differences between two separate documents.

  13. To stop others from editing a document, with an optional password, which option of the Review tab is used?

    1. Compare
    2. Track Changes
    3. Restrict Editing
    4. Accept
    Show answer

    Answer: (C) Restrict Editing

    Explanation: Restrict Editing (Protect group of the Review tab) limits what others can change in a document and can be secured with a password.

  14. Which of the following is NOT a document view in MS Word?

    1. Read Mode
    2. Web Layout
    3. Draft
    4. Slide Sorter
    Show answer

    Answer: (D) Slide Sorter

    Explanation: Word's views are Read Mode, Print Layout, Web Layout, Outline and Draft. Slide Sorter is a view of MS PowerPoint.

  15. In which view does a new MS Word document open by default, showing the page exactly as it will be printed?

    1. Print Layout
    2. Draft
    3. Outline
    4. Web Layout
    Show answer

    Answer: (A) Print Layout

    Explanation: Print Layout is the default view; it shows margins, headers, footers and page boundaries as they will appear on paper.

  16. A Macro in MS Word is:

    1. A large first letter of a paragraph
    2. A recorded sequence of commands used to automate repetitive tasks
    3. A type of template for letters
    4. A tool to compare two documents
    Show answer

    Answer: (B) A recorded sequence of commands used to automate repetitive tasks

    Explanation: A macro records a series of commands and keystrokes so a repetitive task can be run with one click. Macros are in the View tab and need .docm/.dotm files to be saved.

  17. Ruler, Gridlines and Navigation Pane can be shown or hidden from which group of the View tab?

    1. Zoom
    2. Window
    3. Show
    4. Views
    Show answer

    Answer: (C) Show

    Explanation: The Show group of the View tab has check boxes for Ruler, Gridlines and Navigation Pane.

  18. Which shortcut moves the cursor directly to the beginning of the document?

    1. Home
    2. Page Up
    3. Ctrl + Up Arrow
    4. Ctrl + Home
    Show answer

    Answer: (D) Ctrl + Home

    Explanation: Ctrl + Home goes to the start of the document and Ctrl + End to its end. Home alone moves only to the start of the current line.

  19. What does Ctrl + Backspace do in MS Word?

    1. Deletes the whole word to the left of the cursor
    2. Deletes one character to the right of the cursor
    3. Deletes the whole line
    4. Undoes the last action
    Show answer

    Answer: (A) Deletes the whole word to the left of the cursor

    Explanation: Ctrl + Backspace deletes the word to the left of the cursor; Ctrl + Delete deletes the word to the right. Backspace alone deletes one character to the left.

  20. Which of the following function keys opens the 'Save As' dialog box in MS Word?

    1. Shift + F12
    2. F12
    3. Ctrl + F12
    4. F10
    Show answer

    Answer: (B) F12

    Explanation: F12 opens Save As. Shift + F12 saves the document and Ctrl + F12 opens a document.

  21. Which shortcut is used to insert a hyperlink in MS Word?

    1. Ctrl + H
    2. Ctrl + L
    3. Ctrl + K
    4. Ctrl + Shift + H
    Show answer

    Answer: (C) Ctrl + K

    Explanation: Ctrl + K opens the Insert Hyperlink dialog. Hyperlinks can point to a website, an email address or another document.

  22. Which pair of shortcuts inserts the current date and the current time respectively in MS Word?

    1. Ctrl + D and Ctrl + T
    2. Alt + D and Alt + T
    3. Ctrl + Shift + D and Ctrl + Shift + T
    4. Alt + Shift + D and Alt + Shift + T
    Show answer

    Answer: (D) Alt + Shift + D and Alt + Shift + T

    Explanation: Alt + Shift + D inserts the current date and Alt + Shift + T the current time as fields. Ctrl + D opens the Font dialog and Ctrl + T makes a hanging indent.

  23. Consider the following statements about shortcut keys in MS Word: 1. Ctrl + ] increases the font size by one point. 2. Ctrl + 2 applies double line spacing. 3. Ctrl + T creates a hanging indent. Which of the statements given above is/are correct?

    1. 1 and 2 only
    2. 2 and 3 only
    3. 1 and 3 only
    4. 1, 2 and 3
    Show answer

    Answer: (D) 1, 2 and 3

    Explanation: All three are correct: Ctrl + ] / Ctrl + [ change the font size by 1 point, Ctrl + 1 / Ctrl + 2 apply single / double spacing, and Ctrl + T makes a hanging indent.

  24. In MS Word, double-clicking on a word selects the word. What does a triple-click select?

    1. The entire paragraph
    2. The whole line only
    3. The entire document
    4. Only the sentence
    Show answer

    Answer: (A) The entire paragraph

    Explanation: Double-click selects a word and triple-click selects the whole paragraph. Ctrl + A selects the entire document.

  25. Which shortcut adds a bookmark at the cursor position in MS Word?

    1. Ctrl + B
    2. Ctrl + Shift + F5
    3. Shift + F5
    4. Ctrl + Shift + B
    Show answer

    Answer: (B) Ctrl + Shift + F5

    Explanation: Ctrl + Shift + F5 opens the Bookmark dialog. Shift + F5 returns the cursor to the last edited location, and Ctrl + B is Bold.
