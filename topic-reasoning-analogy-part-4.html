  1. EFG : HIJ :: PQR : ?

    1. QRS
    2. UVW
    3. RST
    4. STU
    Show answer

    Answer: (D) STU

    Explanation: Move each letter three places forward.

  2. NO : RS :: TU : ?

    1. XY
    2. VW
    3. YZ
    4. XW
    Show answer

    Answer: (A) XY

    Explanation: Move both letters four places forward.

  3. ABCD : WXYZ :: EFGH : ?

    1. WXYZ
    2. ABCD
    3. STUV
    4. UVWX
    Show answer

    Answer: (B) ABCD

    Explanation: Move every letter four places backward, wrapping around the alphabet.

  4. ACEG : IKMO :: PRTV : ?

    1. WYAC
    2. XZBC
    3. XZBD
    4. YACE
    Show answer

    Answer: (C) XZBD

    Explanation: Move each letter eight places forward, wrapping after Z.

  5. ABC : DEF :: XYZ : ?

    1. BCD
    2. YZA
    3. CDE
    4. ABC
    Show answer

    Answer: (D) ABC

    Explanation: Move each letter three places forward, continuing from Z to A.

  6. MN : OP :: QR : ?

    1. ST
    2. TU
    3. RS
    4. UV
    Show answer

    Answer: (A) ST

    Explanation: Move each letter two places forward.

  7. ABCD : DCBA :: MNOP : ?

    1. ONPM
    2. PONM
    3. PNOM
    4. MOPN
    Show answer

    Answer: (B) PONM

    Explanation: Reverse the order of the letters.

  8. LOVE : EVOL :: HARD : ?

    1. DAHR
    2. HDAR
    3. DRAH
    4. RHAD
    Show answer

    Answer: (C) DRAH

    Explanation: Reverse the four letters.

  9. FLOWER : REWOLF :: FRUITS : ?

    1. SITURF
    2. STRUIF
    3. STUIRF
    4. STIURF
    Show answer

    Answer: (D) STIURF

    Explanation: Reverse the order of all letters.

  10. NAME : 4 :: TRUMPET : ?

    1. 7
    2. 6
    3. 8
    4. 5
    Show answer

    Answer: (A) 7

    Explanation: The number represents the number of letters in the word.

  11. NICE : 14935 :: PRICE : ?

    1. 1618953
    2. 1618935
    3. 1816935
    4. 1691835
    Show answer

    Answer: (B) 1618935

    Explanation: Replace each letter with its alphabetical position: P=16, R=18, I=9, C=3, E=5.

  12. GHA : TSZ :: MPQ : ?

    1. MKI
    2. NLJ
    3. NKJ
    4. OKI
    Show answer

    Answer: (C) NKJ

    Explanation: Replace each letter by its opposite letter in the alphabet: A↔Z, B↔Y, and so on.

  13. AB : ZY :: CD : ?

    1. WX
    2. UV
    3. VU
    4. XW
    Show answer

    Answer: (D) XW

    Explanation: Replace each letter with its opposite in the alphabet, keeping the order.

  14. BDF : HJL :: MOQ : ?

    1. SUW
    2. TVX
    3. RTV
    4. STU
    Show answer

    Answer: (A) SUW

    Explanation: Move each letter six places forward.

  15. MNO : PQR :: EFG : ?

    1. GHI
    2. HIJ
    3. IJK
    4. JKL
    Show answer

    Answer: (B) HIJ

    Explanation: Move each letter three places forward.

  16. ACE : BDF :: MOQ : ?

    1. NQS
    2. OPR
    3. NPR
    4. NQR
    Show answer

    Answer: (C) NPR

    Explanation: Move each letter one place forward.

  17. XYZ : ABC :: PQR : ?

    1. TUV
    2. UVW
    3. QRS
    4. STU
    Show answer

    Answer: (D) STU

    Explanation: Move each letter three places forward, wrapping around after Z.

  18. CAT : XZG :: DOG : ?

    1. WLT
    2. WLO
    3. DLT
    4. WKT
    Show answer

    Answer: (A) WLT

    Explanation: Replace each letter by its opposite in the alphabet: C↔X, A↔Z, T↔G.

  19. ERID : DIRE :: RIPE : ?

    1. PERI
    2. EPIR
    3. EPRI
    4. PEIR
    Show answer

    Answer: (B) EPIR

    Explanation: Reverse the order of the letters in each group.

  20. CAT : 3120 :: DOG : ?

    1. 4715
    2. 4158
    3. 4157
    4. 5147
    Show answer

    Answer: (C) 4157

    Explanation: Write the alphabetical position of each letter in order: D=4, O=15, G=7.

  21. NEWS : 14, 5, 23, 19 :: PAPER : ?

    1. 16, 5, 16, 1, 18
    2. 18, 5, 16, 1, 16
    3. 32, 2, 32, 10, 36
    4. 16, 1, 16, 5, 18
    Show answer

    Answer: (D) 16, 1, 16, 5, 18

    Explanation: Write the alphabetical position of each letter in order.

  22. P × Q : 16 × 17 :: L × M : ?

    1. 12 × 13
    2. 13 × 12
    3. 16 × 13
    4. 17 × 13
    Show answer

    Answer: (A) 12 × 13

    Explanation: Replace each letter by its alphabetical position: P=16, Q=17, L=12, M=13.

  23. ACME : MACE :: FACE : ?

    1. CEFA
    2. CFAE
    3. CAFE
    4. AFCE
    Show answer

    Answer: (B) CFAE

    Explanation: Reorder positions 1–2–3–4 as 3–1–2–4: ACME becomes MACE, so FACE becomes CFAE.

  24. NURTURE : ERUTRUN :: GARDEN : ?

    1. NEDGAR
    2. NEDARG
    3. NEDRAG
    4. GARDEN
    Show answer

    Answer: (C) NEDRAG

    Explanation: Reverse the order of all letters.

  25. Given pair: XY : ZA. Choose the pair with the same rule.

    1. BC : EF
    2. CD : EF
    3. YZ : AB
    4. BC : DE
    Show answer

    Answer: (D) BC : DE

    Explanation: Each letter moves forward by two places: X→Z, Y→A (wrapping around). Applying it to B and C gives D and E.

Why Analogy Part 4 is worth the hours

Analogy Part 4 is factual rather than analytical: you either recall it in seconds or you lose the mark to somebody who did. That makes it one of the cheapest sections to convert - a handful of short sittings usually settles the whole cluster.
