Question bank

Coding and Decoding MCQ – Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. A code is the rank of the first vowel, followed by /, followed by the number of consonant occurrences. A,E,I,O,U are vowels. Which code fits GURDASPUR?

    1. 21/5
    2. 1/6
    3. 21/3
    4. 21/6
    Show answer

    Answer: (D) 21/6

    Explanation: The first vowel is U=21. G,R,D,S,P,R are six consonant occurrences, giving 21/6.

  2. Word codes are fixed and unordered: “Kiran wins today” = “ba se tu”; “Aman wins often” = “ri tu ko”. Which token means “wins”?

    1. ba
    2. se
    3. tu
    4. ko
    Show answer

    Answer: (C) tu

    Explanation: The only common word is wins and the only common token is tu.

  3. A word’s code is its reverse-value sum minus its ordinary alphabet-rank sum. Find the code for SILK.

    1. 210
    2. 51
    3. 6
    4. 57
    Show answer

    Answer: (C) 6

    Explanation: The ordinary sum is 19+9+12+11=51; the reverse sum is 108-51=57. Their difference is 6.

  4. System X moves every letter +7; system Y moves every letter -3. A word entered into X produces QHZWLY. What would Y produce for the same original word?

    1. ULDAPC
    2. GXPMBO
    3. NEWTIV
    4. JASPER
    Show answer

    Answer: (B) GXPMBO

    Explanation: Moving from X’s code to Y’s code changes the shift by -3-7=-10. QHZWLY becomes GXPMBO.

  5. A courier writes every alphabet rank as two digits and joins the groups without separators. Which numeric label belongs to AJMER?

    1. 11013518
    2. 0110130519
    3. 0110131805
    4. 0110130518
    Show answer

    Answer: (D) 0110130518

    Explanation: A,J,M,E,R have ranks 01,10,13,05,18. Joining them gives 0110130518.

  6. An alternating shift is inferred from SONALI→UJPVND. The first-place shift repeats at places 3 and 5; the second-place shift repeats at places 4 and 6. How is RACHNA encoded?

    1. TCEJPC
    2. MCXJIC
    3. TWEDPW
    4. TVECPV
    Show answer

    Answer: (D) TVECPV

    Explanation: The shifts are +2,-5 repeatedly: S→U, O→J. RACHNA becomes TVECPV.

  7. The rule is exactly one of: rank sum plus length; rank product; twice rank sum minus length; sum of rank squares. It gives GEM→47 and LACE→38. What does it give PEAR?

    1. 76
    2. 44
    3. 1440
    4. 606
    Show answer

    Answer: (A) 76

    Explanation: GEM: 2×25-3=47; LACE: 2×21-4=38. Therefore PEAR gives 2×40-4=76.

  8. A five-digit access string replaces every original digit d by 9-d and then reverses the result. What is stored for 30682? Keep leading zeros if any.

    1. 71369
    2. 69317
    3. 28603
    4. 71396
    Show answer

    Answer: (D) 71396

    Explanation: Digit complements give 69317. Reversing gives 71396.

  9. A seven-letter name is encoded with the repeating block +1,-3,+2. The stored code is HRTMBGO. Recover the original name; the block restarts only after every three letters.

    1. GURLEFN
    2. GURLEEN
    3. GURKEEN
    4. GURLDEN
    Show answer

    Answer: (B) GURLEEN

    Explanation: Use -1,+3,-2,-1,+3,-2,-1 to undo the repeating block. This recovers GURLEEN.

  10. Count places from the right, starting at 1. Each letter moves backward by its right-hand place number. Which result belongs to JAIPUR?

    1. DVEMSQ
    2. IYFLPL
    3. DUCJOL
    4. PFMSWS
    Show answer

    Answer: (A) DVEMSQ

    Explanation: From left to right subtract 6,5,4,3,2,1. JAIPUR becomes DVEMSQ.

  11. The labels are SEAT→GATE, GATE→DESK, DESK→SEAT. A guard reports code labels GATE and SEAT for two real items, in that order. Which real pair was reported?

    1. SEAT DESK
    2. SEAT GATE
    3. DESK GATE
    4. GATE SEAT
    Show answer

    Answer: (A) SEAT DESK

    Explanation: Reverse each naming arrow independently: code GATE means real SEAT; code SEAT means real DESK.

  12. Replacing every letter by its alphabet opposite gives the code ZNZO. What was written originally?

    1. AMAZ
    2. AMAL
    3. ALAM
    4. ANAL
    Show answer

    Answer: (B) AMAL

    Explanation: Apply the same opposite pairs again: Z→A, N→M, Z→A, O→L. The original is AMAL.

  13. At left-hand place i, an original vowel moves +i and an original consonant moves -i. Vowels are A,E,I,O,U; use alphabet wraparound. Select the complete code of AMRITSAR.

    1. BOUMYYHZ
    2. BKOMOMHJ
    3. BKOMOMHI
    4. ZOUEYYTZ
    Show answer

    Answer: (B) BKOMOMHJ

    Explanation: Classify original letters before shifting. The shifts +1,-2,-3,+4,-5,-6,+7,-8 give BKOMOMHJ.

  14. Every word has one distinct numeric token; order is arbitrary. “fresh milk daily” = “8 3 6”; “daily school meals” = “6 5 2”; “fresh school fruit” = “8 2 9”; “milk fruit arrives” = “3 9 7”. What is the sum of the tokens for “meals arrives daily”?

    1. 16
    2. 20
    3. 17
    4. 18
    Show answer

    Answer: (D) 18

    Explanation: Common-word elimination gives daily=6, school=2, meals=5 and arrives=7. Required sum: 5+7+6=18.

  15. Each number equals 27 minus the original letter’s rank. In 18-?-23-6, the decoded name is INDU. What must replace the missing number?

    1. 17
    2. 12
    3. 14
    4. 13
    Show answer

    Answer: (D) 13

    Explanation: The missing letter N has rank 14. Its code is 27-14=13.

  16. To secure a two-word label, reverse each word separately, then exchange the two words. What is the secured form of GREEN PARK?

    1. PARK GREEN
    2. NEERG KRAP
    3. KRAP NEERG
    4. KRAP GREEN
    Show answer

    Answer: (C) KRAP NEERG

    Explanation: Separate reversals give NEERG and KRAP. Exchanging the two words gives KRAP NEERG.

  17. The mapping is 4→K, #→A, 7→R, @→T. Which original string is represented by 7#4@?

    1. KART
    2. RAKT
    3. TARK
    4. RATK
    Show answer

    Answer: (B) RAKT

    Explanation: Decode each character in order: 7 # 4 @ → R A K T.

  18. Use row–column coordinates. Matrix I has columns 0,1,2: row 0=P,A,R; row 1=U,N,J. Matrix II has columns 5,6,7: row 5=A,B,P; row 6=R,U,N. Which sequence codes PUNJAB? Each pair must belong entirely to one matrix.

    1. 57-66-67-12-55-56
    2. 57-66-76-12-55-56
    3. 57-66-67-12-56-55
    4. 57-16-67-12-55-56
    Show answer

    Answer: (A) 57-66-67-12-55-56

    Explanation: Read 57=P,66=U,67=N,12=J,55=A,56=B. A coordinate such as 16 cannot mix labels from the two matrices.

  19. A six-letter encoder takes the first three letters as one block and the last three as another, then interleaves them starting with the second block. Its output is GSAAMN. What was the original?

    1. SANGAM
    2. GAMSAN
    3. GASAMN
    4. SAMGAN
    Show answer

    Answer: (A) SANGAM

    Explanation: Read output places 2,4,6 to recover SAN, then 1,3,5 to recover GAM. Joining them gives SANGAM.

  20. Three records use complete reversal correctly. Which record contains an error?

    1. KULLU → ULLUK
    2. KOTLI → ILTOK
    3. MANDI → IDNMA
    4. SHIMLA → ALMIHS
    Show answer

    Answer: (C) MANDI → IDNMA

    Explanation: MANDI reversed is IDNAM. The entry IDNMA swaps the final two letters.

  21. A whole-number encoder uses f(n)=n²-2n. If an input produces 120, which positive input was used?

    1. 14
    2. 10
    3. 12
    4. 11
    Show answer

    Answer: (C) 12

    Explanation: Rewrite n²-2n as (n-1)²-1. Thus (n-1)²=121 and the positive input is 12.

  22. Base codes: A→4, U→9, R→%, 3→K, 6→@. Test original characters. Apply both rules simultaneously: vowel endpoints exchange base codes; every original odd digit gets #. Find the final code of A3R6U.

    1. 9K%@4
    2. 9#%@4
    3. 9#%#4
    4. 4#%@9
    Show answer

    Answer: (B) 9#%@4

    Explanation: The base is 4K%@9. Exchange vowel endpoint codes 4 and 9, and replace only the original odd digit 3’s code: 9#%@4.

  23. Codes are fixed, one-to-one and unordered. “buses reach Ludhiana” = “fa mi so”; “trains reach Delhi” = “mi ku na”; “buses leave Delhi” = “fa te na”. Decode “so te ku”.

    1. Ludhiana leave Delhi
    2. buses leave trains
    3. Ludhiana leave trains
    4. Ludhiana reach trains
    Show answer

    Answer: (C) Ludhiana leave trains

    Explanation: Overlaps identify buses=fa, reach=mi and Delhi=na. The residual codes give so=Ludhiana, te=leave and ku=trains.

  24. First replace each letter of RUPAR by its alphabet opposite. Then keep only original odd-place positions 1,3,5 in the code. Which three-letter result remains?

    1. IFI
    2. IKI
    3. IRK
    4. UKZ
    Show answer

    Answer: (B) IKI

    Explanation: The retained original letters are R,P,R. Their opposites are I,K,I, giving IKI.

  25. A uniform shift changes DELHI to ZAHDE. Under the same shift, which code is printed for PUNE?

    1. LQJA
    2. MRKB
    3. TYRI
    4. KPIZ
    Show answer

    Answer: (A) LQJA

    Explanation: Each letter moves back 4 places. PUNE becomes LQJA.
