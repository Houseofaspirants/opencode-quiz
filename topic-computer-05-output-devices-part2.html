Question bank

Output Devices - Part 2: all 25 questions

Read the question, pick an option, then open the answer.

  1. A printer produces which type of output?

    1. Soft copy
    2. Hard copy (permanent copy on paper)
    3. Audio output
    4. Projected output
    Show answer

    Answer: (B) Hard copy (permanent copy on paper)

    Explanation: A Printer produces a permanent copy of information on paper, i.e. hard copy.

  2. Impact printers print by:

    1. Spraying tiny droplets of liquid ink
    2. Striking an ink ribbon against paper
    3. Using a laser and powdered toner
    4. Using electrostatic charge
    Show answer

    Answer: (B) Striking an ink ribbon against paper

    Explanation: Impact printers print by striking an ink ribbon against paper.

  3. Which of the following is a characteristic of impact printers?

    1. They operate quietly
    2. They give high print quality
    3. They have no contact with paper
    4. They can print carbon copies
    Show answer

    Answer: (D) They can print carbon copies

    Explanation: Impact printers are noisy, have low print quality and can print carbon copies.

  4. The speed of character printers, which print one character at a time, is measured in:

    1. LPM (Lines Per Minute)
    2. PPM (Pages Per Minute)
    3. DPI (Dots Per Inch)
    4. CPS (Characters Per Second)
    Show answer

    Answer: (D) CPS (Characters Per Second)

    Explanation: Character printers print one character at a time; their unit is Characters Per Second (CPS).

  5. Which of the following is an impact printer?

    1. Laser Printer
    2. Dot Matrix Printer
    3. Inkjet Printer
    4. Electrostatic Plotter
    Show answer

    Answer: (B) Dot Matrix Printer

    Explanation: Exam Point: Dot Matrix = Impact Printer.

  6. A Dot Matrix printer creates characters using:

    1. Tiny nozzles that spray ink
    2. A rotating drum of characters
    3. Pins in a print head that form dots
    4. A flower-shaped wheel
    Show answer

    Answer: (C) Pins in a print head that form dots

    Explanation: Dot Matrix printer uses pins in a print head to create characters using dots.

  7. What is the approximate speed of a Dot Matrix printer?

    1. 25–50 CPS
    2. 200–500 CPS
    3. 500–3000 LPM
    4. 600 DPI
    Show answer

    Answer: (B) 200–500 CPS

    Explanation: Dot Matrix printer speed is approximately 200–500 CPS.

  8. Who is credited as the inventor of the Daisy Wheel printer?

    1. Charles Babbage
    2. David S. Lee
    3. Douglas Engelbart
    4. Chester Carlson
    Show answer

    Answer: (B) David S. Lee

    Explanation: The Daisy Wheel printer was invented by David S. Lee.

  9. Which printer uses a flower-shaped wheel, prints only text and cannot print graphics?

    1. Dot Matrix Printer
    2. Laser Printer
    3. Inkjet Printer
    4. Daisy Wheel Printer
    Show answer

    Answer: (D) Daisy Wheel Printer

    Explanation: Daisy Wheel printer uses a daisy-shaped wheel, prints only text, cannot print graphics and is very slow.

  10. What is the speed of a Daisy Wheel printer?

    1. 25–50 CPS
    2. 200–500 CPS
    3. 500–3000 CPS
    4. 300 CPS
    Show answer

    Answer: (A) 25–50 CPS

    Explanation: Daisy Wheel printer speed is 25–50 CPS, which makes it very slow.

  11. Line printers print:

    1. One character at a time
    2. One dot at a time
    3. One complete line at a time
    4. Only graphics
    Show answer

    Answer: (C) One complete line at a time

    Explanation: Line printers print one complete line at a time.

  12. What is the speed range of line printers?

    1. 25–50 LPM
    2. 200–500 LPM
    3. 500–3000 LPM
    4. 5000–9000 LPM
    Show answer

    Answer: (C) 500–3000 LPM

    Explanation: Line printers have a speed of 500–3000 Lines Per Minute (LPM).

  13. Which of the following is NOT a type of line printer?

    1. Daisy Wheel Printer
    2. Drum Printer
    3. Chain Printer
    4. Band Printer
    Show answer

    Answer: (A) Daisy Wheel Printer

    Explanation: Types of line printers are Drum, Chain and Band printers; Daisy Wheel is a character printer.

  14. Which printer uses a rotating chain with embossed characters?

    1. Chain Printer
    2. Drum Printer
    3. Daisy Wheel Printer
    4. Dot Matrix Printer
    Show answer

    Answer: (A) Chain Printer

    Explanation: A Chain Printer uses a rotating chain with embossed characters; a Drum Printer uses a rotating drum.

  15. Which of the following is a characteristic of non-impact printers?

    1. Very noisy operation
    2. Low-quality output
    3. Quiet operation
    4. Slower than impact printers
    Show answer

    Answer: (C) Quiet operation

    Explanation: Non-impact printers have quiet operation, high-quality output and are faster than impact printers.

  16. The speed of non-impact printers is measured in:

    1. CPS (Characters Per Second)
    2. LPM (Lines Per Minute)
    3. RPM (Rotations Per Minute)
    4. PPM (Pages Per Minute)
    Show answer

    Answer: (D) PPM (Pages Per Minute)

    Explanation: The unit for non-impact printers is Pages Per Minute (PPM).

  17. A Laser printer uses:

    1. Liquid ink
    2. Ink ribbon
    3. Toner
    4. Pens
    Show answer

    Answer: (C) Toner

    Explanation: Exam Point: Laser Printer uses Toner, not Ink.

  18. What is the resolution of a Laser printer as given in the chapter?

    1. 600 DPI or more
    2. At least 300 DPI
    3. 200–500 DPI
    4. 25–50 DPI
    Show answer

    Answer: (A) 600 DPI or more

    Explanation: Laser printer resolution is 600 DPI (Dots per Inch) or more; inkjet is at least 300 DPI.

  19. Which printer prints by spraying tiny droplets of liquid ink through nozzles?

    1. Inkjet Printer
    2. Laser Printer
    3. Dot Matrix Printer
    4. Drum Printer
    Show answer

    Answer: (A) Inkjet Printer

    Explanation: An Inkjet printer uses tiny nozzles to spray droplets of liquid ink on paper.

  20. Speakers convert electrical signals into:

    1. Images
    2. Printed text
    3. Digital data
    4. Sound
    Show answer

    Answer: (D) Sound

    Explanation: Speakers convert electrical signals into sound; Speaker = Audio Output Device.

  21. Which output device is specially used for engineering drawings and CAD applications?

    1. Plotter
    2. Speaker
    3. Dot Matrix Printer
    4. Projector
    Show answer

    Answer: (A) Plotter

    Explanation: A Plotter produces high-quality graphics and engineering drawings and is used for CAD.

  22. Compared with a printer, a plotter is:

    1. Less accurate and used for small-size printing
    2. Highly accurate and used for small-size printing
    3. Highly accurate and used for large-size printing
    4. Less accurate and used for large-size printing
    Show answer

    Answer: (C) Highly accurate and used for large-size printing

    Explanation: A plotter draws precise graphics, does large-size printing and is highly accurate.

  23. A Cutting Plotter is also called:

    1. Pen Plotter
    2. Vinyl Cutter
    3. Laser Plotter
    4. Drum Cutter
    Show answer

    Answer: (B) Vinyl Cutter

    Explanation: Cutting Plotter is also called Vinyl Cutter and is used for sign making, vehicle graphics and apparel design.

  24. Which type of plotter uses electrostatic charge to attract toner?

    1. Pen Plotter
    2. Inkjet Plotter
    3. Cutting Plotter
    4. Electrostatic Plotter
    Show answer

    Answer: (D) Electrostatic Plotter

    Explanation: Electrostatic Plotter uses electrostatic charge to attract toner and gives high resolution.

  25. Which of the following is an example of a soft copy?

    1. A PDF displayed on the screen
    2. A printed PDF
    3. A printed certificate
    4. A printed photograph
    Show answer

    Answer: (A) A PDF displayed on the screen

    Explanation: Soft copy is in electronic form and displayed on a monitor, e.g. a PDF on screen; a printed PDF is hard copy.
