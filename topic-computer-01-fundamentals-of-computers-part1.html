Question bank

Fundamentals of Computers - Part 1: all 25 questions

Read the question, pick an option, then open the answer.

  1. According to the chapter, a computer is a man-made ______ machine.

    1. Mechanical
    2. Hydraulic
    3. Electronic
    4. Magnetic
    Show answer

    Answer: (C) Electronic

    Explanation: A computer is a man-made electronic machine that receives data, processes it and produces information.

  2. What is the correct order of the basic working cycle of a computer?

    1. Input → Processing → Output
    2. Processing → Input → Output
    3. Output → Processing → Input
    4. Input → Output → Processing
    Show answer

    Answer: (A) Input → Processing → Output

    Explanation: The basic working of a computer follows the Input → Processing → Output cycle.

  3. When you type "2 + 3" on a keyboard and "5" appears on the screen, the display of "5" is which stage?

    1. Input
    2. Processing
    3. Storage
    4. Output
    Show answer

    Answer: (D) Output

    Explanation: In the chapter's example, "5" displayed on the screen is the Output stage.

  4. In the example of students' marks, the computer calculating the percentage belongs to which stage?

    1. Processing
    2. Input
    3. Output
    4. Storage
    Show answer

    Answer: (A) Processing

    Explanation: Typing marks is Input, calculating percentage is Processing and displaying it is Output.

  5. Raw, unorganized information entered into a computer through input devices is called:

    1. Information
    2. Output
    3. Data
    4. Instruction
    Show answer

    Answer: (C) Data

    Explanation: Data is raw, unorganized information entered through input devices such as keyboard, mouse or scanner.

  6. Processed and organized data that becomes meaningful and useful is called:

    1. Information
    2. Data
    3. Input
    4. Instruction
    Show answer

    Answer: (A) Information

    Explanation: Information is processed and organized data that is meaningful and useful.

  7. Data + Processing = ?

    1. Input
    2. Instruction
    3. Information
    4. Storage
    Show answer

    Answer: (C) Information

    Explanation: The chapter states: Data + Processing = Information.

  8. In the chapter's example, the data 45, 78, 92 is converted into which information?

    1. Average Marks = 78
    2. Average Marks = 71.67
    3. Average Marks = 71.33
    4. Average Marks = 72.67
    Show answer

    Answer: (B) Average Marks = 71.67

    Explanation: Data 45, 78, 92 becomes the information Average Marks = 71.67.

  9. The data entered into a computer is called:

    1. Output
    2. Input
    3. Information
    4. Storage
    Show answer

    Answer: (B) Input

    Explanation: The data entered into a computer is called Input.

  10. The information produced by a computer after processing is called:

    1. Output
    2. Input
    3. Data
    4. Instruction
    Show answer

    Answer: (A) Output

    Explanation: The information produced by a computer after processing is called Output.

  11. Which of the following is an example of Output as given in the chapter?

    1. Clicking with mouse
    2. Audio through speakers
    3. Scanning a document
    4. Typing through keyboard
    Show answer

    Answer: (B) Audio through speakers

    Explanation: Display on monitor, printed report and audio through speakers are examples of output.

  12. Commands given to the computer to perform a specific task, such as "Save a file", are called:

    1. Data
    2. Information
    3. Output
    4. Instructions
    Show answer

    Answer: (D) Instructions

    Explanation: Instructions are commands given to the computer to perform a specific task, e.g. save a file, print a document.

  13. Computer speed refers to the number of instructions processed by the computer in:

    1. One minute
    2. One hour
    3. One second
    4. One day
    Show answer

    Answer: (C) One second

    Explanation: Computer speed is the number of instructions processed in one second.

  14. Among the units of computer speed, the symbol "μs" stands for:

    1. Microsecond
    2. Millisecond
    3. Nanosecond
    4. Picosecond
    Show answer

    Answer: (A) Microsecond

    Explanation: The units of speed listed are Millisecond (ms), Microsecond (μs), Nanosecond (ns) and Picosecond (ps).

  15. Which component executes instructions from software and hardware?

    1. Motherboard
    2. Monitor
    3. Pen Drive
    4. Processor (CPU)
    Show answer

    Answer: (D) Processor (CPU)

    Explanation: The Processor (CPU) executes instructions from software and hardware.

  16. Which of the following is given in the chapter as an example of a processor?

    1. Solid State Drive
    2. AMD Ryzen
    3. Cache Memory
    4. PARAM 8000
    Show answer

    Answer: (B) AMD Ryzen

    Explanation: Intel Core i5, Intel Core i7 and AMD Ryzen are examples of processors.

  17. Which part is called the "Brain of the Computer"?

    1. CPU
    2. Monitor
    3. Keyboard
    4. Hard Disk
    Show answer

    Answer: (A) CPU

    Explanation: CPU is called the brain of the computer.

  18. Which unit performs arithmetic and logical operations?

    1. CU
    2. Memory Unit
    3. Motherboard
    4. ALU
    Show answer

    Answer: (D) ALU

    Explanation: ALU performs arithmetic and logical operations.

  19. Which unit controls all the activities of a computer?

    1. ALU
    2. RAM
    3. CU
    4. SSD
    Show answer

    Answer: (C) CU

    Explanation: CU (Control Unit) controls all activities of the computer.

  20. According to the chapter's quick revision, CPU = ?

    1. CU + ALU + Monitor
    2. CU + ALU + Memory Unit
    3. ALU + RAM + Hard Disk
    4. CU + Motherboard + Storage
    Show answer

    Answer: (B) CU + ALU + Memory Unit

    Explanation: Quick revision: CPU = CU + ALU + Memory Unit.

  21. Memory is used for ______ storage of data and instructions while processing.

    1. Permanent
    2. Offline
    3. Temporary
    4. External
    Show answer

    Answer: (C) Temporary

    Explanation: Memory is used for temporary storage; remember Memory = Temporary, Storage = Permanent.

  22. Which of the following is given in the chapter as an example of Memory?

    1. Pen Drive
    2. CD/DVD
    3. Hard Disk Drive
    4. Cache Memory
    Show answer

    Answer: (D) Cache Memory

    Explanation: RAM and Cache Memory are the examples of memory given in the chapter.

  23. The main circuit board that connects all components of a computer is called:

    1. Processor
    2. Hard Disk
    3. Memory
    4. Motherboard
    Show answer

    Answer: (D) Motherboard

    Explanation: The Motherboard is the main circuit board that connects all components of a computer.

  24. Which component is called the "Backbone of Computer"?

    1. Motherboard
    2. CPU
    3. RAM
    4. Monitor
    Show answer

    Answer: (A) Motherboard

    Explanation: Remember: Motherboard = Backbone of Computer.

  25. Which of the following is a storage device that stores data permanently?

    1. RAM
    2. Solid State Drive (SSD)
    3. Cache Memory
    4. ALU
    Show answer

    Answer: (B) Solid State Drive (SSD)

    Explanation: A storage device stores data permanently, e.g. HDD, SSD, Pen Drive, CD/DVD.
